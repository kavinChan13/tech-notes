内核

操作系统基础

理解进程、线程、调度与虚拟内存，打好系统底层基础。

标签：OS阅读：45 分钟
NUMA 与高级内存管理

first-touch 决定页落在哪个节点（配可运行验证程序）、AutoNUMA 的抖动代价、TLB 覆盖率算例与 THP 的 khugepaged 尖峰、slab/buddy/vmalloc 分工、cgroup v2 的 high 与 max 之别，以及「RSS 不等于真实占用」。

标签：NUMA阅读：70 分钟
进程调度器

CFS/EEVDF 完全公平调度、实时调度与 PREEMPT_RT、多核负载均衡与绑核调优。

标签：Scheduler阅读：45 分钟
多进程与进程间通信

fork/exec 与写时复制的真实代价、多线程 fork 后只能调 async-signal-safe 函数（配确定性复现）、SIGCHLD 必须循环 waitpid、PIPE_BUF 原子性、带同步的共享内存生产者消费者、UDS 传 fd、signalfd 与 self-pipe，末尾是八种机制的选型表。

标签：IPC / Process阅读：60 分钟
文件描述符与三级表模型

三级表里只有第二层会被共享——这一条解释了 dup 与两次 open 的偏移差异、fork 后父子写同一日志的行为，以及「rm 了但空间没释放」。另有 O_APPEND 的边界、CLOEXEC 的由来、SCM_RIGHTS 传 fd 与 fd 泄漏排查。

标签：FD / epoll阅读：45 分钟
内核同步原语与 RCU

原子操作与 READ_ONCE、内存屏障成对法则、spinlock 家族选型、seqlock 与 per-CPU、RCU 宽限期原理与陷阱、lockdep 死锁排查。

标签：Kernel Sync / RCU阅读：50 分钟
设备驱动开发

从内核模块到字符 + 平台驱动，核心是那张「上下文 → 能否睡眠 → 能用哪些 API」对照表（含 threaded IRQ 能睡却不能 copy_to_user）；另有 copy_*_user 的返回值语义、ioctl 的 32/64 混用、四种下半部的判据、DMA 一致性与 IOMMU。

标签：Driver / 嵌入式阅读：70 分钟

标签：Filesystem / Storage阅读：60 分钟

一个包在内核里的完整旅程、NAPI 与软中断、netfilter 五钩子与 conntrack、netns/veth/bridge 手工搭容器网络、tc 队列与 bufferbloat、XDP 数据面、协议栈调优与丢包分层定位。

运维与安全

Linux 启动流程与 systemd

固件到 PID 1 的完整链路、initramfs 的存在理由、unit 依赖的两个维度、Type= 选错的后果、socket 激活、journald 与启动排障救援。

标签：Boot / systemd阅读：45 分钟
容器底层原理

八种 namespace 的创建顺序依赖、PID 1 的信号语义（为什么 docker stop 要等 10 秒）、挂载传播配错会波及宿主、cgroup v2 的 CFS 配额节流尖刺、OverlayFS 整文件 CoW 的实测代价、runc 三阶段握手，以及「哪些资源根本没被 namespace 化」。

标签：Container阅读：55 分钟
Linux 安全模型

权限检查的分层顺序、DAC 与三套 id、capabilities 五个集合、seccomp-bpf 白名单、SELinux/AppArmor 排障、容器逃逸路径与纵深加固。

标签：Security阅读：55 分钟
eBPF 与内核观测机制

标签：eBPF阅读：75 分钟
内核崩溃分析

标签：Kernel Crash阅读：60 分钟
