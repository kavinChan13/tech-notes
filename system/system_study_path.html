Linux 与系统学习路径

P1 内核基础：进程与调度、内核同步、IPC、内存与驱动 → P2 存储与 I/O：I/O 子系统与文件系统持久化语义 → P3 网络：socket 编程、内核收发包路径与异步框架 → P4 运维 · 安全 · 排障：启动流程、容器、安全模型、eBPF 与内核崩溃分析。为 C++ 并发与性能调优打底层。

~77 h
✅ 完成标志
  1. 能说清一次系统调用从用户态到内核态再返回的完整路径，以及一个网络包从网卡到 socket 的完整路径
  2. 能解释「write 返回了数据就安全了吗」，并写出崩溃安全的落盘代码
  3. 能用 eBPF/perf 观测一个真实进程的 I/O、调度或网络行为，并读懂输出
  4. 拿到一个线上故障场景，能分层判断故障域并给出定位与止血步骤
  5. 看到一段内核 Oops 或一个 vmcore，知道从哪里下手
  6. 能为一个服务设计最小权限方案（非 root + caps + seccomp + 只读根），并说清每一层挡住了什么
