感知机 (Perceptron)

感知机是最早的神经网络模型（Rosenblatt, 1957），本质是一个 线性二分类器 ：

1.1 单层感知机

感知机是最早的神经网络模型（Rosenblatt, 1957），本质是一个线性二分类器：

y = sign(w · x + b) = sign(Σ wᵢxᵢ + b)
  • 输入 x ∈ ℝⁿ，权重 w ∈ ℝⁿ，偏置 b ∈ ℝ
  • 学习规则：wᵢ ← wᵢ + η(y − ŷ)xᵢ（感知机收敛定理保证线性可分时有限步收敛）

1.2 线性可分性

单层感知机只能学习线性可分的模式——可以用一个超平面将两类数据完全分开。它能学习 AND、OR、NOT 等简单逻辑门。

1.3 XOR 问题与感知机局限

Minsky & Papert（1969）证明：单层感知机无法解决 XOR（异或）问题，因为 XOR 不是线性可分的。

x₁x₂XOR
000
011
101
110

四个点在二维平面上无法用单条直线分开。

1.4 多层感知机 (MLP) 如何解决

通过引入隐藏层 + 非线性激活函数，MLP 可以学习非线性决策边界：

  • 隐藏层将输入空间映射到新的特征空间，在新空间中 XOR 变得线性可分
  • 例如用 2 个隐藏神经元：h₁ = σ(x₁ + x₂ - 0.5)，h₂ = σ(x₁ + x₂ - 1.5)，再线性组合即可解决 XOR
  • 关键突破：反向传播算法（Rumelhart et al., 1986）使多层网络可训练
知识要点
  • 感知机本质是线性模型，只能处理线性可分问题
  • XOR 问题证明了单层感知机的局限性，推动了多层网络的发展
  • MLP 通过隐藏层+非线性激活实现非线性映射，是深度学习的基石
  • 感知机收敛定理：若数据线性可分，则感知机算法在有限步内收敛

前馈神经网络 (Feedforward Neural Network)

前馈网络信息单向流动，无环路，由三类层组成：

2.1 网络结构

前馈网络信息单向流动，无环路，由三类层组成：

  • 输入层 (Input Layer)：接收原始特征，不含可学习参数（不计入网络层数）
  • 隐藏层 (Hidden Layers)：执行特征变换，每层包含若干神经元
  • 输出层 (Output Layer)：产出最终预测结果
层 l 的计算：z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾，a⁽ˡ⁾ = σ(z⁽ˡ⁾)

2.2 全连接层 (Fully Connected / Dense Layer)

每个神经元与前一层的所有神经元相连。

2.3 参数量计算

对于一个全连接层，输入维度 n_in，输出维度 n_out：

参数量 = n_in × n_out + n_out（权重 + 偏置）

示例：输入 784 → 隐藏 256 → 隐藏 128 → 输出 10

层输入维度输出维度参数量
Layer 1784256784×256 + 256 = 200,960
Layer 2256128256×128 + 128 = 32,896
Layer 312810128×10 + 10 = 1,290
总计235,146

2.4 网络深度 vs 宽度

维度深度（层数多）宽度（每层神经元多）
表达能力能学习分层的、抽象的特征表示增强单层表达能力
参数效率更高 — 深层网络可用更少参数达到等效能力需要指数级更多神经元
训练难度梯度消失/爆炸、退化问题更容易优化
实际策略先适度加深，辅以 ResNet/BatchNorm 等技巧；宽度用于调节容量
知识要点
  • 参数量计算是高频考点，公式：(n_in + 1) × n_out（含偏置）
  • 深度 > 宽度的参数效率：理论上表示同一函数，深层网络参数量可以指数级少于浅层宽网络
  • 输入层不计入"几层网络"的层数统计中
03

激活函数 (Activation Functions)

3.1 Sigmoid

σ(x) = 1 / (1 + e⁻ˣ)　　σ'(x) = σ(x)(1 − σ(x))
  • 输出范围 (0, 1)，可解释为概率
  • 问题①：梯度消失 — 当 |x| 大时，σ'(x) → 0，梯度几乎消失
  • 问题②：输出非零均值 — 均值约 0.5，导致下一层输入偏移
  • 问题③：含 exp 运算，计算开销较大

3.2 Tanh

tanh(x) = (eˣ − e⁻ˣ) / (eˣ + e⁻ˣ)　　tanh'(x) = 1 − tanh²(x)
  • 输出范围 (-1, 1)，零均值，比 Sigmoid 收敛更快
  • 仍有梯度消失问题（饱和区梯度趋近 0）
  • 常用于 RNN/LSTM 的门控结构中

3.3 ReLU (Rectified Linear Unit)

ReLU(x) = max(0, x)　　ReLU'(x) = { 1 if x > 0; 0 if x ≤ 0 }
  • 优势①：计算简单、高效
  • 优势②：正区间梯度恒为 1，缓解梯度消失
  • 优势③：稀疏激活，约 50% 神经元输出为 0
  • 死亡 ReLU：当输入恒为负时，神经元永远输出 0、梯度为 0，永久"死亡"

3.4 Leaky ReLU / PReLU / ELU

Leaky ReLU(x) = max(αx, x)，α 通常取 0.01 PReLU(x) = max(αx, x)，α 为可学习参数 ELU(x) = { x if x > 0; α(eˣ − 1) if x ≤ 0 }
  • 均在负区间保留梯度，解决死亡 ReLU 问题
  • ELU 输出均值接近零，但负区间含 exp 运算
  • PReLU 让负斜率可学习，灵活性最高

3.5 GELU (Gaussian Error Linear Unit)

GELU(x) = x · Φ(x) ≈ 0.5x(1 + tanh[√(2/π)(x + 0.044715x³)])
  • 平滑的非线性，结合了 ReLU 的稀疏性和 Dropout 的随机性思想
  • Transformer 家族（BERT、GPT）默认激活函数
  • 为什么 Transformer 用 GELU？— 平滑性更利于注意力机制的梯度流动，经验上收敛更快、性能更好

3.6 Swish / SiLU

Swish(x) = x · σ(βx)　　当 β=1 时即 SiLU(x) = x · σ(x)
  • Google Brain 通过自动搜索发现的激活函数
  • 平滑、非单调，深层网络中常优于 ReLU
  • 用于 EfficientNet、部分 LLM 中

3.7 Mish

Mish(x) = x · tanh(softplus(x)) = x · tanh(ln(1 + eˣ))
  • 平滑、非单调、自正则化
  • 在 YOLOv4 等视觉模型中表现优异

3.8 Softmax（多分类输出）

Softmax(zᵢ) = eᶻⁱ / Σⱼ eᶻʲ　　输出为概率分布，各元素 ∈ (0,1) 且和为 1
  • 通常只在输出层使用，配合交叉熵损失
  • 温度缩放：Softmax(zᵢ/T)，T↑ 分布更平滑，T↓ 分布更尖锐

3.9 激活函数对比表

激活函数输出范围零均值梯度消失计算效率典型用途
Sigmoid(0, 1)✗严重低二分类输出、门控
Tanh(-1, 1)✓严重低RNN/LSTM
ReLU[0, +∞)✗正区缓解高CNN 隐藏层默认
Leaky ReLU(-∞, +∞)≈缓解高替代 ReLU
PReLU(-∞, +∞)≈缓解高需要自适应负斜率
ELU(-α, +∞)≈缓解中更鲁棒的隐藏层
GELU≈(-0.17, +∞)≈缓解中Transformer
Swish/SiLU≈(-0.28, +∞)≈缓解中EfficientNet、LLM
Mish≈(-0.31, +∞)≈缓解中YOLOv4
Softmax(0, 1) 和=1——中多分类输出层
知识要点
  • 隐藏层默认选 ReLU/GELU；Sigmoid 基本只用于输出层或门控
  • 必须能讲清 Sigmoid 梯度消失的原因：饱和区导数趋近 0，多层链式相乘指数衰减
  • GELU 与 ReLU 的核心区别：GELU 平滑且可微，ReLU 在 0 点不可微、输出硬截断
  • Softmax 的温度参数（Temperature）在推理阶段（如 LLM 采样）中非常重要

万能近似定理 (Universal Approximation Theorem)

Cybenko (1989) / Hornik (1991) ：一个具有 单个隐藏层 和任意…

4.1 定理内容

Cybenko (1989) / Hornik (1991)：一个具有单个隐藏层和任意非线性激活函数的前馈神经网络，只要隐藏神经元数量足够多，就可以以任意精度近似 ℝⁿ 上任意连续函数。

∀ε > 0, ∃ N, W, b：| f(x) − Σᵢ₌₁ᴺ αᵢ σ(wᵢᵀx + bᵢ) | < ε

4.2 直觉理解

  • 每个隐藏神经元可以看作一个"阶梯函数"，大量阶梯函数的组合可以逼近任何形状
  • 类似傅里叶级数：足够多的基函数组合可以逼近任意函数
  • 但定理只保证存在性，不保证可学习性（找不到或需要天文级参数）

4.3 为什么还需要深层网络

  • 参数效率：某些函数用浅层网络逼近需要指数级神经元，深层网络只需多项式级
  • 分层抽象：深层网络自动学习从低级到高级的特征层次
  • 优化角度：虽然浅层理论上能拟合，但深层网络的损失面更容易优化（实践经验）
  • 泛化性：深层网络的归纳偏置更利于泛化
知识要点
  • 万能近似定理是存在性定理，不保证能找到最优参数
  • 浅而宽 vs 深而窄：深层网络参数效率更高，是现代深度学习的基础理论支撑之一
  • 定理要求激活函数非线性（线性激活则多层等价于单层）

权重初始化 (Weight Initialization)

若所有权重初始化为 0（或相同值）：

5.1 零初始化的问题

若所有权重初始化为 0（或相同值）：

  • 所有神经元输出相同 → 梯度相同 → 更新相同 → 对称性破坏失败
  • 网络等价于单个神经元，无论多少层/多少个神经元都无法学习不同特征

5.2 随机初始化

用小的随机数打破对称性（如 N(0, 0.01)），但方差选择不当会导致：

  • 方差太大 → 激活值爆炸（Sigmoid/Tanh 饱和）
  • 方差太小 → 激活值趋近 0 → 梯度消失

5.3 Xavier / Glorot 初始化

适用激活函数：Sigmoid、Tanh（关于原点对称/近似线性区域）

W ~ N(0, 2/(n_in + n_out))　或　W ~ U(-√(6/(n_in + n_out)), √(6/(n_in + n_out)))

推导直觉：

  • 核心目标：让每层的输入方差 ≈ 输出方差，避免信号在前向/反向传播中逐层放大或衰减
  • 假设激活函数在零附近近似线性，则 Var(output) = n_in · Var(W) · Var(input)
  • 要求 Var(output) = Var(input)，前向需要 Var(W) = 1/n_in，反向需要 Var(W) = 1/n_out
  • 取折中：Var(W) = 2/(n_in + n_out)

5.4 He / Kaiming 初始化

适用激活函数：ReLU 及其变体

W ~ N(0, 2/n_in)　　（fan-in 模式）

为什么配合 ReLU：

  • ReLU 会将约一半的激活值置零，等效方差减半
  • Xavier 假设激活函数关于原点对称（线性近似），不适用于 ReLU
  • He 初始化将方差乘以 2 补偿 ReLU 的"截断效应"：Var(W) = 2/n_in

5.5 LSUV (Layer-Sequential Unit-Variance)

  • 先用正交矩阵初始化权重
  • 逐层前向传播一个 mini-batch，测量每层输出方差
  • 缩放权重使每层输出方差 = 1
  • 优势：不依赖激活函数类型的理论假设，数据驱动
初始化方法方差适用激活函数核心思想
Xavier/Glorot2/(n_in+n_out)Sigmoid, Tanh前向反向方差折中
He/Kaiming2/n_inReLU 及变体补偿 ReLU 截断
LSUV数据驱动任意逐层标定方差=1
知识要点
  • 零初始化导致对称性无法破坏，是必须避免的
  • Xavier vs He：关键区别在于 ReLU 将一半输出置零，He 用 2× 补偿
  • 初始化的目标是保持各层激活值和梯度的方差稳定
  • PyTorch 默认 nn.Linear 使用 Kaiming 均匀分布初始化

网络训练流程

6.1 完整训练循环

for epoch in range(num_epochs):                # 外循环：遍历整个数据集
    for batch_x, batch_y in dataloader:         # 内循环：按 mini-batch 迭代
        # 1. 前向传播 (Forward Pass)
        y_pred = model(batch_x)                 # 计算预测值
        
        # 2. 计算损失 (Compute Loss)
        loss = loss_fn(y_pred, batch_y)         # 衡量预测与真实的差距
        
        # 3. 反向传播 (Backward Pass)
        optimizer.zero_grad()                   # 清零梯度（PyTorch 默认累积）
        loss.backward()                         # 计算各参数的梯度 ∂L/∂W
        
        # 4. 参数更新 (Update Parameters)
        optimizer.step()                        # W ← W − η · ∇W

6.2 各阶段细节

阶段核心操作关键点
数据准备归一化、增强、划分 train/val/test、构建 DataLoadershuffle 训练集、固定 val/test
前向传播逐层计算 z = Wx+b, a = σ(z)保存中间激活值用于反向传播
损失计算分类→交叉熵、回归→MSE损失函数选择影响收敛速度
反向传播链式法则逐层计算梯度计算图自动微分
参数更新SGD / Adam 等优化器学习率至关重要

6.3 Epoch / Batch / Iteration 概念

假设训练集 N = 10,000 样本，Batch Size = 100 → 1 个 Epoch = 10,000/100 = 100 次 Iteration
概念定义
Epoch完整遍历训练集一次
Batch (Mini-batch)一次前向+反向传播使用的样本子集
Iteration (Step)一次参数更新（处理一个 batch）
知识要点
  • optimizer.zero_grad() 必须在 loss.backward() 之前调用，否则梯度会累积
  • 梯度累积的正面用途：当 GPU 显存不足时，可累积多个 mini-batch 的梯度再更新，模拟大 batch
  • Epoch 数过多会过拟合，通常用 Early Stopping 控制

超参数 (Hyperparameters)

常用工具： Optuna 、 Ray Tune 、 Weights & Biases Swe…

7.1 学习率 (Learning Rate)

  • 最重要的超参数，直接影响训练能否收敛
  • 太大：loss 震荡甚至发散
  • 太小：收敛极慢，容易陷入局部最优
  • 常用策略：Warmup + Cosine Decay / StepLR / ReduceLROnPlateau
  • 典型初始值：Adam 用 1e-3 ~ 3e-4，SGD 用 0.01 ~ 0.1

7.2 Batch Size

小 batch (32~128)大 batch (512+)
梯度噪声较大 → 正则化效果，有助泛化小 → 可能过拟合
训练速度GPU 利用率低并行效率高
内存需求低高
收敛特性倾向找到平坦最小值（泛化好）倾向找到尖锐最小值

7.3 网络深度与宽度

  • 深度增加 → 特征抽象能力增强，但训练更难
  • 宽度增加 → 单层表达能力增强，但参数量线性增长
  • 实践策略：从较小模型开始，逐步增加直到验证集性能不再提升

7.4 超参数搜索方法

方法原理优点缺点
Grid Search 在预定义的参数网格上穷举 简单直观、可复现 维度灾难——参数组合指数增长
Random Search 在参数空间中随机采样 在高维空间中效率远高于 Grid Search（Bergstra & Bengio, 2012） 不利用历史信息
Bayesian Search 建立目标函数的概率模型（如高斯过程），选最有潜力的点 利用历史结果，样本高效 实现复杂、代理模型本身有开销

常用工具：Optuna、Ray Tune、Weights & Biases Sweeps

知识要点
  • 学习率是"最值得调的超参数"——其他不确定时优先调它
  • Random Search 优于 Grid Search 的原因：大多数超参数只有少数几个对结果影响大，随机搜索能探索更多"重要维度"的值
  • 大 batch 训练需要配合线性 LR scaling（lr ∝ batch_size）+ warmup

8.2 PyTorch 核心 API

nn.Module — 所有模型的基类

import torch
import torch.nn as nn

class MyModel(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_dim, output_dim)
    
    def forward(self, x):
        x = self.relu(self.fc1(x))
        return self.fc2(x)
  • __init__ 中定义层，forward 中定义前向传播逻辑
  • model.parameters() 自动收集所有可学习参数
  • model.train() / model.eval() 切换训练/评估模式（影响 Dropout、BatchNorm）

nn.Linear — 全连接层

layer = nn.Linear(in_features=784, out_features=256, bias=True)
# 参数量 = 784 × 256 + 256 = 200,960
# 权重形状: (256, 784)，偏置形状: (256,)

nn.Sequential — 顺序模型容器

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 128),
    nn.ReLU(),
    nn.Linear(128, 10)
)
# 等价于依次调用各层的 forward

完整训练示例

model = MyModel(784, 256, 10)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(10):
    for x_batch, y_batch in train_loader:
        logits = model(x_batch)
        loss = criterion(logits, y_batch)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
知识要点
  • nn.Module 的 forward 方法不要手动调用，用 model(x) 触发（会执行 hooks）
  • model.eval() 不等于 torch.no_grad()：前者影响层行为，后者关闭梯度计算节省显存

Q&A

为什么神经网络需要非线性激活函数？
没有非线性激活函数，多层网络的组合仍然是线性变换（矩阵连乘 = 一个矩阵），等价于单层线性模型，无法拟合非线性关系。非线性激活函数赋予网络逼近任意复杂函数的能力（万能近似定理）。
Sigmoid 为什么会导致梯度消失？如何缓解？
Sigmoid 在输入绝对值较大时导数趋近 0（最大仅 0.25）。反向传播时，梯度经多层链式相乘后指数级衰减。缓解方法：① 使用 ReLU/GELU 等激活函数；② 使用 BatchNorm 稳定激活值分布；③ 使用 ResNet 的残差连接提供梯度直通路径；④ 合理的权重初始化（Xavier/He）。
ReLU 的死亡问题是什么？怎么解决？
当某个神经元的输入始终为负值时，ReLU 输出恒为 0，梯度也为 0，该神经元永久不再更新——称为"死亡 ReLU"。常见原因：学习率过大导致权重更新过猛。解决方案：① 使用 Leaky ReLU / PReLU / ELU；② 降低学习率；③ 使用合适的权重初始化（He 初始化）；④ 使用 BatchNorm。
Xavier 初始化和 He 初始化的区别是什么？各自适用什么场景？
Xavier 初始化方差为 2/(n_in + n_out)，假设激活函数关于原点对称（如 Sigmoid、Tanh）。He 初始化方差为 2/n_in，专为 ReLU 设计——因为 ReLU 将约一半的值置零（方差减半），所以将初始方差乘以 2 进行补偿。简记：对称激活函数用 Xavier，ReLU 家族用 He。
为什么 Transformer 通常使用 GELU 而不是 ReLU？
① GELU 处处光滑可微，而 ReLU 在 x=0 处不可导，GELU 的平滑性更有利于注意力机制中的梯度流动；② GELU 具有概率解释——以概率 Φ(x) 保留输入，类似于 soft 版的 Dropout，带有自正则化效果；③ 实验上 GELU 在 NLP 任务中始终优于 ReLU；④ GELU 的非单调性（负区间存在小的负值输出）提供了比 ReLU 更丰富的梯度信号。
Batch Size 对训练有什么影响？大 batch 和小 batch 各有什么优劣？
小 batch (32~128)：梯度噪声大，有隐式正则化效果，倾向收敛到平坦的最小值（泛化好），但 GPU 利用率低、训练慢。大 batch (512+)：梯度估计准确，训练吞吐量高，但倾向收敛到尖锐最小值（泛化差），且需要调整学习率（线性缩放 + warmup）。通常推荐从 batch size = 32 或 64 开始，按需增大。
万能近似定理说一层就够了，为什么还要用深度网络？
万能近似定理是存在性定理，理论上可以但实际有三个问题：① 参数效率：单隐层逼近某些函数可能需要指数级神经元，深层网络只需多项式级；② 可学习性：定理不保证 SGD 能找到那个解；③ 泛化性：深层网络学到分层特征表示，归纳偏置更好，泛化能力更强。实践中深层网络在几乎所有任务上优于同参数量的浅层网络。
model.eval() 和 torch.no_grad() 的区别是什么？
model.eval() 改变模型中特定层的行为：Dropout 停止随机丢弃、BatchNorm 使用运行统计量而非 batch 统计量，但仍然会建立计算图、计算梯度。torch.no_grad() 关闭自动梯度计算，节省显存和加速前向传播，但不影响层的行为。推理时应同时使用：model.eval() + with torch.no_grad()。
为什么要在 loss.backward() 之前调用 optimizer.zero_grad()？
PyTorch 的梯度默认是累积的（每次 backward 将新梯度加到已有梯度上）。如果不清零，当前 batch 的梯度会叠加上一次的梯度，导致参数更新方向错误。但梯度累积也有正面用途：当 GPU 显存不足以放下大 batch 时，可以连续调用多次 backward 再调用一次 step，模拟大 batch 训练。
如何计算一个全连接网络的总参数量？如果加入 BatchNorm 呢？
全连接层参数量 = n_in × n_out + n_out（权重 + 偏置）。若某层输出维度为 d 且后接 BatchNorm，BN 增加 2d 个参数（γ 和 β 各 d 个，均值和方差是运行统计量，不算参数）。示例：输入 784 → FC 256 → BN → FC 10，参数量 = (784×256+256) + (2×256) + (256×10+10) = 200,960 + 512 + 2,570 = 204,042。
