生成模型概述

1.1 判别式 vs 生成式模型

维度判别式模型 (Discriminative)生成式模型 (Generative)
建模目标学习 P(y|x)，决策边界学习 P(x) 或 P(x,y)，数据分布
典型代表Logistic 回归、SVM、CNN 分类GAN、VAE、Diffusion、朴素贝叶斯
能力分类/回归采样新数据、密度估计、特征学习
优势通常判别精度更高可生成新样本，理解数据结构

1.2 显式密度 vs 隐式密度

  • 显式密度 (Explicit Density)：直接定义并优化 P(x) 的解析形式。
    • 可直接计算：PixelRNN/CNN、自回归模型
    • 近似计算：VAE（变分下界）、Normalizing Flow（精确似然）
  • 隐式密度 (Implicit Density)：不显式建模 P(x)，通过采样过程间接学习分布。
    • 代表：GAN — 只能采样，不能直接计算概率

1.3 生成模型发展时间线

2013 — VAE (Kingma & Welling)：变分自编码器
2014 — GAN (Goodfellow et al.)：生成对抗网络
2015 — DCGAN：卷积化 GAN；CVAE：条件 VAE
2017 — WGAN / WGAN-GP：Wasserstein 距离解决训练不稳定
2017 — VQ-VAE：离散隐变量
2019 — StyleGAN：高质量人脸生成
2020 — DDPM (Ho et al.)：扩散模型复兴
2021 — DDIM：加速采样；DALL·E：文本到图像
2022 — Stable Diffusion / Imagen / DALL·E 2：Latent Diffusion 大规模落地
2023 — Consistency Models、Flow Matching、SDXL
2024 — Stable Diffusion 3 (Flow Matching)、Sora (视频扩散)
💡 知识要点：
  • 判别式建模 P(y|x)，生成式建模 P(x) — 区别在于学习目标
  • GAN 是隐式密度模型，VAE 是显式密度（近似），Diffusion 属于显式密度（通过去噪得分匹配）
  • 生成模型不仅用于生成，还可用于表示学习、数据增强、异常检测

GAN (Generative Adversarial Network)

GAN 的核心是一个 二人零和博弈 ：

2.1 博弈思想

GAN 的核心是一个二人零和博弈：

  • 生成器 G (Generator)：接受随机噪声 z ~ P(z)，生成假样本 G(z)，目标是"骗过"判别器
  • 判别器 D (Discriminator)：区分真实样本 x 和生成样本 G(z)，输出为真的概率 D(x) ∈ [0,1]

G 和 D 交替训练，互相对抗，最终 G 生成的样本与真实数据不可区分。

2.2 原始目标函数 (Min-Max)

minG maxD V(D, G) = 𝔼x~pdata[log D(x)] + 𝔼z~pz[log(1 − D(G(z)))]
  • D 的目标：最大化 V → 让 D(x) → 1（真实样本判真），D(G(z)) → 0（假样本判假）
  • G 的目标：最小化 V → 让 D(G(z)) → 1（假样本骗过判别器）
  • 最优判别器：D*(x) = pdata(x) / (pdata(x) + pg(x))
  • 代入后等价于最小化 pdata 与 pg 的 JS 散度

2.3 训练过程

  1. 从噪声分布 P(z) 采样 z，生成 G(z)
  2. 从真实数据采样 x
  3. 更新 D：固定 G，最大化 V（通常训练 k 步）
  4. 更新 G：固定 D，最小化 V（或最大化 log D(G(z))）
  5. 重复直至收敛

实践技巧：G 的训练目标通常用 max log D(G(z)) 替代 min log(1-D(G(z)))，因为后者在训练早期梯度消失。

2.4 Nash 均衡

GAN 理想的收敛点是纳什均衡：G 和 D 都无法通过单方面改变策略获益。

  • 理论上达到均衡时：pg = pdata，D(x) = 0.5
  • 实际中 GAN 训练是一个非凸非凹博弈，不保证收敛到纳什均衡
  • 训练过程可能出现振荡、不收敛

2.5 模式崩塌 (Mode Collapse)

定义：G 只学会生成少数几种模式的样本，忽略了数据分布的其他模式。

  • 完全崩塌：所有输入 z 都映射到同一个输出
  • 部分崩塌：只覆盖部分模式，生成多样性不足
  • 原因：G 找到了某些能骗过 D 的"捷径"，D 还未来得及修正
  • 缓解方法：Mini-batch discrimination、Unrolled GAN、WGAN、多样性正则

2.6 训练不稳定性

  • 梯度消失：若 D 太强，G 的梯度接近 0，无法学习
  • 梯度爆炸：G 和 D 更新速率不匹配导致不稳定
  • JS 散度缺陷：当 pdata 和 pg 支撑集不重叠时，JS 散度恒为 log2 → 梯度为 0
  • D/G 平衡：实践中需要仔细调整两者的训练步数比
💡 知识要点：
  • 能完整写出 GAN 的 min-max 目标函数并解释每一项含义
  • 理解最优 D 代入后等价于最小化 JS 散度
  • Mode Collapse 的定义、原因、解决方案
  • 原始 GAN 训练不稳定的根因：JS 散度在分布不重叠时梯度为零

GAN 变体

核心改进 ：用 Wasserstein-1 距离（Earth Mover's Distanc…

3.1 DCGAN (Deep Convolutional GAN)

  • 用卷积/转置卷积替代全连接层
  • G 用转置卷积（反卷积）上采样，D 用卷积下采样
  • 架构准则：使用 BatchNorm（G 中除输出层，D 中除输入层）、G 用 ReLU + Tanh 输出、D 用 LeakyReLU
  • 首次证明 GAN 可以稳定地生成高质量图像

3.2 WGAN (Wasserstein GAN)

核心改进：用 Wasserstein-1 距离（Earth Mover's Distance）替代 JS 散度。

W(pdata, pg) = infγ∈Π(pdata,pg) 𝔼(x,y)~γ[‖x − y‖]

为什么解决不稳定？

  • JS 散度在分布不重叠时为常数 log2 → 梯度消失
  • Wasserstein 距离即使分布不重叠也能给出有意义的梯度
  • W 距离是连续且处处可微的（在 Lipschitz 约束下）

实现要点：

  • D 改称 Critic（不再输出概率，而是分数）
  • 去掉 D 最后的 sigmoid
  • 用 weight clipping 强制 Lipschitz 约束：clip D 的权重到 [-c, c]
  • 优化器用 RMSProp（不用 Adam 中的 momentum）

3.3 WGAN-GP (Gradient Penalty)

Weight clipping 的问题：导致 D 的权重趋向极端值（±c），限制了网络容量。

L = 𝔼x̃~pg[D(x̃)] − 𝔼x~pdata[D(x)] + λ 𝔼x̂~px̂[(‖∇x̂D(x̂)‖₂ − 1)²]
  • 用梯度惩罚替代 weight clipping
  • x̂ 是真实样本和生成样本的随机插值
  • λ 通常取 10
  • 不使用 BatchNorm（与梯度惩罚冲突），改用 LayerNorm 或不用

3.4 StyleGAN

  • Mapping Network：将 z 映射到中间隐空间 w（8 层 MLP），解耦不同属性
  • AdaIN (Adaptive Instance Normalization)：用 w 控制每一层的风格
  • 逐层注入噪声：控制不同尺度的随机变化（高层→姿态/形状，低层→纹理/细节）
  • 渐进式训练：从低分辨率逐步增加到高分辨率
  • StyleGAN2 改进：去除 AdaIN 伪影、引入 path length regularization

3.5 条件 GAN (cGAN)

  • cGAN：G 和 D 都接受条件信息 y（如类别标签），生成特定类别的样本
  • Pix2Pix：用 cGAN 做图像到图像的翻译（如语义分割→真实图像）
  • CycleGAN：无配对数据的图像翻译，引入 cycle consistency loss
cGAN: minG maxD V(D, G) = 𝔼x~pdata[log D(x|y)] + 𝔼z~pz[log(1 − D(G(z|y)|y))]
💡 知识要点：
  • WGAN 用 Wasserstein 距离替代 JS 散度的动机和优势
  • WGAN-GP 为什么比 weight clipping 更好
  • StyleGAN 的 Mapping Network + AdaIN 机制
  • cGAN 的条件注入方式

VAE (Variational Autoencoder)

VAE 将自编码器的隐变量建模为 概率分布 ，而非确定性向量：

4.1 自编码器回顾

  • 编码器 (Encoder)：将输入 x 压缩为隐向量 z = f(x)
  • 解码器 (Decoder)：从 z 重构 x̂ = g(z)
  • 训练目标：最小化重构误差 ‖x − x̂‖²
  • 局限：隐空间不连续、不规则，无法从中采样生成新数据

4.2 VAE 核心思想

VAE 将自编码器的隐变量建模为概率分布，而非确定性向量：

  • 隐变量模型：假设数据 x 由隐变量 z 生成 → P(x) = ∫ P(x|z)P(z)dz
  • 先验：P(z) = N(0, I)
  • 编码器输出的不是 z，而是 q(z|x) 的参数：均值 μ 和方差 σ²
  • 从 q(z|x) 采样 z，再通过解码器重构

4.3 ELBO 推导

目标是最大化数据的对数似然 log P(x)，但直接计算不可行：

log P(x) ≥ 𝔼z~q(z|x)[log P(x|z)] − KL(q(z|x) ‖ P(z)) = ELBO

ELBO（证据下界）两项的含义：

  • 重构损失：𝔼z~q(z|x)[log P(x|z)] → 衡量解码器重构质量，越大越好
  • KL 正则：−KL(q(z|x) ‖ P(z)) → 让编码器输出的分布接近先验 N(0,I)

推导思路：

  1. log P(x) = log ∫ P(x,z)dz
  2. 引入变分分布 q(z|x)，利用 Jensen 不等式或直接分解
  3. log P(x) = ELBO + KL(q(z|x) ‖ P(z|x)) ≥ ELBO

4.4 重参数化技巧 (Reparameterization Trick)

问题：z ~ q(z|x) = N(μ, σ²) 是一个随机采样操作，不可微，无法反向传播。

解决：将采样操作转化为确定性变换 + 独立噪声：

z = μ + σ ⊙ ε，其中 ε ~ N(0, I)
  • 梯度可以通过 μ 和 σ 传播到编码器
  • 随机性全部"转移"到 ε 上
  • 这是 VAE 能端到端训练的关键

4.5 为什么需要 KL 项

  • 如果只有重构损失 → 编码器会为每个样本学习一个极窄的高斯（σ → 0）→ 退化为普通 AE
  • KL 项强制 q(z|x) 接近 N(0,I) → 隐空间连续、规整
  • 规整的隐空间意味着可以从 P(z) 采样 z，再通过解码器生成新数据
  • KL 项还起到正则化作用，防止过拟合

4.6 VAE 的问题

  • 生成模糊：重构损失用 MSE → 倾向于学习平均值 → 图像模糊
  • 后验崩塌：KL 项太强 → 编码器忽略输入，q(z|x) ≈ P(z) → z 不含信息
  • 表达能力有限：高斯先验 + 高斯后验的假设过于简单
  • 生成质量通常不如 GAN（但更稳定、有显式似然）
💡 知识要点：
  • 完整推导 ELBO：从 log P(x) 出发 → 引入 q(z|x) → 分解为重构 + KL
  • Reparameterization Trick 的动机和具体做法
  • KL 项的作用：正则化隐空间、使采样可行
  • VAE 生成模糊的根本原因：MSE 损失 + 高斯假设

VAE 变体

核心改进 ：将连续隐空间替换为 离散 Codebook

5.1 β-VAE

L = 𝔼z~q(z|x)[log P(x|z)] − β · KL(q(z|x) ‖ P(z))，β > 1
  • 增大 β → 更强的 KL 约束 → 促进隐变量的解耦 (Disentanglement)
  • 每个隐变量维度倾向于控制一个独立的生成因子（如颜色、形状、大小）
  • 代价：重构质量下降（重构与解耦的 trade-off）

5.2 VQ-VAE (Vector Quantized VAE)

核心改进：将连续隐空间替换为离散 Codebook。

  • Codebook：维护 K 个离散嵌入向量 e₁, e₂, ..., eK
  • 编码器输出连续向量 ze → 量化为最近的 codebook 向量：zq = ek, k = argmin ‖ze − ei‖
  • 损失函数（三部分）：
    1. 重构损失
    2. Codebook 损失：‖sg[ze] − e‖²（更新 codebook）
    3. Commitment 损失：‖ze − sg[e]‖²（让编码器输出接近 codebook）
  • 不需要 KL 项（均匀使用 codebook）
  • 生成步骤：用自回归模型（如 PixelCNN）在 codebook 索引上建模先验

5.3 VQ-VAE-2

  • 多尺度层次结构：底层 codebook 编码局部细节，顶层编码全局结构
  • 配合强大的先验模型（如 PixelSNAIL）→ 生成质量接近 GAN
  • 是 DALL·E 第一版的基础架构
💡 知识要点：
  • VQ-VAE 如何用 Codebook 实现离散隐变量（量化过程）
  • VQ-VAE 的 Straight-Through Estimator：前向用量化值，反向直接复制梯度
  • β-VAE 中 β 的作用：控制解耦程度

Diffusion Models

从真实数据 x₀ 开始，逐步添加高斯噪声，经过 T 步后变为纯噪声：

6.1 前向过程（逐步加噪）

从真实数据 x₀ 开始，逐步添加高斯噪声，经过 T 步后变为纯噪声：

q(xt | xt-1) = N(xt; √(1−βt) · xt-1, βtI)
  • βt 是第 t 步的噪声系数（noise schedule）
  • 令 αt = 1 − βt，ᾱt = ∏s=1t αs
  • 任意时刻的闭式解（不用逐步加噪）：
q(xt | x₀) = N(xt; √ᾱt · x₀, (1−ᾱt)I)

即 xt = √ᾱt · x₀ + √(1−ᾱt) · ε，ε ~ N(0, I)

6.2 反向过程（逐步去噪）

学习反向转移概率，从纯噪声 xT 逐步去噪回到 x₀：

pθ(xt-1 | xt) = N(xt-1; μθ(xt, t), Σθ(xt, t))
  • 网络需要预测每步去噪的均值 μθ
  • 方差 Σθ 通常固定为 βtI 或 β̃tI
  • 采样过程：xT ~ N(0,I) → 逐步去噪 → x₀

6.3 DDPM 目标函数

通过变分推导，最终简化为噪声预测（Ho et al. 2020 的关键简化）：

Lsimple = 𝔼t,x₀,ε[‖ε − εθ(xt, t)‖²]
  • εθ 是一个神经网络（通常是 U-Net），预测添加到 x₀ 上的噪声
  • 训练：随机采样 t、噪声 ε、数据 x₀ → 构造 xt → 预测噪声
  • 采样：从 xT 开始，用预测的噪声逐步"减去"噪声
  • 等价于得分匹配：εθ ∝ −∇x log p(xt)

6.4 噪声调度 (Noise Schedule)

调度类型βt 变化特点
Linearβ1=10⁻⁴ 线性增到 βT=0.02DDPM 原始，简单
Cosine按余弦函数调整 ᾱt更平滑，避免末期信息过早丢失
Learned可训练参数更灵活，Improved DDPM
💡 知识要点：
  • 前向过程的闭式解：xt = √ᾱt · x₀ + √(1−ᾱt) · ε
  • DDPM 损失简化为噪声预测 MSE 的推导思路
  • Diffusion 等价于得分匹配（Score Matching）
  • 噪声调度对生成质量的影响

Diffusion 进阶

目标 ：增强条件生成的对齐度（如文本→图像更忠实于文本）

7.1 DDIM (Denoising Diffusion Implicit Models)

  • 核心改进：非马尔可夫采样过程 → 可以跳步，减少采样步数
  • DDPM 需要 T=1000 步，DDIM 可用 50~100 步获得相似质量
  • 引入参数 η 控制随机性：η=0 为确定性采样，η=1 退化为 DDPM
  • 确定性采样 → 隐空间有意义 → 可以做插值

7.2 Classifier-Free Guidance (CFG)

目标：增强条件生成的对齐度（如文本→图像更忠实于文本）。

ε̃θ(xt, c) = εθ(xt, ∅) + w · (εθ(xt, c) − εθ(xt, ∅))
  • 训练时随机 drop 掉条件 c（替换为 ∅），让模型同时学有条件和无条件生成
  • 推理时用引导系数 w > 1 放大条件方向的影响
  • w 越大 → 越忠实于条件 → 但多样性降低
  • 无需额外分类器（对比 Classifier Guidance 需要训练一个 noisy classifier）

7.3 Stable Diffusion (Latent Diffusion Model)

核心思想：在隐空间而非像素空间做扩散 → 大幅降低计算成本。

三大组件：

组件作用说明
VAE (Encoder/Decoder)像素空间 ↔ 隐空间将 512×512 图像编码为 64×64 隐表示
U-Net隐空间去噪加入 Cross-Attention 接受条件输入
CLIP Text Encoder文本编码将文本 prompt 编码为 embedding，通过 Cross-Attention 注入 U-Net

训练流程：

  1. 用预训练 VAE 编码器将图像压缩到隐空间
  2. 在隐空间上执行扩散的前向/反向过程
  3. 用 VAE 解码器将去噪后的隐表示还原为图像

7.4 Flow Matching

  • 思想：学习从噪声到数据的连续向量场（ODE 路径），而非离散马尔可夫链
  • 用 ODE solver 代替逐步去噪 → 更灵活的采样
  • 训练目标：预测从 x₁（噪声）到 x₀（数据）的速度场 vθ(xt, t)
  • Stable Diffusion 3、Flux 等新一代模型采用 Flow Matching
  • 与 Diffusion 等价但参数化不同：预测"速度"而非"噪声"
💡 知识要点：
  • DDIM 如何加速采样（跳步 + 确定性采样）
  • CFG 的公式和引导系数 w 的作用
  • Stable Diffusion 三大组件及各自的作用
  • 为什么在隐空间做扩散（降低计算量，隐空间保留语义信息）
  • Flow Matching 与 Diffusion 的区别和联系

Q&A

Q1：GAN 的目标函数是什么？最优判别器是什么？

目标函数：minG maxD V(D,G) = 𝔼x~pdata[log D(x)] + 𝔼z~pz[log(1−D(G(z)))]

最优判别器：D*(x) = pdata(x) / (pdata(x) + pg(x))。代入后，G 的目标等价于最小化 pdata 和 pg 之间的 JS 散度。当 pg = pdata 时，D*(x) = 1/2。

Q2：GAN 的模式崩塌是什么？如何解决？

模式崩塌：生成器只学会生成数据分布中少数几种模式的样本，丧失多样性。极端情况下所有输入 z 映射到同一输出。

原因：G 找到某些能持续骗过 D 的样本，D 来不及调整就被 G 利用。

解决方案：

  • WGAN/WGAN-GP：Wasserstein 距离提供更稳定的梯度信号
  • Mini-batch discrimination：让 D 看到一批样本的统计信息
  • Unrolled GAN：G 更新时考虑 D 的未来更新
  • 多样性正则：惩罚生成样本之间的相似度
Q3：WGAN 为什么比原始 GAN 更稳定？

根本原因：原始 GAN 的损失对应 JS 散度，当生成分布和真实分布的支撑集不重叠时（高维数据中几乎必然发生），JS 散度恒为 log2，梯度为 0。

WGAN 的改进：使用 Wasserstein-1 距离（Earth Mover's Distance），即使分布不重叠也能提供有意义的距离度量和非零梯度。W 距离关于生成器参数是连续且可微的，保证了梯度信号始终存在。

实践改进：WGAN-GP 进一步用梯度惩罚替代 weight clipping，避免权重趋向极端值，提升网络容量。

Q4：推导 VAE 的 ELBO

目标：最大化 log P(x)。

推导：

log P(x) = log ∫ P(x,z)dz = log ∫ P(x|z)P(z)dz

引入变分分布 q(z|x)：

log P(x) = log ∫ [P(x|z)P(z)/q(z|x)] · q(z|x) dz

由 Jensen 不等式：

≥ ∫ q(z|x) log[P(x|z)P(z)/q(z|x)] dz

= 𝔼q[log P(x|z)] − KL(q(z|x) ‖ P(z)) = ELBO

等价地：log P(x) = ELBO + KL(q(z|x) ‖ P(z|x))，由于 KL ≥ 0，所以 ELBO 是 log P(x) 的下界。最大化 ELBO 等价于同时最大化似然和最小化 q 对真实后验的近似误差。

Q5：什么是重参数化技巧？为什么需要它？

问题：VAE 需要从 q(z|x) = N(μ, σ²) 采样 z，但采样操作不可微，无法用反向传播训练编码器。

重参数化：将 z = μ + σ ⊙ ε（ε ~ N(0,I)），随机性转移到独立的 ε 上。此时 z 是 μ 和 σ 的确定性函数（加上外部噪声 ε），梯度可以通过 μ 和 σ 传播到编码器参数。

本质：把不可微的"从参数化分布中采样"操作，变成可微的"确定性变换 + 外部噪声输入"。

Q6：Diffusion Model 的前向和反向过程是什么？

前向过程（固定，不学习）：逐步向数据添加高斯噪声 x₀ → x₁ → ... → xT ≈ N(0,I)。闭式解：xt = √ᾱt · x₀ + √(1−ᾱt) · ε。

反向过程（需学习）：用神经网络（U-Net）逐步去噪 xT → xT-1 → ... → x₀。训练时简化为噪声预测：L = 𝔼[‖ε − εθ(xt, t)‖²]。

关键洞察：前向的闭式解使得训练时可以直接跳到任意 t 步，无需逐步加噪；而反向过程需要逐步去噪（DDIM 可跳步加速）。

Q7：Stable Diffusion 的架构是什么？为什么在隐空间做扩散？

架构三组件：

  • VAE：将图像从像素空间编码到隐空间（如 512×512 → 64×64×4），解码时还原
  • U-Net：在隐空间执行扩散去噪，通过 Cross-Attention 接受文本条件
  • CLIP Text Encoder：将文本 prompt 编码为 token embeddings

为什么用隐空间：

  • 像素空间维度太高（512×512×3 = 786K），扩散计算量巨大
  • 隐空间压缩了冗余信息，保留语义信息 → 同样质量下计算量降低 ~64 倍
  • VAE 的隐空间已经是较好的表示 → 扩散模型只需学习语义级别的去噪
Q8：Classifier-Free Guidance 是什么？如何工作？

目标：增强条件生成的控制力（如让生成图像更忠实于文本描述）。

方法：训练时以一定概率（如 10%）随机丢弃条件 c → 模型同时学会有条件和无条件生成。

推理公式：ε̃ = εθ(xt, ∅) + w · (εθ(xt, c) − εθ(xt, ∅))

w 是 guidance scale：w=1 退化为标准条件生成，w>1 放大条件方向（通常 w=7~12）。w 越大生成越"忠实"于条件，但多样性下降。

优势：无需额外训练分类器（对比 Classifier Guidance），单个模型即可完成。

Q9：GAN、VAE、Diffusion 三者的核心区别是什么？各自的优缺点？

GAN：通过生成器-判别器对抗博弈学习生成。优点：快速采样、锐利图像。缺点：训练不稳定、模式崩塌、无法估计似然。

VAE：通过变分推断最大化 ELBO 学习隐变量模型。优点：训练稳定、有似然估计、隐空间可解释。缺点：生成模糊（MSE + 高斯假设）。

Diffusion：通过逐步去噪学习反转加噪过程。优点：生成质量最高、训练稳定、多样性好、可控性强。缺点：采样速度慢（需多步迭代）。

趋势：Diffusion 已成为主流，但 GAN 的快速推理优势在实时场景仍有价值；VQ-VAE 思想（离散 tokenization）在多模态生成中复兴。

Q10：VQ-VAE 如何工作？与 VAE 的核心区别？

核心区别：VAE 使用连续隐变量 z ~ N(μ,σ²)，VQ-VAE 使用离散隐变量（Codebook 索引）。

工作流程：

  1. 编码器输出连续向量 ze
  2. 在 Codebook {e₁,...,eK} 中找最近邻 → zq = ek（量化）
  3. zq 送入解码器重构
  4. 反向传播用 Straight-Through Estimator 绕过不可微的 argmin

优势：避免 VAE 的后验崩塌问题；离散表示更适合与自回归模型结合（先用 PixelCNN 建模 codebook 索引的先验，再解码生成图像）。

应用：VQ-VAE 思想是 DALL·E 第一版和现代图像 tokenizer 的基础。
