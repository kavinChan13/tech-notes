卷积操作 (Convolution Operation)

卷积核是一个小的权重矩阵（通常 3×3、5×5、7×7），在输入特征图上滑动，通过 逐元素相…

1.1 卷积核 / 滤波器 (Kernel / Filter)

卷积核是一个小的权重矩阵（通常 3×3、5×5、7×7），在输入特征图上滑动，通过逐元素相乘再求和来提取局部特征。

  • 每个卷积核学习一种特征模式（如边缘、纹理、颜色变化）
  • 同一层可设置多个卷积核 → 产出多个特征图（Feature Maps）
  • 卷积核的深度 = 输入的通道数

1.2 步长 (Stride) 与填充 (Padding)

  • Stride：卷积核每次移动的像素数。stride=2 会使输出尺寸减半
  • Padding：在输入边界补零。same padding 保持尺寸不变，valid padding 不补零

1.3 输出尺寸计算

O = ⌊(W − F + 2P) / S⌋ + 1 W = 输入尺寸   F = 卷积核尺寸   P = 填充   S = 步长

例：输入 32×32，卷积核 5×5，P=0，S=1 → O = (32−5+0)/1 + 1 = 28

1.4 多通道卷积

对于 RGB 3 通道输入，单个卷积核也是 3 通道的，即形状为 F × F × C_in。卷积核在每个通道上分别做卷积后求和，产生一个二维特征图。若有 C_out 个卷积核，则输出 C_out 个特征图。

参数量 = C_out × (F × F × C_in + 1) // +1 是 bias

1.5 1×1 卷积的作用

  • 跨通道信息融合：对每个空间位置做通道方向的全连接
  • 升维/降维：改变通道数而不改变空间尺寸，常用于 Bottleneck 结构
  • 增加非线性：1×1 Conv + ReLU 相当于逐像素 MLP
  • GoogLeNet Inception 模块大量使用 1×1 卷积降维以减少计算量
知识要点
  • 能手算输出尺寸公式，注意向下取整
  • 多通道卷积：一个 kernel 的深度 = 输入通道数，输出通道数 = kernel 个数
  • 1×1 卷积 ≠ "什么都不做"：它做的是通道维度的线性变换

池化层 (Pooling)

现代网络（如 ResNet、EfficientNet）倾向于用 stride=2 的卷积 替…

2.1 常见池化类型

类型操作特点
Max Pooling取窗口内最大值保留最强激活，对位置微小偏移鲁棒
Average Pooling取窗口内均值保留整体信息，更平滑
Global Average Pooling (GAP)对整个特征图取均值输出 1×1×C，替代全连接层，大幅减少参数

2.2 池化的作用

  • 平移不变性：特征在空间上小幅移动不影响输出
  • 降维：减少特征图尺寸，降低计算量和过拟合风险
  • 扩大感受野：后续层能"看到"更大的输入区域

2.3 Stride 卷积 vs Pooling

现代网络（如 ResNet、EfficientNet）倾向于用 stride=2 的卷积替代池化：

  • Stride 卷积有可学习参数，信息损失更小
  • Pooling 是固定操作，无参数学习
  • 经验上 stride 卷积效果更好，但增加少量参数
知识要点
  • GAP 常用于分类网络末端，将 H×W×C → 1×1×C，再接 softmax
  • "为什么不直接用 stride 卷积替代所有 pooling？" —— 可以，但 max pooling 在某些任务中提供有用的位置不变性
  • 池化层没有可学习参数

感受野 (Receptive Field)

特征图上一个神经元在 原始输入图像 上所能"看到"的区域大小

3.1 定义

特征图上一个神经元在原始输入图像上所能"看到"的区域大小。它决定了该神经元对输入信息的感知范围。

3.2 计算方法

RF_l = RF_{l-1} + (K_l - 1) × stride_product_{1..l-1} 其中 stride_product = ∏(s_i)，即之前所有层 stride 的乘积

逐层递推：

Layer 1: Conv 3×3, S=1 → RF = 3
Layer 2: Conv 3×3, S=1 → RF = 3 + (3-1)×1 = 5
Layer 3: Conv 3×3, S=2 → RF = 5 + (3-1)×1 = 7  (注意：这一层本身的stride不影响RF大小，但影响后续层)
Layer 4: Conv 3×3, S=1 → RF = 7 + (3-1)×2 = 11  (stride_product 包含了前面的 S=2)

3.3 为什么深层网络感受野更大

  • 每层卷积在前一层的基础上叠加感受野，呈线性增长
  • 加入 stride > 1 或 pooling 后，感受野增长更快（乘法效应）
  • VGG 的核心观点：3 个 3×3 卷积 = 1 个 7×7 卷积的感受野，但参数更少（3×3²C² vs 7²C²）

3.4 有效感受野 (Effective Receptive Field)

理论感受野 ≠ 有效感受野。研究表明有效感受野呈高斯分布，中心区域贡献远大于边缘。实际有效感受野约为理论值的 √RF 量级。

知识要点
  • 能手算简单网络的感受野
  • "为什么用多层小卷积核而不是一层大卷积核？" → 相同感受野但参数更少、非线性更多
  • 感受野太小 → 无法捕获全局信息；太大 → 可能引入噪声

经典架构演进

架构年份深度核心创新Top-5 错误率 (ImageNet)
LeNet-519985首次提出 Conv+Pool+FC 结构，手写数字识别—
AlexNet20128ReLU、Dropout、数据增强、GPU 训练、LRN16.4%
VGGNet201416/19统一使用 3×3 卷积，深度增加到 16-19 层7.3%
GoogLeNet201422Inception 模块（多尺度并行卷积 + 1×1 降维）6.7%
ResNet2015152残差连接（Skip Connection），解决退化问题3.6%
DenseNet2017121+密集连接（每层连接所有前层），特征复用~3.5%
EfficientNet2019—复合缩放（宽度×深度×分辨率），NAS 搜索~2.9%

4.1 关键架构详解

AlexNet 的突破

  • 首次在 ImageNet 上证明深度学习的威力，错误率从 26% 降至 16%
  • 引入 ReLU 替代 Sigmoid（训练速度快 6 倍）、Dropout 正则化
  • 双 GPU 并行训练（当时显存有限）

VGGNet 的哲学

  • 证明了"深度很重要"这一核心观点
  • 全部使用 3×3 卷积核，简洁统一
  • 缺点：参数量巨大（VGG-16 约 138M），FC 层占大部分参数

GoogLeNet / Inception

  • Inception 模块：同一输入并行经过 1×1、3×3、5×5 卷积和 3×3 Max Pooling，再拼接
  • 用 1×1 卷积先降维，大幅减少计算量
  • 无全连接层，使用 GAP，参数仅约 5M（VGG 的 1/28）
知识要点
  • 能说出每个经典架构的"一句话创新点"
  • VGG 深度增加为何有效？—— 更大感受野 + 更多非线性
  • Inception 为何用 1×1 卷积？—— 降维减少 3×3 和 5×5 的计算量
  • 理解 ImageNet 竞赛推动架构演进的历史脉络

ResNet 残差连接

退化问题 (Degradation) ：当网络层数增加到一定程度后，训练误差反而上升

5.1 为什么需要残差？

退化问题 (Degradation)：当网络层数增加到一定程度后，训练误差反而上升。这不是过拟合（测试误差也高），而是优化困难。

理论上，更深的网络至少可以通过学习恒等映射达到与浅网络相同的性能，但实际中 SGD 很难学到恒等映射。

5.2 残差学习

y = F(x) + x // 跳跃连接 (Skip Connection) 网络只需学习残差 F(x) = H(x) - x 当最优映射接近恒等时，F(x) → 0 比 H(x) → x 更容易学习

5.3 为什么残差有效

  • 恒等映射：skip connection 保证信息至少可以无损传递，网络"不会变差"
  • 梯度高速公路：反向传播时梯度可以直接通过 skip 传回，缓解梯度消失
  • 集成学习视角：ResNet 可看作大量不同深度路径的隐式集成
∂L/∂x = ∂L/∂y · (∂F/∂x + 1) // 即使 ∂F/∂x 很小，由于 +1 的存在，梯度至少为 ∂L/∂y

5.4 Bottleneck 结构

Basic Block (浅层):         Bottleneck Block (深层):
  3×3, 64                     1×1, 64  (降维)
  3×3, 64                     3×3, 64  (卷积)
                               1×1, 256 (升维)

// Bottleneck 用 1×1 卷积先降维再升维，减少 3×3 的计算量
// ResNet-50/101/152 使用 Bottleneck，ResNet-18/34 使用 Basic Block

5.5 Pre-activation ResNet (v2)

  • 原始 ResNet：Conv → BN → ReLU → Conv → BN → Add → ReLU
  • Pre-activation：BN → ReLU → Conv → BN → ReLU → Conv → Add
  • 优势：信息在 skip 上完全无阻碍传播（没有 ReLU 挡住），性能略优
知识要点
  • "退化问题"≠ 过拟合，是训练误差上升
  • 残差连接的梯度推导（+1 保底梯度）
  • Bottleneck 1×1→3×3→1×1 的目的：计算量从 O(C²·9) 降到 O(C·C/4·9 + ...)
  • Pre-activation 版本中 skip 完全是恒等映射

深度可分离卷积 (Depthwise Separable Convolution)

将标准卷积分解为两步：

6.1 核心思想

将标准卷积分解为两步：

  1. Depthwise Conv：每个通道独立用一个 F×F 卷积核 → 空间特征提取
  2. Pointwise Conv：用 1×1 卷积跨通道融合 → 通道特征融合

6.2 参数量与计算量对比

标准卷积深度可分离卷积比例
参数量 F² × C_in × C_out F² × C_in + C_in × C_out ≈ 1/C_out + 1/F²
计算量 F² × C_in × C_out × H × W F² × C_in × H × W + C_in × C_out × H × W ≈ 1/C_out + 1/F²

对于 3×3 卷积、256 通道：计算量约为标准卷积的 1/8 ~ 1/9

6.3 MobileNet 核心设计

  • MobileNet V1：全面使用 Depthwise Separable Conv，引入宽度乘子 α 和分辨率乘子 ρ
  • MobileNet V2：Inverted Residual Block — 先升维后降维（与 Bottleneck 相反），在低维做 skip connection
  • MobileNet V3：NAS 搜索 + SE 注意力模块 + h-swish 激活
MobileNet V2 Inverted Residual:
  Input (low-dim) → 1×1 升维 → 3×3 Depthwise → 1×1 降维 → Add
  // 在高维空间做 Depthwise，保留更多信息
知识要点
  • 能推导深度可分离卷积的参数量/计算量节省比例
  • MobileNet V2 Inverted Residual 为何"先升维后降维"？—— 低维空间信息不足以做复杂变换
  • 适用场景：移动端、嵌入式等资源受限设备
07

其他卷积变体

7.1 空洞卷积 / 膨胀卷积 (Dilated / Atrous Convolution)

  • 在卷积核元素之间插入空洞（dilation rate = r），不增加参数但扩大感受野
  • 有效卷积核大小：F_eff = F + (F-1)(r-1)
  • 应用：语义分割（DeepLab 系列），在不降分辨率的前提下获取多尺度上下文
  • 问题：棋盘效应 (Gridding) — 连续使用相同 dilation 率导致信息不连续

7.2 转置卷积 (Transposed Convolution)

  • 也称反卷积（Deconvolution），实现上采样（特征图从小到大）
  • 不是卷积的数学逆运算，而是将卷积的前向与反向互换
  • 输出尺寸：O = (I-1)×S - 2P + F
  • 问题：容易产生棋盘格伪影 (Checkerboard Artifacts)，可用 resize + conv 替代
  • 应用：GAN 生成器、语义分割上采样

7.3 可变形卷积 (Deformable Convolution)

  • 在标准卷积基础上，为每个采样点学习一个 2D 偏移量 (offset)
  • 采样位置不再是固定网格，可自适应目标形状
  • 适用于目标检测、姿态估计等目标形变较大的场景

7.4 分组卷积 (Group Convolution)

  • 将输入通道分为 G 组，每组独立卷积，最后拼接
  • 参数量和计算量降为 1/G
  • AlexNet 最早使用（双 GPU 限制）；ResNeXt 系统化使用（增加"基数"维度）
  • 极端情况 G = C_in 就是 Depthwise Conv
变体核心特点代表应用
空洞卷积不降分辨率扩大感受野DeepLab, WaveNet
转置卷积可学习的上采样GAN, FCN, U-Net
可变形卷积自适应采样位置目标检测、姿态估计
分组卷积通道分组独立卷积ResNeXt, ShuffleNet
知识要点
  • 空洞卷积的感受野公式和棋盘效应
  • 转置卷积的棋盘格伪影问题及替代方案（双线性插值 + Conv）
  • 分组卷积参数量计算，为何 G=C_in 就是 Depthwise Conv

CNN 的数学本质

同一个卷积核在整个输入图像上滑动共享权重

8.1 参数共享 (Parameter Sharing)

同一个卷积核在整个输入图像上滑动共享权重。与全连接层相比：

  • FC 层检测 32×32 图像的某个 5×5 模式需要为每个位置学习独立权重 → 参数爆炸
  • 卷积层只需要一组 5×5 权重 → 参数量从 O(H×W×F²) 降到 O(F²)
  • 前提假设：特征在空间上是平移等变的（同一模式在不同位置有相同响应）

8.2 局部连接 (Local Connectivity)

每个神经元只连接输入的一个局部区域（感受野），而非全部。

  • 利用了自然图像的局部性先验：相邻像素高度相关
  • 局部连接 + 参数共享 = 卷积

8.3 平移等变性 vs 平移不变性

性质定义数学表达CNN 对应
平移等变性
(Equivariance)		 输入平移 → 输出同样平移 f(T(x)) = T(f(x)) 卷积层天然具有
平移不变性
(Invariance)		 输入平移 → 输出不变 f(T(x)) = f(x) 通过 Pooling / GAP 获得

整体 CNN = 卷积（等变）+ 池化（不变）的交替堆叠，逐步从等变到不变。

知识要点
  • "CNN 相比 FC 的优势？" → 参数共享（减参数）+ 局部连接（降计算）+ 平移等变性（泛化好）
  • 严格区分 equivariance 和 invariance：卷积本身是等变的，加上 pooling 才有不变性
  • 参数共享的前提假设：特征的统计特性在空间上一致
09

经典应用

9.1 图像分类 (Image Classification)

  • 最经典的 CNN 任务：输入图像 → 输出类别概率
  • 结构：特征提取（Conv+Pool）→ GAP → FC/Softmax
  • 代表：AlexNet, VGG, ResNet, EfficientNet
  • 技巧：数据增强、迁移学习（ImageNet 预训练 → 微调）

9.2 目标检测 (Object Detection)

Two-Stage: Faster R-CNN

  • Stage 1：Region Proposal Network (RPN) 生成候选框（Anchor-based）
  • Stage 2：对每个候选框做分类 + 边框回归
  • 核心：RPN 与检测网络共享 CNN 特征（Feature Sharing）
  • 精度高但速度较慢

One-Stage: YOLO

  • "You Only Look Once"：将检测建模为回归问题
  • 将图像分为 S×S 网格，每个格子预测 B 个边框 + 置信度 + 类别
  • 单次前向传播完成检测，速度极快
  • YOLO 系列演进：V1(2016) → V2/V3(更好的 backbone) → V4/V5(大量工程优化) → V8+

9.3 语义分割 (Semantic Segmentation)

FCN (Fully Convolutional Network)

  • 将 FC 层替换为卷积层，输出逐像素分类图
  • 使用转置卷积上采样恢复分辨率
  • Skip Connection 融合多尺度特征（FCN-8s）

U-Net

  • 编码器-解码器对称结构（U 形）
  • 编码器下采样提取特征，解码器上采样恢复分辨率
  • 跳跃连接：将编码器的特征直接拼接到解码器对应层（保留高分辨率细节）
  • 在医学图像分割领域极为成功（小数据集也能效果好）
任务输出代表方法关键思想
图像分类类别标签ResNet, EfficientNet特征提取 + 分类头
目标检测边框 + 类别Faster R-CNN, YOLO区域提议 / 直接回归
语义分割逐像素类别FCN, U-Net, DeepLab编码-解码 / 空洞卷积
实例分割逐像素实例Mask R-CNNFaster R-CNN + Mask 分支
知识要点
  • Two-stage vs One-stage 检测：精度 vs 速度的权衡
  • YOLO 如何实现端到端检测？→ 回归 bbox + class in one pass
  • U-Net 跳跃连接与 ResNet 残差连接的区别：U-Net 是 concatenate（拼接），ResNet 是 add（相加）
  • FCN 如何将分类网络改为分割网络？→ FC 层替换为 1×1 Conv

Q&A

参数量 = C_out × (F × F × C_in + 1) ，其中 +1 是 bias
Q1: 卷积层的参数量怎么算？

参数量 = C_out × (F × F × C_in + 1)，其中 +1 是 bias。例如：输入 64 通道，使用 128 个 3×3 卷积核，参数量 = 128 × (3×3×64 + 1) = 128 × 577 = 73,856。

Q2: 为什么用多个小卷积核比一个大卷积核更好？

两个 3×3 卷积 = 5×5 的感受野，三个 3×3 = 7×7 的感受野。优势：①参数更少（2×3²C² vs 5²C²）；②更多非线性（多次 ReLU 激活）；③正则化效果（限制了表达空间）。这是 VGGNet 的核心设计哲学。

Q3: ResNet 的残差连接为什么能训练更深的网络？

两个核心原因：①恒等映射：skip connection 保证最差情况也能保持浅层网络性能，网络只需学习残差 F(x)→0；②梯度高速公路：反向传播时 ∂L/∂x = ∂L/∂y·(∂F/∂x + 1)，+1 保证梯度不会消失。另外从集成学习视角，ResNet 相当于隐式集成了不同深度的子网络。

Q4: 深度可分离卷积节省了多少计算量？

计算量比例 ≈ 1/C_out + 1/F²。对于 3×3 卷积、256 个输出通道：比例 ≈ 1/256 + 1/9 ≈ 0.115，即节省约 88-89% 的计算量。它将空间相关性和通道相关性解耦，分别用 Depthwise 和 Pointwise 处理。

Q5: 平移等变性和平移不变性有什么区别？

等变性 (Equivariance)：输入移动，输出也相应移动 — f(T(x))=T(f(x))，卷积层天然具有。不变性 (Invariance)：输入移动，输出不变 — f(T(x))=f(x)，需要通过 Pooling/GAP 获得。图像分类需要不变性（猫在哪都是猫），目标检测需要等变性（位置信息很重要）。

Q6: 1×1 卷积有什么用？

三大作用：①改变通道数（升维/降维），如 Inception 中降维减少后续计算；②跨通道信息融合，对每个空间位置做通道方向线性变换；③增加非线性，1×1 Conv + ReLU = 逐像素 MLP。它不改变空间尺寸，只操作通道维度。

Q7: 空洞卷积解决什么问题？有什么缺陷？

解决的问题：在不增加参数、不降低分辨率的前提下扩大感受野，特别适合语义分割。dilation rate=r 时有效核大小为 F+(F-1)(r-1)。缺陷：棋盘效应 (Gridding)，连续使用相同 dilation 率会跳过部分像素，导致局部信息丢失。解决方案：使用不同 dilation 率组合（如 DeepLab 的 ASPP 模块）。

Q8: U-Net 和 ResNet 的跳跃连接有何不同？

ResNet：跳跃连接做逐元素相加 (add)，要求维度完全一致，目的是解决梯度消失和退化问题。U-Net：跳跃连接做通道拼接 (concatenate)，将编码器高分辨率特征与解码器语义特征融合，目的是保留空间细节用于精确分割。本质区别：add 是信息融合，concat 是信息保留。

Q9: 转置卷积为什么会产生棋盘格伪影？

当 kernel size 不能被 stride 整除时，输出像素被卷积核覆盖的次数不均匀，某些位置被多次叠加，某些位置覆盖较少，形成规律性的亮暗交替。解决方案：①使用双线性插值上采样 + 普通卷积替代；②选择 kernel size 为 stride 的整数倍；③使用 PixelShuffle（亚像素卷积）。

Q10: CNN 在 Vision Transformer 时代还有价值吗？

有，且互补：①归纳偏置 (Inductive Bias)：CNN 的局部性和平移等变性在小数据上优势明显，ViT 需要大量数据；②效率：轻量级 CNN（MobileNet 等）在端侧部署仍是主流；③混合架构：ConvNeXt 证明纯 CNN 在采纳 Transformer 设计理念后可达到 ViT 级别性能；④低层特征提取：许多 ViT 变体也在前几层使用卷积。CNN 与 Transformer 正在走向融合而非替代。
