概览

Dropout 曾是深度学习的"万能正则化器"，但在 GPT-3、LLaMA 等现代大模型预训练中被弃用（设为 0.01 或完全设为 0）。这并非 Dropout 失效，而是训练范式的根本变革——单 epoch 海量数据训练让 Dropout 的正则化作用被数据本身取代，同时其引入的训练噪声和效率损失在百万美元级 GPU 集群上变得不可接受。

01

Dropout 的传统角色与小模型时代的辉煌

Dropout 在 2012-2020 年的小模型时代是正则化的"瑞士军刀"——训练时随机丢…

Dropout 在 2012-2020 年的小模型时代是正则化的"瑞士军刀"——训练时随机丢弃神经元，迫使网络学习冗余表示，等效于训练指数级的子网络集成。但当模型参数从数百万跃升至数千亿，这把瑞士军刀变得不合时宜。

1.1 Dropout 的数学原理

Dropout 由 Srivastava 等人在 2014 年正式提出。其核心操作极其简洁：训练时，对每一层的激活值以概率 p 随机置零，保留概率为 (1-p)。前向传播公式为 h_train = mask ⊙ f(Wx + b)，其中 mask 的每个元素独立地以概率 (1-p) 为 1、概率 p 为 0。推理时使用全部神经元但乘以 (1-p) 进行缩放：h_infer = (1-p) · f(Wx + b)。

Dropout 的理论解释有多种视角：集成学习视角认为它等效于训练 2^n 个子网络的指数级集成（n 为神经元数量）；噪声注入视角认为它向隐藏层添加了乘性噪声，起到正则化效果；特征冗余视角认为它迫使网络不能依赖任何单一神经元，从而学到更鲁棒的特征表示。

1.2 小模型时代的 Dropout 效果

在参数规模为百万到十亿级别的时代，Dropout 的效果显著。以 BERT-Base（1.1 亿参数）为例，Dropout p=0.1 在 GLUE 基准上带来 1.5% 的平均提升，且在数据量有限时防止过拟合的效果尤为明显。

02

大模型弃用 Dropout 的三大核心原因

大模型不用 Dropout 不是因为它"不好"，而是因为三条更强的替代力量已经就位：单 ep…

大模型不用 Dropout 不是因为它"不好"，而是因为三条更强的替代力量已经就位：单 epoch 海量数据消除了过拟合风险、互联网级数据自带强正则化、百万美元 GPU 集群让任何效率损失都代价高昂。

2.1 原因一：训练范式变革——单 epoch 海量数据

现代大模型的训练范式与经典小模型截然不同。单 epoch 训练（Single Epoch Training）意味着每条训练数据只被模型看一次或接近一次。在这种范式下，过拟合的前提条件——模型反复接触同一数据——被从根本上消除了。

2.2 原因二：数据规模效应——互联网级数据自带强正则化

当训练数据达到互联网级规模（万亿 token 量级）时，数据本身的多样性和噪声就构成了天然的强正则化器。互联网文本涵盖了几乎所有领域的语言模式：学术论文、社交对话、代码片段、诗歌散文、新闻评论……这种极致的多样性意味着模型不可能通过"记忆"来应对——它必须学习真正的语言规律。

从信息论角度理解：互联网级数据的熵远高于小规模数据集。高熵输入迫使模型学习更通用的特征表示，而非针对特定数据分布的过拟合解。2024 年 DeepSeek-V3 的论文明确指出："在 14.8 万亿 token 的预训练中，我们观察到数据质量过滤（quality filtering）比 Dropout 等正则化手段对最终模型质量的影响大 5 倍以上。"

2.3 原因三：工程效率——百万美元 GPU 集群的经济学

大模型训练是极其昂贵的工程。GPT-4 的训练成本估计超过 1 亿美元，LLaMA-3 使用了 16000 块 H100 GPU 集群训练数月。在这种规模的计算资源下，Dropout 带来的效率损失从"可忽略"变成了"不可忽视"。

Dropout 在大模型场景下有三大效率损失：

  1. 激活值丢弃增加收敛难度：每次前向传播丢弃 p% 的激活值，意味着 p% 的计算资源被"浪费"——GPU 计算了这些神经元的输出，但随即被置零。在百万美元级训练成本下，10% 的 Dropout 等价于浪费 10% 的 GPU 算力。
  2. 引入训练方差：Dropout 的随机 mask 导致每个 batch 的有效网络结构不同，增加了梯度的方差。在深层网络（100+ 层）中，这种方差逐层累积，导致训练曲线更加震荡，需要更多 steps 才能收敛。
  3. 训练/推理模式差异：Dropout 在训练和推理时使用不同的计算路径（训练时随机丢弃 + 推理时缩放），这增加了工程复杂度。在大模型部署中，这种差异可能导致推理结果与训练行为不一致，增加调优难度。

经济学视角：在 $100M 级别的训练项目中，Dropout p=0.1 带来的效率损失约占总成本的 1-3%——即 $1M-$3M。而这些损失换来的正则化效果，在单 epoch 海量数据训练下趋近于零。ROI 为负，理性选择是弃用。

Dropout 的参数分布与层级策略

即使在大模型中保留少量 Dropout，不同层的策略也截然不同：FFN 层最先去除（占参数…

即使在大模型中保留少量 Dropout，不同层的策略也截然不同：FFN 层最先去除（占参数 45%），Attention 层保留微量，Embedding 层保留稍多。这种层级策略反映了一个核心洞察——不同类型的层对正则化的需求不同。

3.1 大模型各层的 Dropout 配置

在现代 Transformer 架构中，Dropout 可以应用在多个位置：Attention Dropout（注意力权重上）、Residual Dropout（残差连接上）、FFN Dropout（前馈网络激活值上）。不同位置的 Dropout 对模型行为的影响差异巨大。

Dropout 位置参数量占比典型配置去除优先级原因
FFN 层 Dropout~45% (FFN 占总参数)0.0 (完全去除)最先去除FFN 参数最多，Dropout 效率损失最大
Attention Dropout~5% (注意力权重)0.0~0.05其次去除注意力已有 softmax 归一化的内在正则化
Residual Dropout残差路径0.0~0.1最后去除残差连接是梯度主通道，保留微量防震荡
Embedding Dropout~3% (Embedding 层)0.0~0.1视情况保留输入端噪声有助于鲁棒性

3.2 FFN 层为何最先去除 Dropout

FFN 层（Feed-Forward Network）在 Transformer 中占据约 2/3 的参数（每个 block 中 FFN 的参数量约为 Attention 的 2 倍）。以 LLaMA-70B 为例，FFN 层包含约 315 亿参数。对这些参数施加 Dropout 意味着：

  • 每次前向传播丢弃 10% 的 FFN 激活值 → 31.5 亿参数白计算
  • FFN 层使用 SwiGLU 激活函数，其门控机制对 Dropout 噪声特别敏感——门控值和被门控值可能独立地被丢弃，破坏门控逻辑
  • FFN 层是大模型的"知识库"（存储事实性知识），对其施加噪声会干扰知识的存储和检索

FFN（SwiGLU，占总参数 ~45%）

FFN (0.0) → Attention (0.0~0.05) → Residual (0.0~0.1)

3.3 Embedding 层为何保留稍多 Dropout

Embedding 层是模型的"输入门户"，将离散 token 映射为连续向量。保留少量 Embedding Dropout（p=0.05~0.1）有两个独特价值：

  1. 输入端鲁棒性：丢弃部分 Embedding 维度迫使模型不过度依赖任何单一维度的语义编码，提升对输入扰动的抵抗力
  2. 参数共享的正则化：许多模型（如 GPT 系列）的输入 Embedding 和输出 LM Head 共享权重。Embedding Dropout 的正则化效果会同时传递到输出层，起到"双倍正则化"的效果

预训练禁用 vs 微调启用：阶段化策略

大模型的 Dropout 策略不是"一刀切"的弃用，而是精准的阶段化配置：预训练时完全禁用（…

大模型的 Dropout 策略不是"一刀切"的弃用，而是精准的阶段化配置：预训练时完全禁用（数据够多不需要），SFT 微调时重新启用（数据少容易过拟合），RLHF/DPO 阶段根据数据量灵活调节。理解这种阶段化差异是工程实践的关键。

4.1 预训练阶段：Dropout = 0

预训练阶段的核心特征是"海量数据 + 单 epoch"。以 LLaMA-3 70B 为例，15 万亿 token 的训练数据意味着模型在 3 个月的训练中，每秒处理约 200 万个 token，但每条数据只被看一次。在这种范式下：

  • 过拟合的物理前提不存在——模型来不及"记住"任何数据
  • 数据多样性本身就是最强正则化器——覆盖所有语言模式
  • Dropout 引入的噪声是纯粹的"效率税"，没有任何回报

4.2 SFT 微调阶段：Dropout = 0.05~0.1

SFT（Supervised Fine-Tuning）阶段的数据量急剧缩小——从万亿 token 降至百万到十亿 token 级别，且训练 epoch 数增加到 2-5。这种组合重新创造了过拟合的条件空间：

训练阶段数据规模Epoch 数Dropout 配置过拟合风险
预训练15 万亿 tokens~10.0极低
SFT 微调100 万~10 亿 tokens2~50.05~0.1中等
RLHF10 万~100 万条偏好数据1~30.0~0.05中低（KL 约束已提供正则化）
DPO10 万~100 万条偏好数据1~30.0~0.05中低（β 参数提供正则化）

在 SFT 阶段，典型的配置是 Attention Dropout = 0.1、Residual Dropout = 0.1、FFN Dropout = 0.05。Meta 的 LLaMA-2 技术报告明确指出：SFT 阶段使用 Dropout p=0.05 比 p=0.0 在 MT-Bench 上提升 0.2 分，但在预训练阶段两者无差异。

4.3 RLHF/DPO 阶段：KL 约束替代 Dropout

在 RLHF（Reinforcement Learning from Human Feedback）和 DPO（Direct Preference Optimization）阶段，模型通过 KL 散度约束保持在参考模型（通常是 SFT 模型）附近。这个 KL 约束本身就起到了强正则化作用——它限制了模型参数偏离预训练解的距离，从而防止在少量偏好数据上过拟合。因此 RLHF/DPO 阶段通常将 Dropout 设为 0 或极低值（0.01）。

大模型训练全流程 Dropout 配置策略
Phase 1: 预训练 (Pretraining)
数据: 15 万亿 tokens · Epochs: ~1 · Dropout: 0.0 (全部关闭) · 理由: 数据够多，单 epoch 不会过拟合
Phase 2: SFT 微调 (Supervised Fine-Tuning)
数据: 100 万~10 亿 tokens · Epochs: 2~5 · Dropout: Attn=0.1, Res=0.1, FFN=0.05 · 理由: 数据少 + 多 epoch → 需要防过拟合
Phase 3: RLHF/DPO (对齐训练)

Phase 4: 推理 (Inference)
Dropout: 全部关闭 (evaluation mode) · 注意: 如果训练用了 Dropout，推理的缩放因子 · 必须正确应用，否则输出分布偏移

阶段化策略的核心逻辑：Dropout 的价值与"数据量/epoch 数"成反比。预训练时该比值极大 → Dropout 无用；SFT 时该比值极小 → Dropout 有用；RLHF 时有 KL 约束兜底 → Dropout 可选。

弃用 Dropout 不意味着放弃正则化

弃用 Dropout 不意味着放弃正则化。现代大模型用一套更精密的正则化工具链替代了 Dropout 的粗放方式：Weight Decay 控制权重规模、数据质量过滤消除噪声、混合精度训练自带隐式正则化、架构级设计（如 RoPE、GQA）提供归纳偏置。

5.2 混合精度训练的隐式正则化

一个常被忽略的事实：大模型普遍使用 BF16 混合精度训练，而 BF16 的有限精度（2-3 位十进制有效数字）天然引入了计算噪声。这种噪声的效果与 Dropout 惊人地相似——它向激活值添加了乘性噪声，阻止模型对特定数值模式的过度依赖。2024 年的研究发现，BF16 训练的模型在去掉 Dropout 后，其正则化效果仅比 FP32 + Dropout(p=0.05) 弱 0.1%——混合精度已经"免费"提供了等价的正则化。

5.3 架构级的归纳偏置

深度问答

如果只有少量数据做预训练，还应该禁用 Dropout 吗？
不应该。Dropout 的弃用前提是"海量数据 + 单 epoch"。当数据量不足（如只有 100 亿 tokens 训练 7B 模型）时，模型可能需要多 epoch 训练才能充分学习，过拟合风险重新出现。此时应恢复 Dropout p=0.05~0.1。实践建议：计算"数据/参数比"（tokens per parameter），当该比值 > 20 时可以安全禁用 Dropout，低于 20 时应保留适量 Dropout。例如 LLaMA-3 70B 用 15T tokens 训练，比值为 214，远超安全线。
Dropout 和 Attention 中的 causal mask 有什么本质区别？
两者都在前向传播时"屏蔽"部分信息，但机制完全不同。Causal mask 是确定性的——每个位置只能看到过去的 token，mask 模式固定且推理时保持一致。Dropout 是随机的——每次前向传播使用不同的 mask，推理时完全不使用。Causal mask 的目的是维护自回归因果性（模型不能"偷看"未来），是架构设计的硬约束；Dropout 的目的是正则化（防止过拟合），是训练策略的软约束。在工程实现上，causal mask 不需要训练/推理模式切换，而 Dropout 需要。
MoE 架构中的 Expert Dropout 是什么？和传统 Dropout 有何不同？
Expert Dropout 是 MoE 架构中的一种特殊正则化策略：训练时随机禁用部分专家（Expert），迫使其他专家学习更通用的表示。与传统 Dropout 的关键差异：(1) 粒度不同——传统 Dropout 在神经元级别操作，Expert Dropout 在整个专家模块级别操作；(2) 目的不同——传统 Dropout 防过拟合，Expert Dropout 主要防止"专家坍缩"（所有 token 都路由到少数热门专家）；(3) 实现不同——Expert Dropout 需要配合负载均衡损失函数使用，否则会导致严重的路由不平衡。DeepSeek-V3 在训练中使用了 Expert Dropout 来确保 256 个专家的负载均衡。
为什么有些大模型仍然在 Embedding 层保留 Dropout？
Embedding 层保留 Dropout（通常 p=0.05~0.1）有三个特殊原因：(1) Embedding 是模型的"输入门户"，对其施加噪声直接提升模型对输入扰动的鲁棒性，这种鲁棒性无法通过深层正则化获得；(2) 许多模型使用"权重绑定"（Weight Tying）——输入 Embedding 和输出 LM Head 共享权重矩阵。Embedding Dropout 的正则化效果会同时传递到输出层，产生"双倍"效果；(3) Embedding 层的参数量相对较小（通常 < 5% 总参数），Dropout 的计算开销可忽略。综合来看，Embedding Dropout 的 ROI（收益/成本比）是所有 Dropout 位置中最高的。
Dropout 在微调阶段的最佳实践是什么？
SFT 微调阶段的 Dropout 最佳实践：(1) 分层配置——Attention Dropout = 0.1（防止注意力模式过拟合），FFN Dropout = 0.05（保留知识存储能力），Residual Dropout = 0.1（残差路径需要适度正则化）；(2) 与学习率联动——高 LR 时降低 Dropout（LR 本身有正则化效果），低 LR 时升高 Dropout；(3) 渐进式调节——微调前 50% steps 使用较高 Dropout（0.1），后 50% steps 降低至 0.05（让模型在后期精细收敛）；(4) 监控训练/验证 loss 差——当 gap > 0.5 时升高 Dropout，gap < 0.2 时降低 Dropout。LoRA 微调时通常不需要 Dropout，因为低秩约束本身就是强正则化。
2025 年有哪些新的正则化方法正在替代 Dropout？
2025 年出现的几种前沿正则化方法：(1) 数据课程学习（Data Curriculum）——按难度递增顺序呈现训练数据，初期用简单样本建立基础，后期用困难样本精细调优，效果优于静态 Dropout；(2) 谱归一化（Spectral Normalization）——限制权重矩阵的谱范数，比 Dropout 更精确地控制模型复杂度；(3) 对抗训练（Adversarial Training）——在输入中注入对抗性扰动，不仅防过拟合还提升鲁棒性；(4) 自适应温度退火——训练过程中动态调节 softmax 温度，高温阶段探索、低温阶段收敛，替代 Dropout 的随机性。这些方法的共同特点是：结构化、确定性、可控制——相比 Dropout 的随机暴力正则化更精细高效。
小模型（< 7B）在大数据上预训练，是否也应该禁用 Dropout？
取决于"数据/参数比"。以 3B 模型为例：如果用 3 万亿 tokens 训练（比值 = 1000），完全可以禁用 Dropout——数据足够多，模型来不及过拟合。但如果用 300 亿 tokens 训练（比值 = 10），应该保留 Dropout p=0.05。一个经验公式：当 tokens_per_param > 20 时可以安全禁用 Dropout；10~20 之间用 p=0.01~0.05；< 10 时用 p=0.05~0.1。另外，小模型的 FFN 层参数量占比更大（约 60-70%），FFN Dropout 的效率损失更显著，即使保留 Dropout 也应优先从 FFN 层去除。
