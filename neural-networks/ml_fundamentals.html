监督学习 vs 无监督学习 vs 半监督学习 vs 自监督学习

1.1 四种学习范式对比

范式标签要求典型算法应用场景
监督学习
Supervised		 全部有标签 线性回归、逻辑回归、SVM、决策树、神经网络 分类、回归、目标检测
无监督学习
Unsupervised		 无标签 K-Means、DBSCAN、GMM、PCA、Autoencoder 聚类、降维、异常检测
半监督学习
Semi-supervised		 少量有标签 + 大量无标签 Label Propagation、MixMatch、FixMatch、Pseudo-labeling 医疗图像、NLP 标注成本高的场景
自监督学习
Self-supervised		 自动构造标签（来自数据本身） BERT (MLM)、GPT (CLM)、SimCLR、MAE、DINO 预训练、表征学习、大模型基础

1.2 核心区别

  • 监督 vs 无监督：是否有外部标注的真实标签 (ground truth)
  • 半监督 vs 自监督：半监督仍需少量人工标签引导；自监督完全从数据自身构造监督信号（如遮盖词预测、对比学习）
  • 自监督的关键思想：设计 pretext task（前置任务），让模型从无标签数据中学到通用表征，再通过 fine-tune 迁移到下游任务
💡 知识要点
  • Q: 自监督学习和无监督学习有什么区别？
    A: 自监督学习本质上是监督学习的变体——它从数据自身构造标签（如 BERT 的 Masked LM），训练时仍有 loss 函数和梯度回传；而传统无监督学习（如 K-Means）不涉及标签概念。
  • Q: 为什么自监督学习在大模型时代如此重要？
    A: 因为互联网上的海量文本/图像天然无标签，自监督使得大规模预训练成为可能（GPT、BERT、CLIP 均基于自监督）。
02

偏差-方差权衡 (Bias-Variance Tradeoff)

其中：

2.1 概念定义

  • 偏差 (Bias)：模型预测值与真实值的期望差距，反映模型的拟合能力。高偏差 → 欠拟合
  • 方差 (Variance)：模型在不同训练集上预测值的波动程度，反映模型的稳定性。高方差 → 过拟合
  • 不可约噪声 (Irreducible Noise)：数据本身的随机噪声，无法通过模型消除

2.2 误差分解公式

E[(y − f̂(x))²] = Bias²(f̂(x)) + Var(f̂(x)) + σ²noise

其中：

  • Bias(f̂) = E[f̂(x)] − f(x) — 期望预测与真实函数的差
  • Var(f̂) = E[(f̂(x) − E[f̂(x)])²] — 预测值围绕其期望的波动

2.3 过拟合 vs 欠拟合判断

现象训练误差验证误差诊断对策
欠拟合高高高偏差增加模型复杂度、添加特征、减少正则化
过拟合低高高方差增加数据、正则化、Dropout、Early Stopping、剪枝
理想低低偏差方差均衡保持当前模型
💡 知识要点
  • Q: 如何直观理解偏差和方差？
    A: 用射击靶来类比——偏差是弹着点中心偏离靶心的距离（系统误差），方差是弹着点的分散程度（随机误差）。
  • Q: 为什么说集成方法能降低方差？
    A: Bagging 通过对多个高方差模型取平均，根据方差缩放 Var(X̄) = Var(X)/n 的原理显著降低方差。
  • Q: 神经网络的 bias-variance tradeoff 有什么特殊性？
    A: 现代深度学习存在 "double descent" 现象——当模型参数远超数据量时，测试误差反而下降，这挑战了经典的 U 型偏差-方差曲线。

正则化 (Regularization)

3.1 三种常见正则化

方法惩罚项特点适用场景
L1 (Lasso) λ Σ|wᵢ| 产生稀疏解（部分权重为 0） 特征选择，高维稀疏数据
L2 (Ridge) λ Σwᵢ² 权重趋近于 0 但不等于 0 多重共线性，防止过拟合
Elastic Net λ₁ Σ|wᵢ| + λ₂ Σwᵢ² 结合 L1 和 L2 的优点 特征多且相关性高

3.2 为什么 L1 产生稀疏解？

几何解释

L1 的约束区域是菱形（各轴交叉的尖角），等值线与菱形的交点更可能落在坐标轴上（即某些 wᵢ = 0）。L2 的约束区域是圆形，等值线与圆的切点一般不在坐标轴上。

次梯度解释

L1 在 w = 0 处不可导，其次梯度包含 0，这使得优化过程中权重可以精确到达 0。L2 的梯度 2w 在 w = 0 处为 0，权重只能趋近于 0。

L1 次梯度: ∂|w|/∂w = { −1 if w < 0 ; [−1, 1] if w = 0 ; +1 if w > 0 }

3.3 其他正则化技术

  • Dropout：训练时随机丢弃神经元，等效于训练指数级子模型的集成
  • Early Stopping：监控验证集 loss，在过拟合发生前停止训练
  • Data Augmentation：通过变换扩充数据，隐式正则化
  • Weight Decay：与 L2 正则化等价（在 SGD 下），但在 Adam 中需区分 decoupled weight decay (AdamW)
  • Batch Normalization：有轻微正则化效果（mini-batch 噪声）
💡 知识要点
  • Q: L1 和 L2 正则化的区别？
    A: L1 倾向于产生稀疏解（特征选择），L2 倾向于使权重均匀缩小。几何上 L1 是菱形约束、L2 是圆形约束。L1 在优化中需要使用近端梯度下降。
  • Q: Weight Decay 和 L2 正则化的区别？
    A: 在标准 SGD 下二者等价。但在 Adam 等自适应学习率优化器中，L2 正则化的梯度会被自适应缩放，导致效果不一致；AdamW 将 weight decay 从梯度更新中解耦，效果更好。
04

交叉验证 (Cross-Validation)

4.1 常见方法

方法做法优点缺点
K-Fold CV 数据分 K 份，依次用 1 份验证、K−1 份训练 充分利用数据，结果稳定 计算量为 K 倍
Stratified K-Fold 每折保持类别比例与原数据一致 分类问题更公平 同上
Leave-One-Out (LOO) K = N，每次留 1 个样本验证 偏差最小 方差大，计算开销极高
时间序列 CV 训练集只用过去数据，验证集只用未来数据（滑动窗口 / 扩展窗口） 尊重时间因果性 早期数据利用不充分

4.2 K 值选择

  • K = 5 或 10 是最常见的选择，兼顾偏差和方差
  • K 大（如 LOO）：低偏差、高方差，计算昂贵
  • K 小（如 2-Fold）：高偏差、低方差，计算便宜
💡 注意：交叉验证只用于模型选择和超参调优，最终模型应在全量数据上重新训练。嵌套交叉验证 (Nested CV) 可用于同时进行模型选择和性能评估，避免信息泄露。
💡 知识要点
  • Q: 时间序列数据为什么不能用普通 K-Fold？
    A: 普通 K-Fold 会导致"未来数据泄露"——用未来的数据训练、过去的数据验证，违反了时间因果性，导致评估结果过于乐观。
  • Q: 什么是嵌套交叉验证？
    A: 外层 CV 评估模型泛化性能，内层 CV 进行超参调优。避免了在同一个 CV 上既调参又评估导致的过拟合。

集成学习 (Ensemble Learning)

5.1 三大范式

方法核心思想基学习器关系代表算法
Bagging 有放回采样 + 并行训练 + 投票/平均 独立并行 Random Forest
Boosting 串行训练，每轮关注前一轮的错误 串行依赖 AdaBoost, GBDT, XGBoost, LightGBM
Stacking 用元学习器组合多个异构基学习器的预测 异构组合 多种基模型 + 逻辑回归/线性模型

5.2 Random Forest

  • Bagging + 随机特征子集选择（通常选 √p 个特征）
  • 降低树之间的相关性，进一步降低方差
  • 支持 OOB (Out-of-Bag) 估计，无需额外验证集
  • 天然支持特征重要性评估

5.3 GBDT / XGBoost / LightGBM 对比

特性GBDTXGBoostLightGBM
分裂策略 贪心逐层 (level-wise) 贪心逐层 + 近似算法 叶子优先 (leaf-wise)
正则化 无显式正则 L1 + L2 正则 + 树复杂度惩罚 同 XGBoost
缺失值 需预处理 内置处理（学习最优方向） 内置处理
速度 较慢 中等（支持并行 + 缓存优化） 最快（直方图加速 + GOSS + EFB）
类别特征 需编码 需编码 原生支持

5.4 AdaBoost

  • 每轮根据分类错误率更新样本权重：被错分的样本权重增大
  • 每个弱学习器有一个投票权重 αₜ = ½ ln((1 − εₜ) / εₜ)
  • 最终预测: H(x) = sign(Σ αₜ hₜ(x))
  • 可以证明训练误差指数下降（在弱学习器比随机猜好的前提下）
💡 知识要点
  • Q: Bagging 和 Boosting 的核心区别？
    A: Bagging 降低方差（并行 + 平均），Boosting 降低偏差（串行 + 聚焦错误）。Bagging 适合高方差模型（如深树），Boosting 适合高偏差模型（如浅树/弱学习器）。
  • Q: XGBoost 相比 GBDT 有什么改进？
    A: ① 二阶泰勒展开（用到 Hessian 信息）② 正则化（树复杂度惩罚）③ 列采样 ④ 缺失值处理 ⑤ 并行化特征分裂 ⑥ Shrinkage（学习率缩减）。
  • Q: LightGBM 为什么更快？
    A: ① leaf-wise 生长策略（精度高但需控制深度防过拟合）② 直方图算法减少分裂计算 ③ GOSS 只保留梯度大的样本 ④ EFB 合并互斥特征。

决策树

其中 H(D) = −Σ pₖ log₂ pₖ 是信息熵

6.1 分裂准则

信息增益 (Information Gain) — ID3

IG(D, A) = H(D) − Σ (|Dᵥ|/|D|) × H(Dᵥ)

其中 H(D) = −Σ pₖ log₂ pₖ 是信息熵。缺点：偏向取值多的特征。

增益率 (Gain Ratio) — C4.5

GR(D, A) = IG(D, A) / IV(A) ，其中 IV(A) = −Σ (|Dᵥ|/|D|) log₂(|Dᵥ|/|D|)

IV(A) 为固有值 (Intrinsic Value)。增益率对取值少的特征有偏好，C4.5 先选信息增益高于平均的特征，再从中选增益率最大的。

基尼系数 (Gini Index) — CART

Gini(D) = 1 − Σ pₖ²

CART 使用二叉树，选择使加权基尼系数最小的分裂点。基尼系数计算比信息熵更快（无需对数运算）。

6.2 剪枝策略

策略做法特点
预剪枝 (Pre-pruning) 生成树的过程中提前停止（限制深度、叶子最小样本数、信息增益阈值） 速度快，但可能欠拟合（贪心决策可能错过后续好的分裂）
后剪枝 (Post-pruning) 先生成完整树，再自底向上评估是否合并（CCP — Cost Complexity Pruning） 效果更好，但计算开销大

6.3 CART 算法

  • 分类树用基尼系数，回归树用均方误差 (MSE)
  • 始终生成二叉树（每次选择一个特征的一个分裂点）
  • 回归树的分裂：选择使左右子树 MSE 之和最小的分裂点
💡 知识要点
  • Q: ID3、C4.5、CART 的区别？
    A: ID3 用信息增益（偏向多值特征），C4.5 用增益率修正（且支持连续值和缺失值），CART 用基尼系数（二叉树，支持分类和回归）。
  • Q: 预剪枝和后剪枝哪个更好？
    A: 后剪枝通常更好（避免贪心导致的欠拟合），但实际工程中常结合使用，或直接使用集成方法（如随机森林）来替代手动剪枝。
07

支持向量机 (SVM)

SVM 寻找能正确分类所有样本且 几何间隔最大 的超平面：

7.1 最大间隔分类器

SVM 寻找能正确分类所有样本且几何间隔最大的超平面：

minw,b ½ ‖w‖²    s.t. yᵢ(w·xᵢ + b) ≥ 1, ∀i

间隔 margin = 2/‖w‖，最大化间隔等价于最小化 ‖w‖²。

7.2 软间隔 (Soft Margin)

引入松弛变量 ξᵢ ≥ 0，允许部分样本违反间隔约束：

minw,b,ξ ½ ‖w‖² + C Σ ξᵢ    s.t. yᵢ(w·xᵢ + b) ≥ 1 − ξᵢ

C 控制惩罚力度：C 大 → 少容忍错分（复杂边界）；C 小 → 多容忍错分（简单边界）。

7.3 核函数 (Kernel)

核函数公式特点
线性核 K(x,z) = x·z 线性可分场景，速度快
RBF (高斯核) K(x,z) = exp(−γ‖x−z‖²) 最常用，隐式映射到无穷维空间。γ 大 → 复杂边界
多项式核 K(x,z) = (x·z + c)ᵈ 可控复杂度（d 阶交叉特征）
💡 核技巧 (Kernel Trick) 的本质：在对偶形式中，优化和预测只涉及内积 x·z。核函数 K(x,z) = φ(x)·φ(z) 直接计算高维空间的内积，避免显式计算映射 φ(x)，从而实现"低维计算、高维分类"。

7.4 SMO 算法思想

  • 将大规模 QP 问题分解为一系列最小子问题（每次只优化两个 αᵢ）
  • 选择违反 KKT 条件最严重的两个变量进行优化
  • 两变量优化有解析解，无需数值求解器
  • 重复迭代直到所有变量满足 KKT 条件
💡 知识要点
  • Q: SVM 的对偶问题有什么好处？
    A: ① 对偶问题约束更简单 ② 引入核函数成为可能（只需计算内积）③ 当特征维度 > 样本量时更高效。
  • Q: RBF 核的 γ 和 C 如何调？
    A: γ 大 → 每个支持向量影响范围小 → 复杂边界（易过拟合）；C 大 → 惩罚误分强 → 复杂边界。通常用网格搜索 + 交叉验证联合调优。
  • Q: SVM 的缺点？
    A: ① 大规模数据训练慢（O(n²)~O(n³)）② 对特征缩放敏感 ③ 多分类需要 OvO/OvR 策略 ④ 核函数选择需要经验。
08

评估指标

8.1 二分类指标

指标公式含义
Accuracy (TP+TN)/(TP+TN+FP+FN) 整体正确率（类别不平衡时不可靠）
Precision TP/(TP+FP) 预测为正的样本中有多少真正为正（查准率）
Recall TP/(TP+FN) 所有真正为正的样本中有多少被预测为正（查全率）
F1 Score 2 × P × R / (P + R) Precision 和 Recall 的调和平均
AUC-ROC ROC 曲线下面积 衡量模型在所有阈值下的排序能力（概率意义：随机正样本 score > 随机负样本的概率）
PR Curve Precision vs Recall 曲线 类别不平衡时比 ROC 更有区分度
Log Loss −(1/N) Σ [yᵢ log(pᵢ) + (1−yᵢ) log(1−pᵢ)] 衡量预测概率的校准程度

8.2 ROC vs PR 曲线

  • ROC 曲线：FPR (x轴) vs TPR (y轴)。在类别平衡时表现好；类别不平衡时 FPR 分母大（TN 多），AUC 可能虚高
  • PR 曲线：Recall (x轴) vs Precision (y轴)。在类别不平衡时（如欺诈检测、疾病筛查）更能反映模型真实性能

8.3 多分类指标

平均方式做法适用场景
Macro 每个类别单独算指标，取算术平均 各类别同等重要
Micro 全局 TP/FP/FN 汇总后计算 关注整体性能（等同于 Accuracy）
Weighted 每个类别指标按样本数加权平均 类别不平衡时兼顾大类性能
💡 知识要点
  • Q: 什么时候用 AUC-ROC，什么时候用 PR AUC？
    A: 类别平衡时用 AUC-ROC；类别严重不平衡（正样本极少）时用 PR AUC，因为 ROC 中大量 TN 会掩盖 FP 的影响。
  • Q: AUC 的概率解释是什么？
    A: AUC = P(score(正样本) > score(负样本))，即随机取一对正负样本，模型给正样本打分更高的概率。AUC = 0.5 等同于随机猜。
  • Q: F1 和 Accuracy 的选择？
    A: 类别平衡时 Accuracy 直观有效；类别不平衡时 F1 更有意义（如正类占 1%，全预测为负也有 99% Accuracy）。
09

类别不平衡

γ = 0 时退化为标准交叉熵

9.1 数据层面方法

方法做法优缺点
随机过采样 复制少数类样本 简单但易过拟合
SMOTE 在少数类样本间插值生成新样本：xnew = xᵢ + λ(xⱼ − xᵢ)，λ ∈ [0,1] 缓解过拟合，但可能引入噪声（Borderline-SMOTE 改进）
随机欠采样 丢弃多数类样本 速度快但丢失信息
Tomek Links / ENN 清理边界噪声样本 常与其他方法组合使用

9.2 算法层面方法

  • 代价敏感学习：给少数类更高的误分代价，等价于调整 class_weight
  • Focal Loss：FL(pₜ) = −αₜ(1 − pₜ)ᵞ log(pₜ)，通过 (1 − pₜ)ᵞ 降低简单样本的 loss 权重，聚焦难分样本
  • 阈值调整：不改变模型，调整分类阈值（如从 0.5 降到 0.3）
Focal Loss: FL(pₜ) = −αₜ (1 − pₜ)γ log(pₜ)

γ = 0 时退化为标准交叉熵。γ = 2 是常用值。αₜ 平衡正负样本权重。

9.3 评估层面

  • 不平衡数据上避免只看 Accuracy
  • 使用 F1、PR AUC、MCC (Matthews Correlation Coefficient) 等指标
  • 使用 Stratified K-Fold 确保每折的类别比例一致
💡 知识要点
  • Q: SMOTE 的原理是什么？有什么改进？
    A: SMOTE 对每个少数类样本，找 K 近邻中随机选一个，在两者连线上随机插值生成新样本。改进包括 Borderline-SMOTE（只在边界附近生成）、ADASYN（根据局部密度自适应生成数量）。
  • Q: Focal Loss 解决了什么问题？
    A: 解决了目标检测中大量简单负样本主导 loss 的问题。通过 (1−pₜ)ᵞ 因子，让模型聚焦于难分样本。最初在 RetinaNet 论文提出。

10.2 PCA (主成分分析)

原理

  1. 对数据中心化（减去均值）
  2. 计算协方差矩阵 C = (1/n) XTX
  3. 对 C 做特征值分解，得到特征值 λ₁ ≥ λ₂ ≥ ... 和对应的特征向量
  4. 取前 k 个特征向量组成投影矩阵 Wk
  5. 降维后数据 Z = X Wk

方差保留比例

保留方差比 = Σᵢ₌₁ᵏ λᵢ / Σᵢ₌₁ᵈ λᵢ

通常选择保留 95% 方差对应的 k 值。

关键性质

  • PCA 等价于对数据做 SVD 分解：X = UΣVT
  • PCA 是线性降维方法，假设数据的主要变化方向是线性的
  • PCA 对特征尺度敏感，需要先做标准化

💡 知识要点
  • Q: PCA 和 LDA 的区别？
    A: PCA 是无监督降维，最大化方差（数据分散度）；LDA 是有监督降维，最大化类间距离 / 类内距离。PCA 保留主要变化方向，LDA 保留最具区分力的方向。
  • Q: t-SNE 的结果可以用于下游分类吗？
    A: 不推荐。t-SNE 主要用于可视化，其嵌入不保距、不可复现（非凸优化）、不支持新样本映射。降维后做分类建议用 PCA 或 UMAP。
  • Q: PCA 为什么要先标准化？
    A: PCA 基于方差/协方差，特征量纲不同会导致方差大的特征主导主成分。标准化使每个特征方差为 1，消除量纲影响。

📋 Q&A

偏差反映模型的拟合能力不足（欠拟合），方差反映模型对训练数据过度敏感（过拟合）
解释偏差-方差权衡，以及如何在实践中平衡？

偏差反映模型的拟合能力不足（欠拟合），方差反映模型对训练数据过度敏感（过拟合）。总误差 = 偏差² + 方差 + 噪声。实践中通过以下方式平衡：增加模型复杂度降低偏差（更多层/特征），增加正则化/数据降低方差。集成方法是最有效的平衡手段——Bagging 降低方差，Boosting 降低偏差。现代深度学习中的 double descent 现象表明，在过参数化区间，增加参数可以同时降低偏差和方差。

L1 正则化为什么能产生稀疏解？请从几何和优化两个角度解释。

几何角度：L1 的约束区域是菱形（超八面体），其尖角位于坐标轴上。损失函数的等值线与菱形相切时，切点大概率落在尖角处，对应某些权重恰好为 0。L2 的约束区域是圆（超球体），切点一般不在坐标轴上。优化角度：L1 在 w=0 处不可导，次梯度包含 0。当数据梯度的绝对值小于正则化系数 λ 时，最优解恰好是 w=0（近端算子的 soft-thresholding 效果）。

Random Forest 和 GBDT 各自的优缺点是什么？如何选择？

Random Forest：Bagging + 随机特征。优点：不易过拟合、可并行、对异常值鲁棒、有 OOB 估计。缺点：精度可能不如 Boosting、模型较大。GBDT：串行 Boosting。优点：精度高（关注残差/梯度）、可处理多种损失函数。缺点：易过拟合（需仔细调参）、训练慢（串行）、对异常值敏感。选择：数据噪声大、不想调参 → RF；追求最高精度且愿意调参 → XGBoost/LightGBM；实时性要求高 → LightGBM。

SVM 中核函数的作用是什么？如何选择核函数？

核函数实现了"核技巧"——在不显式计算高维映射的前提下，直接计算高维空间的内积。这使 SVM 可以学习非线性边界，计算复杂度只依赖样本数而非映射后的维度。选择策略：① 先试线性核（特征多、样本少时常够用）② 非线性数据用 RBF 核（最通用，只有一个超参 γ）③ 先验知识表明需要多项式交叉特征时用多项式核。RBF 的 γ 和 C 通常用网格搜索 + 交叉验证联合调优。

处理类别不平衡数据有哪些方法？各有什么优缺点？

数据层面：过采样（SMOTE，避免简单复制导致过拟合）、欠采样（快但丢信息，可结合 EasyEnsemble 多次采样）。算法层面：调整 class_weight 做代价敏感学习；使用 Focal Loss 聚焦难分样本。评估层面：避免用 Accuracy，改用 F1/PR AUC/MCC；使用 Stratified CV。其他：阈值调优（根据 PR 曲线选最优阈值）、异常检测范式（极端不平衡时把少数类当异常）。实践建议：先试 class_weight 调整（最简单），再试 SMOTE + 欠采样组合。

解释 AUC-ROC 的含义。AUC = 0.5 和 AUC = 1 分别代表什么？

AUC 是 ROC 曲线（TPR vs FPR）下的面积。概率解释：随机取一个正样本和一个负样本，模型给正样本的预测分数高于负样本的概率。AUC = 0.5 表示模型的排序能力等同于随机猜测（ROC 为对角线）；AUC = 1.0 表示模型能完美将所有正负样本分开（存在一个阈值使 TPR=1 且 FPR=0）。AUC 的优点是阈值无关，衡量模型的排序/区分能力而非在某个特定阈值的表现。在类别极端不平衡时，PR AUC 比 ROC AUC 更有意义。

PCA 的原理是什么？与 SVD 有什么关系？

PCA 寻找数据方差最大的正交方向作为主成分。步骤：中心化 → 计算协方差矩阵 → 特征值分解 → 取前 k 个特征向量。与 SVD 的关系：对中心化数据 X 做 SVD 得 X = UΣVT，则协方差矩阵 C = XTX/(n−1) = V(Σ²/(n−1))VT。V 的列就是主成分方向，Σ² 对应特征值。实践中直接用 SVD 分解 X 更数值稳定、更高效（避免计算协方差矩阵）。

XGBoost 相比传统 GBDT 有哪些关键改进？

① 目标函数加入正则化项（叶子数 + L2 权重惩罚），控制树复杂度；② 二阶泰勒展开近似目标函数，同时利用梯度和 Hessian 信息，分裂更精确；③ 列采样（column subsampling），类似随机森林，减少过拟合并加速；④ 内置缺失值处理，学习缺失值的最优分裂方向；⑤ 加权分位数近似算法，高效处理连续特征分裂；⑥ Shrinkage（学习率缩减），每棵树的贡献乘以 η，增加集成的正则效果；⑦ 工程优化：cache-aware 访问、分块并行、out-of-core 计算。

交叉验证的目的是什么？K 值如何选择？

目的：利用有限数据可靠地估计模型泛化性能，用于模型选择和超参调优。K 的选择是偏差-方差的权衡：K 大（如 LOO）→ 训练集更大 → 偏差小，但各折训练集高度重叠 → 方差大且计算昂贵。K 小（如 2-Fold）→ 训练集小 → 偏差大但方差小。经验法则：K=5 或 K=10 在大多数场景表现良好。小数据集可用 LOO 或重复 K-Fold。时间序列必须使用前向验证（时序分裂）。最终模型应在全量数据上重新训练。

Bagging 和 Boosting 分别降低了什么？为什么？

Bagging 降低方差：通过 Bootstrap 采样生成多个训练集，独立训练多个模型后取平均/投票。根据方差缩放定理 Var(X̄) ≈ ρσ² + (1−ρ)σ²/n（ρ 为模型间相关性），平均可降低方差，随机森林通过随机特征子集进一步降低 ρ。Boosting 降低偏差：串行训练，每轮聚焦前一轮的错误（残差/权重提升），逐步降低训练误差。弱学习器（如深度为 1 的树）本身高偏差，通过 Boosting 组合成强学习器。注意：Boosting 也可能增加方差（过拟合风险），需通过 Shrinkage、Subsampling 控制。
