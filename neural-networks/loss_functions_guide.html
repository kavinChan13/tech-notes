📐 一、损失函数的作用

损失函数（Loss Function）将模型预测与真实标签之间的差异量化为一个 标量值 ，为…

1.1 为什么需要损失函数

损失函数（Loss Function）将模型预测与真实标签之间的差异量化为一个标量值，为优化器提供明确的优化方向。没有损失函数，模型无法通过梯度下降进行学习。

  • 衡量标准：定义"好"与"差"的数学度量
  • 梯度信号源：反向传播的起点，\(\nabla_\theta \mathcal{L}\) 驱动参数更新
  • 隐含先验：不同损失函数隐含不同的噪声假设和鲁棒性偏好

1.2 损失函数与优化目标

我们在训练集上最小化的是经验风险（Empirical Risk）：

$$R_{\text{emp}}(\theta) = \frac{1}{N}\sum_{i=1}^{N} \mathcal{L}(f_\theta(x_i),\, y_i)$$

但真正关心的是期望风险（Expected Risk）：

$$R(\theta) = \mathbb{E}_{(x,y)\sim p_{\text{data}}} [\mathcal{L}(f_\theta(x),\, y)]$$

1.3 经验风险 vs 结构风险

概念公式含义
经验风险最小化 (ERM) \(\min_\theta R_{\text{emp}}(\theta)\) 仅优化训练损失，可能过拟合
结构风险最小化 (SRM) \(\min_\theta R_{\text{emp}}(\theta) + \lambda \Omega(\theta)\) 加入正则项 \(\Omega(\theta)\)（如 L2 范数），平衡拟合与复杂度
  • 损失函数 ≠ 评估指标：损失函数需可微（训练用），评估指标不一定可微（如 Accuracy、F1）
  • MSE 隐含高斯噪声假设，交叉熵隐含伯努利/多项式分布假设 — 本质是 MLE
  • 正则化项可看作贝叶斯先验：L2 ↔ 高斯先验，L1 ↔ 拉普拉斯先验

2.1 MSE — Mean Squared Error (L2 Loss)

$$\mathcal{L}_{\text{MSE}} = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2$$

梯度：\(\frac{\partial \mathcal{L}}{\partial \hat{y}_i} = -\frac{2}{N}(y_i - \hat{y}_i)\)，误差越大梯度越大。

概率解释：在高斯噪声 \(y = f(x) + \epsilon,\ \epsilon \sim \mathcal{N}(0,\sigma^2)\) 假设下，最大化似然等价于最小化 MSE。

特点：对异常值敏感（平方放大大误差）；处处可微。

2.2 MAE — Mean Absolute Error (L1 Loss)

$$\mathcal{L}_{\text{MAE}} = \frac{1}{N}\sum_{i=1}^{N}|y_i - \hat{y}_i|$$

梯度：\(\frac{\partial \mathcal{L}}{\partial \hat{y}_i} = -\frac{1}{N}\text{sign}(y_i - \hat{y}_i)\)，梯度恒为 ±1/N，不受误差大小影响。

概率解释：对应拉普拉斯噪声假设，预测中位数而非均值。

特点：对异常值鲁棒；在零点不可微；收敛速度较 MSE 慢。

2.3 Huber Loss / Smooth L1 Loss

$$\mathcal{L}_{\text{Huber}}(\delta) = \begin{cases} \frac{1}{2}(y - \hat{y})^2 & \text{if } |y - \hat{y}| \le \delta \\ \delta\,|y - \hat{y}| - \frac{1}{2}\delta^2 & \text{otherwise} \end{cases}$$

当 \(\delta = 1\) 时即为目标检测中常用的 Smooth L1 Loss。小误差区域类似 MSE（处处可微），大误差区域类似 MAE（线性增长，抗异常值）。

2.4 RMSE

$$\mathcal{L}_{\text{RMSE}} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}$$

RMSE 与原始数据同量纲，便于直观解释。通常用作评估指标而非直接作为训练损失（因梯度含 \(1/\sqrt{\text{MSE}}\) 项，早期梯度可能极大）。

回归损失对比

损失函数对异常值可微性收敛速度典型场景
MSE敏感处处可微快回归基线、高斯噪声
MAE鲁棒零点不可微较慢含异常值数据
Huber可控 (δ)处处可微中等目标检测 bbox 回归
RMSE敏感零点附近不稳定—评估指标
  • MSE 对异常值敏感因为平方放大大误差；MAE 梯度恒定所以鲁棒
  • Huber Loss 的 δ 是关键超参：δ→∞ 退化为 MSE，δ→0 退化为 MAE
  • Smooth L1 = Huber(δ=1)，是 Faster R-CNN 默认回归损失
  • MSE 隐含高斯噪声假设 → 预测均值；MAE 隐含拉普拉斯假设 → 预测中位数

🏷️ 三、分类损失

其中 \(\hat{p}_i = \sigma(z_i)\) 是 Sigmoid 输出

3.1 二元交叉熵 (BCE — Binary Cross-Entropy)

$$\mathcal{L}_{\text{BCE}} = -\frac{1}{N}\sum_{i=1}^{N}\Big[y_i \log(\hat{p}_i) + (1 - y_i)\log(1 - \hat{p}_i)\Big]$$

其中 \(\hat{p}_i = \sigma(z_i)\) 是 Sigmoid 输出。

3.2 多分类交叉熵 (CE — Cross-Entropy)

$$\mathcal{L}_{\text{CE}} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{c=1}^{C} y_{i,c}\log(\hat{p}_{i,c})$$

当 \(y\) 为 one-hot 编码时简化为：

$$\mathcal{L}_{\text{CE}} = -\frac{1}{N}\sum_{i=1}^{N}\log(\hat{p}_{i,y_i})$$

3.3 从 MLE 角度推导交叉熵

假设样本独立，模型输出 \(p_\theta(y|x)\)，最大化对数似然：

$$\max_\theta \sum_{i=1}^{N} \log p_\theta(y_i | x_i)$$

取负号变最小化问题，即为交叉熵：

$$\min_\theta -\sum_{i=1}^{N} \log p_\theta(y_i | x_i) = \min_\theta\ N \cdot \mathcal{L}_{\text{CE}}$$

因此 最小化交叉熵 ≡ 最大化似然估计 ≡ 最小化 KL 散度 \(D_{\text{KL}}(p_{\text{data}} \| p_\theta)\)。

3.4 Softmax + CE 的梯度推导

设 logits 为 \(z_j\)，Softmax 输出 \(\hat{p}_j = \frac{e^{z_j}}{\sum_k e^{z_k}}\)，损失 \(\mathcal{L} = -\log \hat{p}_y\)。

推导过程：

$$\frac{\partial \mathcal{L}}{\partial z_j} = \frac{\partial (-\log \hat{p}_y)}{\partial z_j} = -\frac{1}{\hat{p}_y}\cdot\frac{\partial \hat{p}_y}{\partial z_j}$$

利用 Softmax 的导数性质：

$$\frac{\partial \hat{p}_y}{\partial z_j} = \begin{cases} \hat{p}_y(1 - \hat{p}_y) & j = y \\ -\hat{p}_y \hat{p}_j & j \neq y \end{cases}$$

代入得到极其简洁的结果：

$$\boxed{\frac{\partial \mathcal{L}}{\partial z_j} = \hat{p}_j - \mathbb{1}[j = y]}$$

含义：梯度 = 预测概率 - 真实标签（one-hot），实现简单、数值稳定。这是 Softmax + CE 被广泛采用的核心原因。

3.5 Hinge Loss (SVM)

$$\mathcal{L}_{\text{Hinge}} = \max(0,\; 1 - y \cdot \hat{y})$$

其中 \(y \in \{-1, +1\}\)。当预测正确且 margin ≥ 1 时损失为 0。SVM 的目标是最大化分类间隔。

多分类扩展：\(\mathcal{L} = \sum_{j \neq y_i} \max(0,\; s_j - s_{y_i} + \Delta)\)

  • 交叉熵的三重等价：最小化 CE = 最大化似然 = 最小化 KL 散度
  • Softmax + CE 梯度 = \(\hat{p} - y\)，极简且数值稳定；PyTorch 使用 log-sum-exp 技巧避免溢出
  • BCE 用于多标签分类（每个类独立 Sigmoid），CE 用于互斥多分类（Softmax）
  • Hinge Loss 只关心 margin，不提供概率校准；CE 提供概率输出

⚖️ 四、类别不平衡损失

为少数类赋予更大权重 \(w_c\)，常设 \(w_c \propto 1/n_c\) 或…

4.1 Weighted Cross-Entropy

$$\mathcal{L}_{\text{WCE}} = -\sum_{c=1}^{C} w_c \cdot y_c \log(\hat{p}_c)$$

为少数类赋予更大权重 \(w_c\)，常设 \(w_c \propto 1/n_c\) 或 \(w_c \propto 1/\sqrt{n_c}\)。

4.2 Focal Loss

由 Lin et al., 2017 (RetinaNet) 提出，解决目标检测中前景/背景极端不平衡问题。

公式推导

标准 CE 对于样本 \(i\)（令 \(p_t\) 为真实类的预测概率）：

$$\text{CE}(p_t) = -\log(p_t)$$

Focal Loss 添加调制因子 \((1-p_t)^\gamma\)：

$$\boxed{\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)}$$

其中 \(p_t = \begin{cases} \hat{p} & y=1 \\ 1-\hat{p} & y=0 \end{cases}\)，\(\alpha_t\) 为类别平衡因子。

γ 参数的作用

场景\(p_t\) 值调制因子 \((1-p_t)^\gamma\)效果
易分类样本高 (如 0.9)\(0.1^\gamma\) → 极小损失被大幅降低 ↓
难分类样本低 (如 0.2)\(0.8^\gamma\) → 接近1损失几乎不变 →

γ = 0 退化为标准 CE；γ = 2 是论文推荐值，使模型聚焦于困难样本。

RetinaNet 背景

One-stage 检测器（如 RetinaNet）因 anchor 密集，负样本（背景）占绝对多数。Focal Loss 让简单负样本对总损失贡献极小，使模型专注于学习困难正样本。这使 RetinaNet 首次在精度上超越 two-stage 检测器。

4.3 Dice Loss

$$\mathcal{L}_{\text{Dice}} = 1 - \frac{2\sum_i p_i g_i + \epsilon}{\sum_i p_i + \sum_i g_i + \epsilon}$$

源自 Dice 系数（F1 Score 的连续近似）。直接优化前景/背景的重叠度，对类别不平衡天然鲁棒。广泛用于医学图像分割。

4.4 Class-Balanced Loss

$$\mathcal{L}_{\text{CB}} = \frac{1 - \beta}{1 - \beta^{n_c}} \cdot \mathcal{L}_{\text{base}}$$

Cui et al., 2019 提出"有效样本数"概念，\(\beta \in [0,1)\) 控制重加权强度。\(\beta\to 0\) 时无重加权，\(\beta\to 1\) 时等价于逆频率加权。

  • Focal Loss 核心思想：降低易分类样本权重，让模型聚焦困难样本
  • γ 越大，对易分类样本的抑制越强；实践中 γ=2, α=0.25 效果最佳
  • Dice Loss 直接优化分割指标，不受类别比例影响，但梯度可能不稳定（分母含预测值）
  • 实际工程常组合使用：CE + Dice 兼顾稳定性和分割质量

🔗 五、对比学习损失

其中 \(d_i = \|f(x_i^a) - f(x_i^b)\|_2\)，\(y_i=1…

5.1 Contrastive Loss

$$\mathcal{L} = \frac{1}{2N}\sum_{i=1}^{N}\Big[y_i \cdot d_i^2 + (1-y_i)\cdot\max(0,\; m - d_i)^2\Big]$$

其中 \(d_i = \|f(x_i^a) - f(x_i^b)\|_2\)，\(y_i=1\) 表示同类，\(m\) 为 margin。正对拉近，负对推开至距离 ≥ m。

5.2 Triplet Loss

$$\mathcal{L}_{\text{Triplet}} = \max\Big(0,\; \|f(a) - f(p)\|_2^2 - \|f(a) - f(n)\|_2^2 + m\Big)$$

三元组 (anchor, positive, negative)：要求 anchor 到 positive 的距离比到 negative 的距离至少小 margin \(m\)。

Margin 的作用

margin \(m\) 定义类间最小距离间隔。太小 → 特征空间不够分离；太大 → 训练困难、不收敛。

Hard Negative Mining

随机采样的三元组中，大部分负样本已满足 margin 约束（loss=0），训练信号弱。解决方案：

  • Batch Hard：每个 batch 内对每个 anchor 选最难的正例和负例
  • Semi-Hard：选满足 \(\|a-p\| < \|a-n\| < \|a-p\| + m\) 的负例（FaceNet 策略）
  • 离线挖掘：周期性在全数据集上找最难三元组

5.3 InfoNCE

Contrastive Predictive Coding (CPC, van den Oord et al., 2018) 提出。

推导

给定 query \(q\)、一个正样本 \(k^+\) 和 \(K\) 个负样本 \(\{k^-_j\}\)，定义：

$$\mathcal{L}_{\text{InfoNCE}} = -\log \frac{\exp(q \cdot k^+ / \tau)}{\exp(q \cdot k^+ / \tau) + \sum_{j=1}^{K}\exp(q \cdot k^-_j / \tau)}$$

这是一个 (K+1)-way softmax 分类问题：将正样本识别出来。

信息论联系：InfoNCE 是互信息 \(I(q; k^+)\) 的下界：

$$I(q;\,k^+) \ge \log(K+1) - \mathcal{L}_{\text{InfoNCE}}$$

温度参数 τ 的影响

τ 大小分布特征效果
τ → 0趋近 one-hot（argmax）强调最难负样本，训练不稳定
τ → ∞趋近均匀分布所有负样本同等对待，区分度低
τ ≈ 0.07–0.1适度尖锐常用实践值，平衡难度与稳定性

5.4 NT-Xent (SimCLR)

$$\mathcal{L}_{i,j} = -\log\frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N}\mathbb{1}_{[k \neq i]}\exp(\text{sim}(z_i, z_k)/\tau)}$$

其中 \(\text{sim}(u,v) = \frac{u^\top v}{\|u\|\|v\|}\) 为余弦相似度。

NT-Xent 本质上是 InfoNCE 的对称版本：对 batch 中 \(2N\) 个样本（每个样本两个增强视图），每对正样本 \((i,j)\) 和 \((j,i)\) 都计算损失，\(2(N-1)\) 个负样本来自同 batch 其他样本。

  • Contrastive Loss 是成对的，Triplet Loss 是三元组的，InfoNCE 是1-vs-K的
  • τ 控制分布锐度：太小导致训练崩溃，太大丧失区分力；SimCLR 用 τ=0.5，MoCo 用 τ=0.07
  • Hard Negative Mining 是 Triplet Loss 能否训练成功的关键
  • InfoNCE 负样本数 K 越大 → 互信息下界越紧 → 效果越好，所以 MoCo 用队列扩大 K

📎 六、CLIP Loss

CLIP（Radford et al

6.1 对称交叉熵

CLIP（Radford et al., 2021）将图像和文本编码到共享空间，对一个 batch 的 \(N\) 个图文对构造 \(N \times N\) 的相似度矩阵。

$$S_{ij} = \frac{f_{\text{img}}(I_i)^\top f_{\text{txt}}(T_j)}{\tau}$$

损失为行方向（image→text）和列方向（text→image）交叉熵的平均：

$$\mathcal{L}_{\text{CLIP}} = \frac{1}{2}\Big[\underbrace{\mathcal{L}_{\text{i2t}}}_{\text{Image→Text CE}} + \underbrace{\mathcal{L}_{\text{t2i}}}_{\text{Text→Image CE}}\Big]$$

其中：

$$\mathcal{L}_{\text{i2t}} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(S_{ii})}{\sum_{j=1}^{N}\exp(S_{ij})}$$ $$\mathcal{L}_{\text{t2i}} = -\frac{1}{N}\sum_{j=1}^{N}\log\frac{\exp(S_{jj})}{\sum_{i=1}^{N}\exp(S_{ij})}$$

6.2 矩阵形式理解

目标：让相似度矩阵 \(S\) 的对角线元素（匹配对）最大化，其余元素最小化。等价于让 \(S\) 的每一行和每一列都趋向 one-hot 分布（匹配位置概率为1）。

Label 矩阵就是单位矩阵 \(I_N\)，分别对行和列做 softmax + CE。

  • CLIP Loss = 双向 InfoNCE，图→文 和 文→图 对称
  • Batch 内其他 \(N-1\) 个非匹配对作为负样本 → batch size 越大效果越好（CLIP 用 32768）
  • 温度 τ 是可学习参数（初始化 0.07），控制分布锐度
  • 与 SimCLR 的区别：CLIP 是跨模态对比，SimCLR 是同模态对比

🎓 七、知识蒸馏损失

KL 散度衡量分布 \(Q\) 对分布 \(P\) 的近似程度

7.1 KL 散度

$$D_{\text{KL}}(P \| Q) = \sum_{c=1}^{C} P(c)\log\frac{P(c)}{Q(c)}$$

KL 散度衡量分布 \(Q\) 对分布 \(P\) 的近似程度。非对称：\(D_{\text{KL}}(P\|Q) \neq D_{\text{KL}}(Q\|P)\)。

7.2 软标签与温度参数 T

Teacher 和 Student 的 logits 经过温度缩放后的 Softmax：

$$p_i^{(T)} = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

T 的作用：

  • \(T = 1\)：标准 Softmax，分布尖锐
  • \(T > 1\)：分布变平滑，暴露类间相似性的"暗知识"（dark knowledge）
  • T 越大，非真实类的概率差异越明显（如"猫"被误判为"虎" > "汽车"的信息被保留）

7.3 蒸馏损失公式

$$\boxed{\mathcal{L}_{\text{KD}} = \alpha \cdot T^2 \cdot D_{\text{KL}}\big(p^{(T)}_{\text{teacher}} \;\|\; p^{(T)}_{\text{student}}\big) + (1 - \alpha) \cdot \mathcal{L}_{\text{CE}}(y,\; p^{(1)}_{\text{student}})}$$

两部分：

  1. Distillation Loss：Student 的软标签分布 → Teacher 的软标签分布（KL 散度），乘以 \(T^2\) 补偿温度缩放导致的梯度缩小
  2. Student Loss：Student 对真实标签的标准 CE

超参 \(\alpha\) 平衡两者，\(T\) 通常取 3~20。

为什么乘 \(T^2\)？

当 \(T\) 较大时，softmax 输出的梯度量级约为 \(1/T^2\)，乘以 \(T^2\) 可使蒸馏损失的梯度与 Student Loss 保持可比较的量级。

  • 蒸馏的核心是暗知识：Teacher 对非正确类的概率分布包含类间关系信息
  • \(T^2\) 的作用是梯度补偿，不是经验 trick
  • KL 散度非对称：蒸馏中是 \(D_{\text{KL}}(P_T \| P_S)\)，Teacher 在前（固定），Student 在后（优化）
  • 现代蒸馏方法还包含特征蒸馏、注意力蒸馏等，但 logit 蒸馏仍是基础
08

🎨 八、生成模型损失

判别器 D 最大化区分真假，生成器 G 最小化被识别为假的概率

8.1 GAN Loss

原始 GAN (Vanilla GAN)

$$\min_G \max_D\; \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

判别器 D 最大化区分真假，生成器 G 最小化被识别为假的概率。最优 D 下，G 最小化 \(2\,\text{JSD}(p_{\text{data}} \| p_G) - \log 4\)。

问题：训练不稳定、模式崩塌、梯度消失（D 太强时 G 梯度趋零）。

WGAN (Wasserstein GAN)

$$\min_G \max_{D \in \mathcal{D}_{\text{1-Lip}}} \;\mathbb{E}_{x \sim p_{\text{data}}}[D(x)] - \mathbb{E}_{z \sim p_z}[D(G(z))]$$

用 Wasserstein-1 距离替代 JS 散度。D 需满足 1-Lipschitz 约束（原始 WGAN 用 weight clipping）。

优势：损失值与生成质量相关（可监控）、梯度更稳定、不存在模式崩塌。

WGAN-GP (Gradient Penalty)

$$\mathcal{L}_D = \underbrace{\mathbb{E}_{\tilde{x}}[D(\tilde{x})] - \mathbb{E}_{x}[D(x)]}_{\text{Wasserstein 距离}} + \lambda\,\underbrace{\mathbb{E}_{\hat{x}}[(\|\nabla_{\hat{x}}D(\hat{x})\|_2 - 1)^2]}_{\text{梯度惩罚}}$$

用梯度惩罚替代 weight clipping 来约束 Lipschitz 条件，\(\hat{x}\) 是真假样本间的插值点。更稳定、效果更好。

8.2 VAE 的 ELBO

VAE 最大化证据下界（ELBO）：

$$\log p(x) \ge \underbrace{\mathbb{E}_{q(z|x)}[\log p(x|z)]}_{\text{重构损失}} - \underbrace{D_{\text{KL}}(q(z|x) \| p(z))}_{\text{KL 正则}}$$

等价于最小化：

$$\boxed{\mathcal{L}_{\text{VAE}} = -\mathbb{E}_{q(z|x)}[\log p(x|z)] + D_{\text{KL}}(q(z|x) \| p(z))}$$
  • 重构损失：让解码器从 \(z\) 重建 \(x\)，通常用 MSE 或 BCE
  • KL 正则：让后验 \(q(z|x)\) 接近先验 \(p(z) = \mathcal{N}(0, I)\)，保证隐空间连续可采样

当 \(q(z|x) = \mathcal{N}(\mu, \sigma^2)\) 时，KL 项有解析解：

$$D_{\text{KL}} = -\frac{1}{2}\sum_{j=1}^{d}(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2)$$

8.3 Diffusion Loss

DDPM（Ho et al., 2020）简化后的训练目标：

$$\boxed{\mathcal{L}_{\text{simple}} = \mathbb{E}_{t, x_0, \epsilon}\Big[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\Big]}$$

模型 \(\epsilon_\theta\) 预测在时间步 \(t\) 加入的噪声 \(\epsilon\)。本质上是一个去噪自编码器，用简单的 MSE 损失训练。

完整推导来自变分下界，但实践表明这个简化版本效果最好（去掉了时间步权重 SNR 项）。

  • 原始 GAN 优化 JS 散度 → 训练不稳定；WGAN 用 Wasserstein 距离 → 提供有意义的损失曲线
  • WGAN-GP 用梯度惩罚替代 weight clipping → 避免权重空间被限制到小范围
  • VAE ELBO = 重构 + 正则：KL 项过强导致后验坍缩（posterior collapse）
  • Diffusion 训练目标极简：预测噪声的 MSE，但采样需要多步迭代去噪
09

📊 九、排序损失

或使用交叉熵形式（RankNet）：

9.1 Pairwise Loss

$$\mathcal{L}_{\text{pair}} = \sum_{(i,j): y_i > y_j} \max(0,\; -(s_i - s_j) + m)$$

或使用交叉熵形式（RankNet）：

$$\mathcal{L}_{\text{RankNet}} = -\sum_{(i,j)} \bar{P}_{ij}\log P_{ij} + (1-\bar{P}_{ij})\log(1-P_{ij})$$

其中 \(P_{ij} = \sigma(s_i - s_j)\) 是模型认为 \(i\) 排在 \(j\) 前面的概率。

9.2 ListNet

将评分列表通过 Softmax 转为概率分布，用 CE 衡量预测排列分布与真实排列分布的差异：

$$\mathcal{L}_{\text{ListNet}} = -\sum_{i=1}^{n} P_{\text{true}}(i)\log P_{\text{pred}}(i)$$ $$P(i) = \frac{\exp(s_i)}{\sum_j \exp(s_j)}$$

ListNet 考虑全局排列，而非仅成对关系。

9.3 LambdaRank 思想

核心创新：直接在梯度中注入排序指标（如 NDCG）的变化量。

$$\lambda_{ij} = \frac{\partial \mathcal{L}_{\text{CE}}}{\partial s_{ij}} \cdot |\Delta\text{NDCG}_{ij}|$$

对每个文档对 \((i,j)\)，梯度乘以交换 \(i,j\) 后 NDCG 的变化量。位于排序前列的交换影响更大 → 自动聚焦 top-k 排序质量。

LambdaMART = LambdaRank + MART (Gradient Boosted Trees)，长期霸榜 L2R 竞赛。

  • 排序损失三个层次：Pointwise（逐样本回归/分类） → Pairwise（相对顺序） → Listwise（全局排列）
  • NDCG 不可微，LambdaRank 巧妙绕过：不写损失函数，直接定义梯度
  • 实际搜索/推荐系统中 LambdaMART 仍广泛使用（尤其在精排阶段）

💬 十一、Q&A

三个原因 ：
Q1：为什么分类任务用交叉熵而不用 MSE？

三个原因：

  1. 梯度性质：MSE 的梯度含 \(\hat{p}(1-\hat{p})\) 项（Sigmoid 导数），当预测极端错误时梯度反而很小（饱和区），导致学习缓慢。CE 的梯度 \(\propto (\hat{p}-y)\)，预测越错梯度越大。
  2. 概率解释：CE = 负对数似然，有清晰的 MLE 理论基础。MSE 对概率输出没有良好的统计解释。
  3. 损失曲面：MSE 在分类任务上的损失曲面存在多个局部极小值，CE 对 Softmax/Sigmoid 输出是凸的。
Q2：Focal Loss 的原理是什么？γ 如何影响训练？

Focal Loss = \(-\alpha_t(1-p_t)^\gamma\log(p_t)\)。核心思想是添加调制因子 \((1-p_t)^\gamma\)：

  • 对于易分类样本（\(p_t\) 大），调制因子趋近 0，极大降低其贡献
  • 对于困难样本（\(p_t\) 小），调制因子趋近 1，保留其损失

γ=0 时退化为标准 CE；γ 越大，对易分类样本的抑制越强。论文推荐 γ=2, α=0.25。

实际影响：在 RetinaNet 中，Focal Loss 使 one-stage 检测器精度首次超越 two-stage（如 Faster R-CNN），因为它解决了 1:1000 级别的前景/背景不平衡问题。

Q3：对比学习中温度参数 τ 的作用是什么？

温度 τ 出现在 InfoNCE 的 softmax 分母中，控制相似度分布的锐度：

  • τ 小：分布尖锐，模型更关注最难负样本，但训练不稳定（梯度方差大）
  • τ 大：分布平滑，所有负样本贡献均匀，丧失对困难样本的区分力

实践值：SimCLR τ=0.5，MoCo τ=0.07，CLIP τ 为可学习参数（初始 0.07）。τ 的选择与 batch size、负样本数量相关。

Q4：知识蒸馏中为什么要乘 T²？

温度 T 缩放使 Softmax 输出变平滑：\(p_i = \text{softmax}(z_i/T)\)。

当 T 较大时，softmax 输出值变小，导致 KL 散度（以及其梯度）的量级约为 \(1/T^2\)。乘以 \(T^2\) 是为了梯度补偿：确保蒸馏损失的梯度与硬标签 CE 损失的梯度在同一量级，使超参 α 的调节有意义。

数学推导：对 \(z_j\) 求导，softmax(\(z/T\)) 贡献 \(1/T\)，log 的导数再贡献 \(1/T\) → 总共 \(1/T^2\)。

Q5：GAN 训练不稳定的原因？WGAN 如何改进？

原始 GAN 的问题：

  • 优化 JS 散度 — 当两个分布不重叠时 JSD 恒为 \(\log 2\)，梯度为 0
  • 判别器太强 → 生成器梯度消失；判别器太弱 → 训练信号弱
  • 模式崩塌（mode collapse）：G 只学会生成少数几种样本

WGAN 改进：用 Wasserstein-1 距离（Earth Mover's Distance）替代 JSD。W 距离即使在分布不重叠时也提供有意义的梯度。损失值可直接反映生成质量。WGAN-GP 进一步用梯度惩罚替代 weight clipping，提升稳定性。

Q6：VAE 的 ELBO 包含哪两部分？各有什么作用？

ELBO = \(\mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{\text{KL}}(q(z|x)\|p(z))\)

  1. 重构损失 \(\mathbb{E}[\log p(x|z)]\)：鼓励解码器从隐变量 z 准确重建 x
  2. KL 正则 \(D_{\text{KL}}\)：约束后验 q(z|x) 接近先验 N(0,I)，保证隐空间连续可采样

权衡：KL 项过强 → 后验坍缩（忽略 z，退化为标准解码器）；KL 项过弱 → 隐空间无结构，无法有意义采样。β-VAE 通过 β 系数控制这一平衡。

Q7：Softmax + Cross-Entropy 的梯度为什么是 p̂ - y？

设 Softmax 输出 \(\hat{p}_j = e^{z_j}/\sum_k e^{z_k}\)，损失 \(\mathcal{L} = -\log \hat{p}_y\)。

对 logit \(z_j\) 求导：

  • \(j = y\)（正确类）：\(\frac{\partial \mathcal{L}}{\partial z_y} = -\frac{1}{\hat{p}_y}\cdot\hat{p}_y(1-\hat{p}_y) = \hat{p}_y - 1\)
  • \(j \neq y\)（其他类）：\(\frac{\partial \mathcal{L}}{\partial z_j} = -\frac{1}{\hat{p}_y}\cdot(-\hat{p}_y\hat{p}_j) = \hat{p}_j\)

统一写为 \(\hat{p}_j - \mathbb{1}[j=y]\)，即预测概率 - one-hot 标签。这个简洁结果使得实现高效（一次向量减法），数值稳定（避免分开计算 softmax 和 log 的数值问题，用 log-sum-exp trick）。

Q8：CLIP Loss 与 InfoNCE 的关系？

CLIP Loss = 双向/对称 InfoNCE。

InfoNCE 是单方向的：给定 query 找正样本。CLIP 对一个 batch 的 N 个图文对构造 N×N 相似度矩阵，分别对行（image→text）和列（text→image）做 softmax + CE，取平均。

目标：使相似度矩阵的对角线（匹配对）最大化，非对角线（非匹配对）最小化。Label 矩阵 = 单位矩阵。

关键设计：batch 内其他 N-1 个样本作为负样本 → batch size 越大效果越好（CLIP 用 32768）；温度 τ 是可学习参数。

Q9：Diffusion 模型的训练损失是什么？与 VAE 有什么联系？

DDPM 的简化训练目标：\(\mathcal{L} = \mathbb{E}_{t,x_0,\epsilon}[\|\epsilon - \epsilon_\theta(x_t,t)\|^2]\)

模型 \(\epsilon_\theta\) 预测加入的噪声，用简单 MSE 训练。完整推导来自变分下界（与 VAE 的 ELBO 类似）：

  • Diffusion 可看作层次化 VAE：T 步扩散 = T 层隐变量
  • 前向过程（加噪）= 编码器（固定，不需学习）
  • 反向过程（去噪）= 解码器（需要学习）
  • 但 Diffusion 每步只有微小变化 → 高斯假设合理 → 训练更稳定

简化版去掉了 SNR 权重项，实验表明效果更好（可能因为均匀对待所有时间步有正则化效果）。

Q10：LambdaRank 是如何解决 NDCG 不可微的问题的？

LambdaRank 的核心创新是不定义损失函数，直接定义梯度：

对于每对文档 (i,j)，梯度 = RankNet 的 CE 梯度 × |ΔNDCG|（交换 i,j 后 NDCG 的变化量）。

直觉：如果交换两个文档的排序位置对 NDCG 影响大（如 top-1 和 top-2 交换 vs top-100 和 top-101 交换），那么模型应该更努力学习这对文档的正确顺序。

这种"梯度注入"方法绕开了 NDCG 不可微的问题，同时使模型自动聚焦于排序头部质量。后来的 LambdaMART 结合 GBDT，长期统治搜索排序领域。
