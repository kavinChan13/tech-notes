01

前向传播 (Forward Propagation)

前向传播是指输入数据从 输入层 逐层流经网络，经过线性变换与非线性激活，最终到达 输出层 产…

1.1 核心概念

前向传播是指输入数据从输入层逐层流经网络，经过线性变换与非线性激活，最终到达输出层产生预测值的过程。它是推理 (inference) 和训练 (training) 中计算损失的基础步骤。

1.2 逐层计算过程

对于第 l 层，计算分为两步：

线性变换 (Linear Transform)
z⁽ˡ⁾ = W⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
激活函数 (Activation)
a⁽ˡ⁾ = σ(z⁽ˡ⁾)

其中：

  • W⁽ˡ⁾ — 第 l 层权重矩阵，形状 (nₗ, nₗ₋₁)
  • b⁽ˡ⁾ — 第 l 层偏置向量，形状 (nₗ, 1)
  • a⁽ˡ⁻¹⁾ — 上一层的激活输出（第 0 层即输入 x）
  • σ(·) — 激活函数（ReLU / Sigmoid / Tanh 等）

1.3 完整数学推导（L 层网络）

输入层
a⁽⁰⁾ = x
隐藏层 l = 1, 2, …, L-1
z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾ a⁽ˡ⁾ = g⁽ˡ⁾(z⁽ˡ⁾)
输出层 (以分类任务为例)
z⁽ᴸ⁾ = W⁽ᴸ⁾ a⁽ᴸ⁻¹⁾ + b⁽ᴸ⁾ ŷ = a⁽ᴸ⁾ = softmax(z⁽ᴸ⁾)
损失函数 (Cross-Entropy)
L(ŷ, y) = − Σᵢ yᵢ log(ŷᵢ)

1.4 前向传播的数据流示意

前向传播数据流 · 逐层 z=Wx+b → 激活，并缓存 z/a 供反向使用
输入 x
第 1 层
z=Wx+b → a=ReLU(z)（缓存 z, a）
第 2 层
z=Wx+b → a=ReLU(z)（缓存 z, a）
输出层 → ŷ
z=Wx+b → a=softmax（缓存 z, a）
知识要点
  • 为什么需要缓存中间值？ 反向传播计算梯度时需要用到前向传播中的 z 和 a 值，因此前向传播必须保存这些中间结果。
  • 前向传播的时间复杂度与网络参数量成正比 — O(Σ nₗ · nₗ₋₁)。
  • 推理 vs 训练的区别：推理只需前向传播，不需保存中间值；训练则需要完整的前向 + 反向。

计算图 (Computation Graph)

计算图是一种 有向无环图 (DAG) ，用于表示数学表达式的计算过程

2.1 什么是计算图

计算图是一种有向无环图 (DAG)，用于表示数学表达式的计算过程。每个节点代表一个操作（加法、乘法、激活函数等）或一个变量，边代表数据的流动方向。

2.2 节点与边

元素含义示例
叶子节点输入变量 / 可学习参数x, W, b
中间节点运算操作的结果z = Wx + b
根节点最终输出（通常是 loss）L = CrossEntropy(ŷ, y)
边数据依赖关系 / 梯度流向x → Wx → z → a → L

2.3 计算图表示前向过程

计算图：L = −y·log(σ(Wx + b))
W, x
Wx
z = Wx + b
a = σ(z)
L

前向传播沿着边从左到右逐节点计算；反向传播则从右到左沿边反向传递梯度。

2.4 静态图 vs 动态图

特性静态图 (TensorFlow 1.x)动态图 (PyTorch / TF Eager)
构建时机先定义图结构，再喂数据执行逐行执行时即时构建
调试便利性较难（需 Session.run）方便（可 print / pdb）
控制流需要 tf.cond / tf.while_loop直接用 Python if / for
性能优化编译期可做全局优化运行时优化（torch.compile）
适用场景生产部署、模型导出研究、快速原型
知识要点
  • 计算图的核心价值：将复杂的数学表达式分解为原子操作，使自动微分成为可能。
  • 为什么 PyTorch 更受研究者欢迎？ 动态图支持更灵活的控制流（如变长序列、条件分支），调试体验类似普通 Python 程序。
  • TensorFlow 2.x 的改变：默认使用 Eager Execution（动态图），同时通过 @tf.function 支持图模式编译优化。
03

反向传播算法 (Backpropagation)

反向传播的本质是 链式法则 (Chain Rule) 的高效应用

3.1 核心思想

反向传播的本质是链式法则 (Chain Rule) 的高效应用。它从损失函数出发，沿计算图逆向逐层计算每个参数对损失的梯度，避免了重复计算，将梯度计算复杂度从指数级降低到与前向传播同阶。

链式法则
∂L/∂W⁽ˡ⁾ = ∂L/∂a⁽ˡ⁾ · ∂a⁽ˡ⁾/∂z⁽ˡ⁾ · ∂z⁽ˡ⁾/∂W⁽ˡ⁾

3.2 逐层推导

Step 1: 定义误差项 δ

令 δ⁽ˡ⁾ = ∂L/∂z⁽ˡ⁾ 为第 l 层的「误差信号」，则：

输出层误差 (Softmax + Cross-Entropy)
δ⁽ᴸ⁾ = ∂L/∂z⁽ᴸ⁾ = a⁽ᴸ⁾ − y = ŷ − y

Softmax + Cross-Entropy 的组合使得输出层梯度形式极为简洁。

Step 2: 隐藏层误差的递推

隐藏层误差递推公式
δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾)ᵀ · δ⁽ˡ⁺¹⁾ ⊙ g'(z⁽ˡ⁾)

其中 ⊙ 表示逐元素乘法 (Hadamard product)，g'(z⁽ˡ⁾) 是激活函数的导数。

Step 3: 参数梯度计算

权重梯度
∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ · (a⁽ˡ⁻¹⁾)ᵀ
偏置梯度
∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾

3.3 完整反向传播流程

反向传播 · 从 Loss 逐层回传误差信号 δ 并计算梯度
Loss L
前向得到预测 ŷ，与真值 y 计算损失 —— 从这里开始反向
输出层误差  δ⁽ᴸ⁾ = ŷ − y
↳ 权重梯度 ∂L/∂W⁽ᴸ⁾ = δ⁽ᴸ⁾·(a⁽ᴸ⁻¹⁾)ᵀ  ·  偏置梯度 ∂L/∂b⁽ᴸ⁾ = δ⁽ᴸ⁾
隐藏层误差  δ⁽ᴸ⁻¹⁾ = (W⁽ᴸ⁾)ᵀ δ⁽ᴸ⁾ ⊙ g′(z⁽ᴸ⁻¹⁾)
↳ ∂L/∂W⁽ᴸ⁻¹⁾ = δ⁽ᴸ⁻¹⁾·(a⁽ᴸ⁻²⁾)ᵀ  ·  ∂L/∂b⁽ᴸ⁻¹⁾ = δ⁽ᴸ⁻¹⁾
…… 沿计算图逆序重复，直到第 1 层，得到全部参数的梯度 ……

3.4 Mini-batch 下的反向传播

当使用 mini-batch（批大小 m）时，梯度是对批次内所有样本梯度的平均：

批次平均梯度
∂L/∂W⁽ˡ⁾ = (1/m) Σⱼ₌₁ᵐ δⱼ⁽ˡ⁾ · (aⱼ⁽ˡ⁻¹⁾)ᵀ
知识要点
  • 反向传播 ≠ 梯度下降：反向传播只负责计算梯度，梯度下降负责更新参数（W ← W − α · ∂L/∂W）。
  • 反向传播的时间复杂度与前向传播相同量级 — 一次反向约为 2× 前向的计算量（需要额外的转置矩阵乘法）。
  • 为什么反向传播高效？ 通过复用中间计算结果（动态规划思想），避免对每个参数独立求导。
  • δ 的物理意义：衡量第 l 层的加权输入 z 对最终损失的敏感度。

自动微分 (Autograd)

神经网络通常有 数百万参数 （多输入）但只有 一个标量 loss （单输出），因此反向模式…

4.1 自动微分 vs 数值微分 vs 符号微分

方法原理优点缺点
数值微分f'(x) ≈ [f(x+ε)−f(x−ε)] / 2ε实现简单精度低、计算量大 O(n)
符号微分对表达式做符号化求导精确表达式膨胀、效率低
自动微分在计算过程中追踪导数精确 + 高效需要框架支持

4.2 前向模式 vs 反向模式

前向模式自动微分 (Forward-mode AD)
同时计算函数值和导数，每次追踪一个输入变量的导数 适用于：输入少、输出多 (n ≪ m) 一次扫描得到一个输入对所有输出的导数：∂f/∂xᵢ
反向模式自动微分 (Reverse-mode AD)
先前向计算函数值，再反向传播导数 适用于：输入多、输出少 (n ≫ m) ← 神经网络正是这种情况！ 一次扫描得到所有输入对一个输出的导数：∂L/∂θ

神经网络通常有数百万参数（多输入）但只有一个标量 loss（单输出），因此反向模式 AD（即反向传播）是最优选择。

4.3 PyTorch Autograd 机制

计算图的构建

PyTorch 在每次前向计算时动态构建计算图。每个 Tensor 操作会创建一个 grad_fn 节点，记录如何计算梯度。

import torch

x = torch.tensor([2.0], requires_grad=True)   # 叶子节点，需要梯度
w = torch.tensor([3.0], requires_grad=True)

z = w * x          # z.grad_fn = MulBackward0
a = z.relu()       # a.grad_fn = ReluBackward0
loss = (a - 5)**2  # loss.grad_fn = PowBackward0

loss.backward()    # 触发反向传播

print(w.grad)      # ∂loss/∂w — 梯度存在叶子节点的 .grad 属性
print(x.grad)      # ∂loss/∂x

核心 API

API作用使用场景
.backward()从当前 tensor 反向计算所有叶子节点的梯度训练循环中调用 loss.backward()
.grad存储叶子节点累积的梯度读取参数梯度用于更新
.detach()从计算图中分离 tensor，返回不需要梯度的新 tensor目标网络更新、评估指标计算
torch.no_grad()上下文管理器，临时禁用梯度追踪推理 / 参数更新 / 验证
.requires_grad_()就地修改 tensor 的梯度追踪标志冻结/解冻参数
.retain_graphbackward() 后保留计算图需要多次 backward 时

梯度累积

PyTorch 中梯度是累加的，不会自动清零。训练循环中必须手动清零：

optimizer.zero_grad()   # 清零梯度
loss = model(x, y)      # 前向传播
loss.backward()          # 反向传播
optimizer.step()         # 参数更新

利用梯度累积模拟大 batch：连续多次 backward() 不清零，等效于大 batch 训练：

for i, (x, y) in enumerate(loader):
    loss = model(x, y) / accumulation_steps
    loss.backward()                  # 梯度累加
    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
知识要点
  • 为什么用反向模式而非前向模式？ 神经网络参数多、输出（loss）只有一个标量，反向模式只需一次反向扫描即可得到所有参数梯度。
  • .detach() vs .no_grad()：detach() 针对单个 tensor 切断计算图；no_grad() 是上下文管理器，禁用区域内所有操作的梯度追踪。
  • 为什么梯度需要手动清零？ 设计上的选择 — 方便实现梯度累积，模拟更大的 batch size。
  • 动态图何时销毁？ 默认 backward() 后计算图被释放（节省内存），需要 retain_graph=True 才能保留。

梯度消失与梯度爆炸

回顾隐藏层误差递推公式：

5.1 数学分析

回顾隐藏层误差递推公式：

误差递推
δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾)ᵀ · δ⁽ˡ⁺¹⁾ ⊙ g'(z⁽ˡ⁾)

从输出层到第 1 层的梯度涉及连乘：

梯度的连乘结构
∂L/∂W⁽¹⁾ ∝ ∏ₗ₌₂ᴸ [(W⁽ˡ⁾)ᵀ · diag(g'(z⁽ˡ⁻¹⁾))] 若每个因子的谱范数 < 1 → 连乘趋近 0 → 梯度消失 若每个因子的谱范数 > 1 → 连乘趋近 ∞ → 梯度爆炸

为什么 Sigmoid 导致梯度消失？

Sigmoid 函数 σ(z) = 1/(1+e⁻ᶻ)，其导数：

Sigmoid 导数
σ'(z) = σ(z)(1 − σ(z)) 最大值在 z=0 处取到：σ'(0) = 0.25 即梯度在每层至少缩小为 1/4 经过 L 层后：梯度缩小约 (0.25)ᴸ L=10 时：(0.25)¹⁰ ≈ 9.5 × 10⁻⁷ → 几乎为零

为什么深层网络容易梯度爆炸？

若权重矩阵 W 的最大奇异值 σ_max(W) > 1，且激活函数导数不做有效衰减（如 ReLU 导数为 1），则：

梯度爆炸分析
‖∂L/∂W⁽¹⁾‖ ∝ ∏ₗ₌₂ᴸ σ_max(W⁽ˡ⁾) · max(g'(z⁽ˡ⁻¹⁾)) 若 σ_max ≈ 1.5，L = 50： 1.5⁵⁰ ≈ 6.4 × 10⁸ → 梯度爆炸

5.2 信号传播角度分析

从信号传播（而非梯度）的角度看，健康的网络应满足：

  • 前向传播：每一层输出的方差应与输入方差相近 — Var(a⁽ˡ⁾) ≈ Var(a⁽ˡ⁻¹⁾)
  • 反向传播：每一层梯度的方差应保持稳定 — Var(δ⁽ˡ⁾) ≈ Var(δ⁽ˡ⁺¹⁾)

这两个条件共同推导出了 Xavier 初始化的理论基础。

知识要点
  • 梯度消失的直觉：深层网络的浅层参数"感受不到"损失函数的变化信号，导致学习极慢。
  • 梯度爆炸的症状：训练 loss 突然变 NaN / Inf，参数值急剧增大。
  • ReLU 为什么能缓解消失但仍有问题？ ReLU 正区间导数恒为 1，不会指数衰减；但负区间导数为 0（Dead ReLU），可能导致神经元永久死亡。

解决方案

# PyTorch 权重初始化 import torch

6.1 权重初始化

方法公式适用激活函数核心思想
Xavier / Glorot W ~ N(0, 2/(nᵢₙ + nₒᵤₜ)) Sigmoid / Tanh 保持前向和反向传播中信号方差不变
He / Kaiming W ~ N(0, 2/nᵢₙ) ReLU 及其变体 考虑 ReLU 会将一半输入置零，方差需补偿 ×2
LSUV 逐层前向传播后调整 W 使输出方差 ≈ 1 通用 数据驱动的自适应初始化 
# PyTorch 权重初始化
import torch.nn as nn

# Xavier
nn.init.xavier_uniform_(layer.weight)
nn.init.xavier_normal_(layer.weight)

# He / Kaiming
nn.init.kaiming_uniform_(layer.weight, nonlinearity='relu')
nn.init.kaiming_normal_(layer.weight, nonlinearity='relu')

6.2 残差连接 (ResNet Skip Connection)

残差块
a⁽ˡ⁺²⁾ = g(z⁽ˡ⁺²⁾ + a⁽ˡ⁾) ← 跳跃连接 (skip connection)

为什么残差连接能解决梯度消失？

梯度分析
∂a⁽ˡ⁺²⁾/∂a⁽ˡ⁾ = ∂g/∂z · (∂F/∂a⁽ˡ⁾ + I) 由于恒等映射 I 的存在，即使 ∂F/∂a⁽ˡ⁾ 很小， 梯度仍可通过 I 直接传回 → 梯度信息「高速公路」
ResNet 残差块 · 主路 + 恒等 skip 相加
输入 a⁽ˡ⁾
同时沿主路与 skip 旁路前进
F(a⁽ˡ⁾)
与 skip 的 a⁽ˡ⁾ 相加
a⁽ˡ⁺²⁾ = ReLU(F(a⁽ˡ⁾) + a⁽ˡ⁾)
恒等旁路提供梯度直通路径

6.3 梯度裁剪 (Gradient Clipping)

按范数裁剪 (Clip by Norm)
若 ‖g‖ > threshold: g ← g · (threshold / ‖g‖) 效果：保持梯度方向不变，仅缩小模长
按值裁剪 (Clip by Value)
g ← clip(g, −threshold, +threshold) 效果：逐元素截断，可能改变梯度方向 
# PyTorch 梯度裁剪
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=0.5)

6.4 激活函数选择

激活函数导数范围是否有消失/爆炸风险备注
Sigmoid(0, 0.25]严重消失已基本弃用于隐藏层
Tanh(0, 1]消失（比 Sigmoid 轻）零中心化但仍有消失
ReLU{0, 1}无消失；Dead ReLU默认选择
Leaky ReLU{α, 1}（α≈0.01）无消失、无死亡解决 Dead ReLU
GELU连续平滑无Transformer 标配
SiLU/Swish连续平滑无x·σ(x)，效果好

6.5 归一化层的帮助

BatchNorm 和 LayerNorm 通过规范化每层的输入分布，使各层的激活值保持在合理范围内，从根本上缓解了梯度不稳定问题。

BatchNorm
x̂ = (x − μ_B) / √(σ²_B + ε) ← 标准化 y = γ · x̂ + β ← 可学习的缩放和平移 在 batch 维度上统计均值和方差
LayerNorm
x̂ = (x − μ_L) / √(σ²_L + ε) 在特征维度上统计均值和方差 适用于 RNN / Transformer（不依赖 batch size）
知识要点
  • Xavier vs He 的本质区别：He 初始化考虑了 ReLU 会将约一半激活值置零（方差减半），因此在分母中去掉了 nₒᵤₜ 并乘以 2 来补偿。
  • ResNet 为什么能训练 150+ 层？ Skip connection 提供了梯度的直通路径（恒等映射），使深层梯度不依赖连乘结构。
  • 梯度裁剪常用于什么模型？ RNN / LSTM / Transformer 训练中几乎标配，clip_grad_norm_ 比 clip_grad_value_ 更常用。
  • BatchNorm 在训练和推理时的区别？ 训练时使用 mini-batch 统计量；推理时使用全局滑动平均统计量（running_mean, running_var）。
07

反向传播的变体

BPTT 是反向传播在 循环神经网络 (RNN) 上的扩展

7.1 BPTT — 时间反向传播 (Backpropagation Through Time)

BPTT 是反向传播在循环神经网络 (RNN) 上的扩展。将 RNN 沿时间步展开后，等价于一个很深的前馈网络，然后对展开后的网络执行标准反向传播。

BPTT · RNN 沿时间展开为深层前馈网络
h₀→h₁x₀ · L₁
h₁→h₂x₁ · L₂
h₂→h₃x₂ · L₃
…
h₋→hₜxₜ · Lₜ
所有时间步共享参数 W_hh / W_xh / W_hy；梯度 = Σₜ ∂Lₜ/∂W（对所有时间步求和）
BPTT 的梯度连乘问题
∂L/∂h₁ = ∏ₜ₌₂ᵀ (W_hh)ᵀ · diag(g'(hₜ)) T 很大时 → 同样面临梯度消失/爆炸 这就是 LSTM / GRU 被发明的动机

7.2 Truncated BPTT (截断式 BPTT)

对于很长的序列，完整 BPTT 计算开销和内存消耗巨大。Truncated BPTT 将序列分为固定长度的片段，只在每个片段内做反向传播：

  • 前向传播：跨片段传递隐藏状态（维持上下文）
  • 反向传播：在片段边界截断梯度（不回传到前面的片段）
Truncated BPTT
片段长度 k：只回传 k 步梯度 优点：内存 O(k) 而非 O(T)，计算量大幅减少 缺点：无法捕获跨越 k 步以上的长程依赖 典型值：k = 35 ~ 100

7.3 梯度检查点 (Gradient Checkpointing)

也叫激活重计算 (Activation Recomputation)，是一种用时间换空间的技术。

核心思想

标准反向传播需保存所有中间激活值，内存为 O(L)。梯度检查点只保存部分层的激活值（检查点），反向传播时从检查点重新前向计算丢弃的中间值。

内存 vs 计算权衡
标准模式：内存 O(L)，计算 1× forward + 1× backward 检查点模式：内存 O(√L)，计算 1× forward + ~1.33× backward 若将 L 层网络均匀分为 √L 段，每段 √L 层： — 保存 √L 个检查点 — 反向时每段重新前向计算 √L 步 — 峰值内存降至 O(√L) 
# PyTorch 梯度检查点
from torch.utils.checkpoint import checkpoint

class MyModel(nn.Module):
    def forward(self, x):
        # 对特定的 block 使用 checkpoint
        x = checkpoint(self.block1, x, use_reentrant=False)
        x = checkpoint(self.block2, x, use_reentrant=False)
        return self.head(x)
知识要点
  • BPTT 和标准 BP 的关系：BPTT 就是将 RNN 沿时间展开后应用标准 BP，本质完全相同。
  • Truncated BPTT 的 trade-off：片段越长，能捕获的依赖越远，但内存和计算开销越大。
  • 梯度检查点的典型加速场景：训练大模型时 GPU 显存不足，使用检查点可将 batch size 增大约 2-4 倍，以约 33% 额外计算时间换取。
  • 大模型训练中的实际应用：GPT-3 / LLaMA 等大语言模型训练中广泛使用 Gradient Checkpointing + 模型并行 + 梯度累积的组合策略。

Q&A

Q1: 请解释前向传播和反向传播的关系？
A: 前向传播将输入数据逐层经过线性变换和激活函数传递到输出层，计算预测值和损失。反向传播则从损失出发，利用链式法则从输出层向输入层逆向计算每个参数对损失的梯度。二者配合完成一个训练迭代：前向传播产生预测 → 计算损失 → 反向传播计算梯度 → 优化器更新参数。前向传播时需要缓存中间值（z 和 a），供反向传播使用。
Q2: 反向传播的本质是什么？它为什么比朴素求导高效？
A: 反向传播的本质是链式法则的动态规划式应用。朴素方法对每个参数独立求导需要 O(n) 次前向计算（n 为参数数量），而反向传播通过从后向前复用已计算的中间梯度（δ），只需一次反向扫描即可得到所有参数的梯度，时间复杂度与前向传播相同量级。这就是反向模式自动微分的核心优势。
Q3: 为什么 Sigmoid 激活函数会导致梯度消失？
A: Sigmoid 的导数 σ'(z) = σ(z)(1−σ(z))，最大值仅为 0.25（在 z=0 时取到）。由于反向传播涉及各层梯度的连乘，每经过一层至少缩小到 1/4，深层网络中梯度会指数级衰减趋向于零。例如 10 层网络，梯度可能缩小约 10⁻⁶ 倍。这导致浅层参数几乎无法学习。
Q4: ResNet 的残差连接是如何解决梯度消失的？
A: 残差连接引入跳跃路径 a⁽ˡ⁺²⁾ = F(a⁽ˡ⁾) + a⁽ˡ⁾，使得梯度中包含恒等项 I：∂a⁽ˡ⁺²⁾/∂a⁽ˡ⁾ = ∂F/∂a + I。即使残差分支的梯度 ∂F/∂a 很小，恒等分支仍能保证梯度至少为 1，相当于为梯度提供了一条"高速公路"，使得梯度可以无衰减地传到很深的层。
Q5: PyTorch 中为什么每次训练迭代都需要 zero_grad()？
A: PyTorch 的设计是梯度默认累加到 .grad 属性上，而不是覆盖。这样设计是为了方便实现梯度累积（多次 backward 后一次 step，模拟更大 batch size）。如果不手动清零，前一次迭代的梯度会叠加到当前梯度上，导致更新方向错误。因此标准训练循环是：zero_grad → forward → backward → step。
Q6: 前向模式和反向模式自动微分有什么区别？神经网络为什么用反向模式？
A: 前向模式一次扫描计算一个输入变量对所有输出的导数（适合 n≪m 场景）；反向模式一次扫描计算所有输入对一个输出的导数（适合 n≫m 场景）。神经网络有数百万参数（大量输入变量）但只有一个标量 loss（单输出），所以反向模式只需一次反向扫描即可得到所有梯度，而前向模式需要扫描百万次，效率差距悬殊。
Q7: Xavier 初始化和 He 初始化的核心区别是什么？什么时候用哪个？
A: 两者都基于"保持前向/反向传播中信号方差稳定"的思想。Xavier 假设激活函数是线性的（适用于 Sigmoid/Tanh），方差为 2/(nᵢₙ + nₒᵤₜ)。He 初始化考虑到 ReLU 会将约一半的激活值置零（方差减半），因此方差设为 2/nᵢₙ 来补偿。简单记：用 ReLU → He 初始化；用 Sigmoid/Tanh → Xavier 初始化。
Q8: 什么是梯度检查点 (Gradient Checkpointing)？它如何节省显存？
A: 梯度检查点是一种用时间换空间的策略。标准反向传播需保存所有层的中间激活（内存 O(L)）。梯度检查点只在部分"检查点"层保存激活，反向传播到需要丢弃的层时，从最近的检查点重新前向计算。若均匀设置 √L 个检查点，峰值内存降至 O(√L)，额外计算开销约 33%。在训练 GPT/LLaMA 等大模型时广泛使用。
Q9: BPTT 是什么？为什么需要 Truncated BPTT？
A: BPTT（时间反向传播）是将 RNN 沿时间步展开后应用标准反向传播。对于长度为 T 的序列，展开后等价于 T 层深度网络，面临两个问题：(1) 内存需 O(T)；(2) 梯度连乘导致消失/爆炸。Truncated BPTT 将序列分为长度 k 的片段，只在片段内反向传播，将内存降至 O(k)。代价是无法学习超过 k 步的长程依赖。这也是后来 LSTM（门控机制）和 Transformer（注意力机制）被提出的动机之一。
Q10: 静态计算图和动态计算图有什么区别？各有什么优劣？
A: 静态图（TensorFlow 1.x）先构建完整计算图再执行，可做全局编译优化（算子融合、内存规划），利于部署，但调试困难、控制流不灵活（需要专用 API）。动态图（PyTorch / TF Eager）逐行构建图，可直接用 Python 控制流、支持 print/断点调试，开发体验好，但优化机会较少。现代趋势是两者融合：PyTorch 通过 torch.compile 做即时编译优化；TensorFlow 2.x 默认 Eager 执行 + @tf.function 做图模式优化。
