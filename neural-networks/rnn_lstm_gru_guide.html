01

RNN 基础 — 循环结构与参数共享

传统前馈网络（MLP / CNN）假设输入之间 相互独立 ，无法建模序列中的 时序依赖
核心

1.1 为什么需要 RNN？

传统前馈网络（MLP / CNN）假设输入之间相互独立，无法建模序列中的时序依赖。自然语言、语音、时间序列等数据都具有强时序关系 —— 当前时刻的含义依赖于之前的上下文。

RNN 的核心思想：引入一个隐状态 (hidden state) ht，在每个时间步将前一步的信息传递到当前步，形成"记忆"。

1.2 循环结构与展开图

RNN 沿时间展开（Unrolled）· 同一单元 A 在每步共享参数
x₁ → A → h₁ → y₁
x₂ → A → h₂ → y₂
x₃ → A → h₃ → y₃
x₄ → A → h₄ → y₄
隐状态 h 沿链向右传递（h₀→h₁→…→h₄）形成"记忆"；折叠视图即这条链首尾相接的自循环。

1.3 参数共享

RNN 在所有时间步共享同一组权重矩阵 W_h、W_x、b。好处：

  • 参数量不随序列长度增长，适应任意长度的输入
  • 学到的模式可以泛化到不同位置（类似 CNN 的平移不变性）

1.4 前向传播公式

隐状态更新 h_t = f(W_h · h_{t-1} + W_x · x_t + b)

输出 y_t = g(W_y · h_t + b_y)

其中 f(·) 通常为 tanh 或 ReLU（激活函数） g(·) 为输出层激活函数（如 softmax 用于分类） W_h ∈ ℝ^{d_h × d_h} — 隐状态到隐状态的权重 W_x ∈ ℝ^{d_h × d_x} — 输入到隐状态的权重 W_y ∈ ℝ^{d_y × d_h} — 隐状态到输出的权重

1.5 RNN 的变体拓扑

类型输入→输出应用示例
One-to-One单输入 → 单输出标准前馈网络
One-to-Many单输入 → 序列输出图片生成描述
Many-to-One序列输入 → 单输出文本情感分类
Many-to-Many (等长)序列 → 等长序列词性标注 / NER
Many-to-Many (不等长)序列 → 不等长序列机器翻译 (Seq2Seq)
💡 知识要点
  • RNN 的参数共享是核心设计 — 同一组参数作用于所有时间步
  • 隐状态 h_t 扮演"记忆"角色，理论上可以编码任意长的历史信息（实际受限）
  • 能清楚画出 RNN 的折叠图 + 展开图，说明前向传播过程
  • 理解 tanh 作为激活函数的选择：输出范围 [-1,1]，梯度比 sigmoid 更好

梯度消失与梯度爆炸

RNN 使用 BPTT (Backpropagation Through Time) 进行训…
数学

2.1 时间维度上的反向传播 (BPTT)

RNN 使用 BPTT (Backpropagation Through Time) 进行训练。将 RNN 展开后，沿时间维度反向计算梯度：

损失对 h_k 的梯度 ∂L / ∂h_k = ∂L / ∂h_T · ∏_{t=k+1}^{T} (∂h_t / ∂h_{t-1})

其中每一项 ∂h_t / ∂h_{t-1} = diag(f'(z_t)) · W_h

因此 ∂L / ∂h_k = ∂L / ∂h_T · ∏_{t=k+1}^{T} diag(f'(z_t)) · W_h

2.2 为什么 RNN 特别严重？

关键在于 Jacobian 矩阵 W_h 的连乘：

  • 如果 W_h 的最大特征值 λ_max > 1：连乘后梯度呈指数增长 → 梯度爆炸
  • 如果 W_h 的最大特征值 λ_max < 1：连乘后梯度趋近于 0 → 梯度消失
  • 序列越长，连乘次数越多，问题越严重

使用 tanh 作为激活函数时，f'(z) ∈ (0, 1)，进一步加剧梯度消失。

2.3 应对策略

问题解决方案说明
梯度爆炸梯度裁剪 (Gradient Clipping)当梯度范数超过阈值时按比例缩放：g ← g · (threshold / ‖g‖)
梯度消失LSTM / GRU 门控机制通过"门"控制信息流，建立梯度直通路径
梯度消失残差连接 (Residual)h_t = h_{t-1} + f(h_{t-1}, x_t)，梯度至少为 1
梯度消失正交初始化将 W_h 初始化为正交矩阵，特征值模为 1
梯度爆炸权重正则化L2 正则约束 W_h 的范数
💡 知识要点
  • 能从 BPTT 公式推导出梯度消失/爆炸的数学原因 — W_h 的连乘
  • 理解 CNN 的梯度消失 vs RNN 的梯度消失区别：CNN 是深度方向，RNN 是时间方向
  • 梯度爆炸用 Gradient Clipping 解决（简单有效），梯度消失需要结构性改进（LSTM/GRU）
  • LSTM 不是"解决"了梯度消失，而是"缓解" — 通过门控机制提供了梯度的直通路径

LSTM — 长短期记忆网络

LSTM (Hochreiter & Schmidhuber, 1997) 引入了一条 Ce…
核心 数学

3.1 核心思想

LSTM (Hochreiter & Schmidhuber, 1997) 引入了一条Cell State（细胞状态）—— 类比"信息高速公路"。信息可以几乎不受干扰地沿 Cell State 流动，仅通过门控机制进行精细的增删操作。

LSTM 单元结构：三个门守护 Cell State
输入 x_t ＋ 上一步 h_{t-1}
分别送入三个门
遗忘门 f_t
决定从 C_{t-1} 丢弃多少旧信息（0=全忘，1=全留）
输入门 i_t × C̃
决定写入多少新信息
C_t = f_t × C_{t-1} ＋ i_t × C̃
"信息高速公路"，梯度可长程传递
h_t = o_t × tanh(C_t)
对外输出的隐藏状态

3.2 三个门 + Cell State 更新（完整公式）

① 遗忘门 (Forget Gate)

决定从 Cell State 中丢弃多少旧信息：

f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
输出范围 (0,1)：0 = 完全遗忘，1 = 完全保留

② 输入门 (Input Gate)

决定写入多少新信息到 Cell State：

i_t = σ(W_i · [h_{t-1}, x_t] + b_i) ← 门控（写入多少）
C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C) ← 候选值（写入什么）

③ Cell State 更新

核心更新公式 C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t

⊙ 表示逐元素乘法 (Hadamard product)
第一项：选择性遗忘旧信息 第二项：选择性写入新信息

④ 输出门 (Output Gate)

决定从 Cell State 中输出多少信息作为隐状态：

o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
h_t = o_t ⊙ tanh(C_t)

3.3 为什么 LSTM 能缓解梯度消失？

关键在于 Cell State 更新公式 C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t：

  • 这是一个加法结构（而非 RNN 的矩阵乘法）
  • 当 f_t ≈ 1 时，∂C_t / ∂C_{t-1} ≈ 1，梯度可以无衰减地沿 Cell State 回传
  • 类似 ResNet 的残差连接思想 — 提供梯度的"高速公路"
  • 门控值是数据自适应的，网络可以学习在哪些时间步保留梯度
梯度回传分析 ∂C_t / ∂C_k = ∏_{j=k+1}^{t} f_j (当 f_j ≈ 1 时，梯度 ≈ 1)

对比 vanilla RNN： ∂h_t / ∂h_k = ∏_{j=k+1}^{t} diag(f'(z_j)) · W_h (连乘导致指数衰减)

3.4 参数量分析

LSTM 参数量 共 4 组权重矩阵 (f, i, C̃, o)，每组包含： W ∈ ℝ^{d_h × (d_h + d_x)} 和 b ∈ ℝ^{d_h}

总参数 = 4 × [d_h × (d_h + d_x) + d_h] = 4 × d_h × (d_h + d_x + 1)

约为 vanilla RNN 的 4 倍
💡 知识要点
  • LSTM 的三个门（遗忘、输入、输出）各自的公式和直觉含义必须能写出
  • Cell State 更新是加法结构，这是缓解梯度消失的关键 — 对比 RNN 的乘法结构
  • 遗忘门 f_t 的偏置通常初始化为较大正值（如 1~2），让初期倾向于"记住"
  • LSTM 不是完全解决梯度消失，而是提供了梯度的直通路径
  • 参数量是 vanilla RNN 的 4 倍 — 更强的表达力但也更慢

GRU — 门控循环单元

GRU (Cho et al
核心 数学

4.1 简化设计思路

GRU (Cho et al., 2014) 是 LSTM 的简化版本：

  • 将遗忘门和输入门合并为一个更新门 (Update Gate)
  • 去掉独立的 Cell State，直接使用隐状态 h_t
  • 引入重置门 (Reset Gate) 控制如何融合历史信息
  • 只有 2 个门（vs LSTM 的 3 个门），参数更少

4.2 完整公式推导

① 更新门 (Update Gate)

z_t = σ(W_z · [h_{t-1}, x_t] + b_z)
控制保留多少旧信息 vs 接受多少新信息（类似 LSTM 的 f_t 和 i_t 的综合体）

② 重置门 (Reset Gate)

r_t = σ(W_r · [h_{t-1}, x_t] + b_r)
控制在计算候选隐状态时，忽略多少历史信息 当 r_t → 0 时，相当于"重置"记忆，只看当前输入

③ 候选隐状态

h̃_t = tanh(W · [r_t ⊙ h_{t-1}, x_t] + b)
注意：r_t 在这里作用于 h_{t-1}，决定历史信息的参与程度

④ 隐状态更新

核心更新公式 h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t

z_t → 1：更多使用新信息 h̃_t（更新） z_t → 0：保留旧信息 h_{t-1}（记忆）

这其实是一个线性插值：在旧状态和新候选之间做加权平均

4.3 GRU 缓解梯度消失的机制

与 LSTM 类似，GRU 的更新公式也是加法结构：

h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t

当 z_t → 0 时：h_t ≈ h_{t-1}，梯度直接回传 ∂h_t / ∂h_{t-1} ≈ (1 - z_t) ≈ 1 → 梯度保持

4.4 GRU 参数量

GRU 参数量 共 3 组权重矩阵 (z, r, h̃)：
总参数 = 3 × [d_h × (d_h + d_x) + d_h] = 3 × d_h × (d_h + d_x + 1)

约为 LSTM 的 75%，vanilla RNN 的 3 倍
💡 知识要点
  • GRU 的两个门（更新门、重置门）的公式和作用要能清晰写出
  • 核心公式 h_t = (1-z_t)⊙h_{t-1} + z_t⊙h̃_t 是线性插值
  • 更新门 z_t 同时承担了 LSTM 遗忘门和输入门的功能：1-z_t 对应遗忘，z_t 对应输入
  • GRU 没有独立的 Cell State，参数更少，训练更快

LSTM vs GRU 对比

在大多数 NLP 任务上，LSTM 和 GRU 性能差距不大
对比
维度LSTMGRU
提出时间1997 (Hochreiter)2014 (Cho)
门的数量3 (遗忘、输入、输出)2 (更新、重置)
状态数量2 (h_t 和 C_t)1 (仅 h_t)
参数量4d_h(d_h+d_x+1)3d_h(d_h+d_x+1)，约少 25%
训练速度较慢较快（参数少、计算少）
表达能力更强（独立控制 Cell State 和输出）稍弱（合并了门控）
长距离依赖更好（独立的 Cell State 高速公路）较好（但略逊于 LSTM）
小数据集可能过拟合更优（参数少，泛化好）
大数据集通常更优（表达力强）接近 LSTM，有时更好
工程建议任务复杂、数据充足时首选资源有限、数据较少时首选
⚠️ 实践经验

在大多数 NLP 任务上，LSTM 和 GRU 性能差距不大。选择策略：

  • 默认尝试 GRU（训练更快），如果效果不够再换 LSTM
  • 超长序列 + 复杂依赖 → 优先 LSTM
  • 计算资源受限（嵌入式/移动端）→ GRU
  • 当下更推荐：考虑 Transformer 架构（但理解 RNN/LSTM/GRU 仍是面试必考）
💡 知识要点
  • 必须能画出 LSTM 和 GRU 的对比表，清楚说明结构差异
  • GRU 的更新门 = LSTM 的"遗忘门 + 输入门"的融合（互补关系：1-z 和 z）
  • GRU 没有输出门，隐状态直接暴露 → 信息可能泄露更多
  • "哪个更好" 没有定论 — 回答要看具体场景和数据量

双向 RNN (Bidirectional)

标准 RNN 只能利用 过去 的信息（从左到右）
核心

6.1 为什么需要双向？

标准 RNN 只能利用过去的信息（从左到右）。但许多任务需要同时利用上下文：

  • "我吃了一个___" — 需要前文信息
  • "___很好吃" — 需要后文信息
  • NER："苹果公司发布了..." — "苹果"是公司还是水果，取决于后文

6.2 结构

双向 RNN：两条方向相反的隐状态链

x₁x₂x₃x₄
  • Forward →h₁→ → h₂→ → h₃→ → h₄→（从左到右）
  • Backward ←h₁← ← h₂← ← h₃← ← h₄←（从右到左）

输出：ŷ_t = g([h_t→ ; h_t←])，拼接两个方向的隐状态

每个时间步的最终表示是前向和后向隐状态的拼接：

h_t = [h_t→ ; h_t←] ∈ ℝ^{2d_h}

前向 RNN：h_t→ = f(W→ · h_{t-1}→ + W_x→ · x_t + b→) 后向 RNN：h_t← = f(W← · h_{t+1}← + W_x← · x_t + b←)

6.3 应用场景

适用不适用
NER (命名实体识别)
文本分类
机器阅读理解
语音识别 (离线)		 语言模型 (LM) — 不能看到未来
实时语音识别
文本生成 — 自回归，逐字生成
💡 知识要点
  • BiRNN 的输出维度是单向的 2 倍（拼接），参数量也是 2 倍
  • 关键限制：只能用于已知完整序列的场景，不能用于自回归生成
  • BERT 的核心思想（双向 Transformer）与 BiRNN 的动机一致 — 利用双向上下文
  • BiLSTM + CRF 曾是 NER 的标准方案（面试常问）

多层 RNN / Deep RNN

将多个 RNN 层堆叠，上一层的隐状态序列作为下一层的输入：
核心

7.1 堆叠方式

将多个 RNN 层堆叠，上一层的隐状态序列作为下一层的输入：

多层 RNN：上一层隐状态序列作为下一层输入
输入序列
x₁x₂x₃x₄
Layer 1
h₁¹h₂¹h₃¹h₄¹
Layer 2
h₁²h₂²h₃²h₄²
Layer 3 → 输出
h₁³h₂³h₃³h₄³
第 l 层、时间步 t 的隐状态 h_t^(l) = f(W_h^(l) · h_{t-1}^(l) + W_x^(l) · h_t^(l-1) + b^(l))

其中 h_t^(0) = x_t（输入层）

7.2 Deep RNN 的挑战

  • 层数过多时，垂直方向也会出现梯度消失（类似深层 CNN）
  • 训练更慢、更难收敛
  • 实践中 RNN 通常 2~4 层就够（远不如 CNN/Transformer 能堆很深）

7.3 Residual RNN

借鉴 ResNet 思想，在层与层之间添加残差连接：

h_t^(l) = h_t^(l-1) + f(W^(l) · [h_{t-1}^(l), h_t^(l-1)] + b^(l))

跳跃连接让梯度可以绕过 RNN 计算直接回传到下层

其他技术：Layer Normalization（比 Batch Norm 更适合 RNN，因为序列长度可变）、Dropout（通常只在层间使用，不在时间步间使用）。

💡 知识要点
  • Deep RNN 一般 2~4 层，不像 CNN/Transformer 可以几十上百层
  • Dropout 在 RNN 中的使用有讲究 — 不在时间步间 drop（否则破坏序列依赖），Variational Dropout 是更好的方案
  • Layer Norm 优于 Batch Norm — RNN 的 batch 内序列长度不同，BN 统计量不稳定
  • 残差连接对深层 RNN 至关重要

Seq2Seq 架构

Seq2Seq (Sutskever et al
核心

8.1 Encoder-Decoder 结构

Seq2Seq (Sutskever et al., 2014) 是解决不等长序列映射的经典框架：

Seq2Seq：Encoder 压缩上下文，Decoder 逐词生成
Encoder（编码器）
x₁x₂x₃[EOS]
h₁ → h₂ → h₃
Decoder（解码器）
[SOS]y₁y₂[EOS]
s₁ → s₂ → s₃ → 输出 ŷ₁ ŷ₂ ŷ₃
编码器 h_t = LSTM_enc(x_t, h_{t-1}) c = h_T （最后一个隐状态作为 context vector）

解码器 s_t = LSTM_dec(y_{t-1}, s_{t-1})，其中 s_0 = c ŷ_t = softmax(W_o · s_t)

8.2 信息瓶颈问题

所有源序列信息被压缩到一个固定长度的向量 c 中，这造成了严重的信息瓶颈：

  • 源序列越长，丢失的信息越多
  • c 对前面时间步的信息记忆更弱（梯度消失的遗留问题）
  • 翻译任务中，长句子性能显著下降 (Cho et al., 2014 实验验证)

8.3 引出 Attention 机制

为解决信息瓶颈，Bahdanau et al. (2015) 提出 Attention 机制：

Attention 核心思想 不再依赖单个 c，而是让 Decoder 在每个时间步动态关注 Encoder 的不同位置：

α_{t,i} = softmax(score(s_{t-1}, h_i)) ← 注意力权重 c_t = Σ_i α_{t,i} · h_i ← 加权上下文向量

每个解码步都有自己的 c_t，不再是固定的单一向量

Attention → Self-Attention → Transformer（2017）→ 彻底取代了 RNN 在主流 NLP 中的地位。

💡 知识要点
  • Seq2Seq = Encoder + Decoder，两者可以是不同的 RNN
  • 信息瓶颈是 Seq2Seq 最大的缺陷 — 倒逼出 Attention 机制
  • Attention 是从"一个固定 c"进化到"每步动态 c_t"
  • 理清演进路线：RNN → LSTM/GRU → Seq2Seq → Attention → Transformer
  • Teacher Forcing：训练时用真实 y_{t-1} 而非预测 ŷ_{t-1} 作为输入，加速收敛但可能导致 exposure bias

Q&A Q&A

RNN 梯度消失的原因： BPTT 中梯度需要沿时间维度反向传播，涉及 W_h 的连乘
RNN 为什么会出现梯度消失？LSTM 是如何解决的？

RNN 梯度消失的原因：BPTT 中梯度需要沿时间维度反向传播，涉及 W_h 的连乘。当 W_h 的最大特征值 < 1 时，连乘结果呈指数衰减趋近于 0，导致远处时间步的梯度几乎为零，模型无法学习长距离依赖。

LSTM 的解决方案：引入 Cell State 和门控机制。Cell State 的更新公式 C_t = f_t⊙C_{t-1} + i_t⊙C̃_t 是加法结构。当遗忘门 f_t ≈ 1 时，∂C_t/∂C_{t-1} ≈ 1，梯度可以无衰减地沿 Cell State 回传，类似 ResNet 的残差连接，提供了梯度的"高速公路"。注意：LSTM 是"缓解"而非"彻底解决"梯度消失。

LSTM 的三个门分别是什么？各自的作用是什么？

遗忘门 f_t = σ(W_f·[h_{t-1},x_t]+b_f)：决定从 Cell State 中丢弃多少旧信息。输出 0 表示完全遗忘，1 表示完全保留。

输入门 i_t = σ(W_i·[h_{t-1},x_t]+b_i)：决定往 Cell State 中写入多少新信息。配合候选值 C̃_t = tanh(W_C·[h_{t-1},x_t]+b_C) 一起使用。

输出门 o_t = σ(W_o·[h_{t-1},x_t]+b_o)：决定从 Cell State 中输出多少信息作为隐状态 h_t = o_t⊙tanh(C_t)。

三个门都使用 sigmoid 激活（输出 0~1），起到"阀门"的调控作用。

GRU 和 LSTM 的区别是什么？什么时候用 GRU？

结构差异：GRU 只有 2 个门（更新门、重置门），LSTM 有 3 个门；GRU 没有独立的 Cell State，只有隐状态 h_t；GRU 参数量约为 LSTM 的 75%。

机制差异：GRU 的更新门 z_t 同时承担了 LSTM 遗忘门和输入门的功能（互补关系 1-z 和 z）。GRU 的更新公式 h_t = (1-z_t)⊙h_{t-1} + z_t⊙h̃_t 本质是线性插值。

选择建议：数据量小 / 计算资源有限 → GRU；任务复杂 / 超长序列 / 数据充足 → LSTM。实际性能差距通常不大，默认可先试 GRU。

什么是 Seq2Seq？它有什么局限？

Seq2Seq 是 Encoder-Decoder 架构：Encoder RNN 将输入序列编码为一个固定长度的 context vector c（通常取最后一个隐状态），Decoder RNN 基于 c 逐步生成输出序列。

最大局限是信息瓶颈：整个输入序列被压缩到一个固定维度的向量中，序列越长，信息损失越严重。这直接促使了 Attention 机制的诞生 — 让 Decoder 每步动态关注 Encoder 的不同位置，而不是依赖单一的 c。

其他局限包括：训练时的 teacher forcing 导致 exposure bias；解码时的搜索策略（贪心 vs beam search）影响生成质量。

为什么 RNN 被 Transformer 取代了？RNN 完全过时了吗？

被取代的原因：① 无法并行 — h_t 依赖 h_{t-1}，时间步必须串行，GPU 利用率低；② 长距离依赖困难 — 信息传递路径为 O(n)，而 Transformer 的 Self-Attention 为 O(1)；③ 难以堆叠很深 — 实践中 2~4 层，而 Transformer 可达 100+ 层。

RNN 并未完全过时：① 流式/实时推理场景（逐步处理，不需要完整输入）；② 低资源设备（O(1) 内存，无需存储 attention 矩阵）；③ Mamba、RWKV 等"新 RNN"正在以线性复杂度的递推结构挑战 Transformer。理解 RNN 仍是面试和理解序列建模演进的基础。

双向 RNN 的结构和限制是什么？

结构：包含两个独立的 RNN，一个从左到右（前向），一个从右到左（后向）。每个时间步的最终表示是两个方向隐状态的拼接：h_t = [h_t→; h_t←]，维度是单向的 2 倍。

限制：只能用于已知完整序列的场景（如文本分类、NER、阅读理解）。不能用于自回归生成（如语言模型、文本生成），因为生成时看不到未来的 token。也不适合实时流式处理。

经典应用：BiLSTM + CRF 曾是 NER 的标准方案；BERT 的双向思想与 BiRNN 的动机一致。

梯度裁剪 (Gradient Clipping) 是什么？为什么对 RNN 特别重要？

梯度裁剪是应对梯度爆炸的标准技术。当梯度的范数超过预设阈值 θ 时，按比例缩放梯度：g ← g × (θ / ‖g‖)。

对 RNN 特别重要的原因：RNN 的 BPTT 涉及 W_h 的连乘，当 W_h 的最大特征值 > 1 时，梯度呈指数增长（梯度爆炸）。这在长序列上尤为严重，可能导致参数更新过大，模型发散（loss 变为 NaN）。

注意：梯度裁剪只能解决梯度爆炸，不能解决梯度消失。梯度消失需要结构性改进（LSTM/GRU 的门控机制 或 残差连接）。

RNN 中为什么用 tanh 而不用 ReLU 作为激活函数？

用 tanh 的原因：① 输出范围 [-1,1]，有正有负，均值接近 0，有利于梯度流动；② 输出有界，不会导致隐状态爆炸。

不用 ReLU 的原因：① ReLU 输出无上界，在 RNN 中隐状态经过多步递推容易爆炸（值会指数增长）；② ReLU 有"死神经元"问题，一旦输入为负，梯度永远为 0。

但也有例外：研究表明配合适当的初始化（如正交初始化 + 恒等矩阵初始化 W_h），ReLU RNN 也能工作，且有时性能更好（Le et al., 2015）。LSTM/GRU 的门控用 sigmoid（输出 0~1 作为"阀门"），候选值用 tanh。

Teacher Forcing 是什么？有什么优缺点？

Teacher Forcing：在训练 Seq2Seq 的 Decoder 时，每一步输入使用真实的上一步目标 y_{t-1}，而非模型自己的预测 ŷ_{t-1}。

优点：① 加速收敛（避免早期预测错误累积导致训练不稳定）；② 训练过程更稳定。

缺点 — Exposure Bias：训练时 Decoder 总是看到"正确"的输入，但推理时只能看到自己的预测。训练和推理的分布不匹配，导致推理时错误累积（一步错，步步错）。

缓解方案：Scheduled Sampling（随训练进行逐渐减少 teacher forcing 比例）；Reinforcement Learning 方法（如 REINFORCE）；Curriculum Learning。

从 RNN 到 Transformer 的技术演进路线是什么？每一步的动机是什么？

RNN (1990)：引入循环结构建模序列，但存在梯度消失/爆炸，无法学习长距离依赖。

LSTM (1997) / GRU (2014)：通过门控机制和加法结构缓解梯度消失，但仍然是串行计算。

Seq2Seq (2014)：Encoder-Decoder 框架解决不等长序列映射，但存在信息瓶颈。

Attention (2015)：让 Decoder 动态关注 Encoder 的不同位置，解决信息瓶颈，但仍依赖 RNN 作为骨干。

Transformer (2017)："Attention Is All You Need" — 完全去掉 RNN，用 Self-Attention 实现全并行计算 + O(1) 路径长度。这是范式转换的关键一步。

每一步都是为了解决上一步的瓶颈：梯度消失 → 门控 → 信息瓶颈 → Attention → 并行化 → Transformer。
