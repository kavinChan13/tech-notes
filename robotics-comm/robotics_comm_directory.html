确定性网络

TSN 深入

802.1AS 时间同步、Qbv 门控与 GCL 设计、Qav CBS、Qbu 帧抢占、Qci 过滤、CB FRER 冗余，以及 Linux taprio/etf 落地与最坏时延界。

标签：IEEE 802.1阅读：45 分钟
DetNet 与跨域确定性

RFC 8655 三平面架构、MPLS/IPv6 数据平面、PREOF 冗余、CQF 与 ATS 排队，以及 TSN + DetNet + 5G URLLC 的分层拼接与选型。

标签：IETF DetNet阅读：35 分钟
确定性网络保障体系

时延预算分解与抖动来源分类学，端内/端间/端边/端云四类场景的预算与手段，尾部分位测量方法论，以及需求到网络指标的转化。

标签：工程方法论阅读：45 分钟

机器人通信中间件与总线

ROS2 与 DDS / RTPS 深入

DDS 数据中心模型与 RTPS 线协议、可靠传输状态机、QoS 兼容性矩阵、rmw 实现选型、Executor 实时陷阱、零拷贝与规模化调优。

标签：机器人中间件阅读：35 分钟
机器人端内总线选型

EtherCAT 飞读飞写与分布式时钟、CAN FD 无损仲裁与最坏时延计算、共享内存与无锁环形缓冲、PCIe 与板内 TSN，以及完整的控制周期预算。

标签：端内通信阅读：25 分钟
实时控制协议设计与标准化

帧格式与必备字段、新鲜度校验与序号回绕、看门狗分级降级、失步恢复握手、版本协商与向后兼容、安全层，以及协议标准化的五阶段流程。

标签：协议设计阅读：35 分钟
