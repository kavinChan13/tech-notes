算法与数据结构学习路径

P1 分析基础：先把「怎么衡量快慢」和「怎么证明算法对」这两件事立起来——复杂度记号、摊销分析、主定理，再是递归与分治这个最重要的算法范式 → P2 排序与查找：用排序和二分把 P1 的工具全部用一遍，并深入到工业级实现 → P3 线性结构技巧：双指针、滑动窗口、单调栈、前缀和——这批技巧的共同点是「靠一个论证丢掉一半候选」→ P4 核心数据结构：哈希表与堆的内核剖析，以及它们在生产系统里的选型判据 → P5 树与区间结构：从「用层级换对数」到平衡树四条路，再到并查集与三种区间结构各自的前提 → P6 图论：图的表示如何决定复杂度、拓扑排序的两副面孔、松弛与割性质如何统一六个算法 → P7 算法范式与字符串：DP 的状态设计方法论、贪心的证明与失效判据、字符串算法共用的「复用已知区间」框架。适合有 C++ 基础、想把算法从「刷题」升级到「工程」的读者。

~52 h180 道面试题代码 C++17/20
P1
分析基础（~7 h）
先有度量与证明工具，再谈具体算法
#内容时间
1复杂度与分析3.5 h
2递归与分治3.5 h
✅ 完成标志
  1. 能说清 O / Θ / Ω 的区别，以及「快排是 O(n log n)」为什么不算完整回答
  2. 能用聚合法和势能法两种方式证明 vector::push_back 的摊销 O(1)
  3. 拿到一个递推式能立刻判断落在主定理哪一情形，并说出该情形里优化该往哪使劲
  4. 能解释为什么 std::list 的 O(1) 插入实测输给 std::vector 的 O(n)
  5. 能说清在 C++ 里为什么不该依赖尾调用消除，以及深递归的两条正确出路
P2
排序与查找（~7 h）
把 P1 的工具用一遍，并下探到工业级实现
#内容时间
3排序全景4 h
4二分查找3 h
✅ 完成标志
  1. 能用决策树模型证明比较排序的 Ω(n log n) 下界，并说清这个下界约束不到谁
  2. 能逐段讲出 libstdc++ std::sort 的三段结构，以及三者短板为何互补
  3. 知道比较器违反严格弱序为什么会导致越界而不只是顺序错，以及怎么在 CI 里挡住
  4. 能写下二分的循环不变式，并用它推出四种边界写法而不是靠试
  5. 看到「最小化最大值」能立刻想到二分答案，并主动去证明 feasible 的单调性
P3
线性结构技巧（~6.5 h）
共同点：靠一个论证丢掉一半候选
#内容时间
5双指针与滑动窗口3 h
6单调栈与前缀和3.5 h
✅ 完成标志
  1. 写完双指针解法后，能立刻指出那个「单调变化且有界」的势能量，从而确认它真是 O(n)
  2. 能说清滑动窗口的隐藏前提（数组是否全为正），以及不满足时该换什么工具
  3. 「求最长」与「求最短」的收缩条件和统计位置不再靠试，而是先判断题型再落笔
  4. 能解释单调栈弹出元素为什么安全（完全支配），以及哨兵技巧消掉了哪两类边界判断
  5. 知道 max 没有逆元，因此区间最值不能用前缀和、窗口最值不能加一个减一个
P4
核心数据结构（~6.5 h）
从内核剖析到生产选型
#内容时间
7哈希表内核3.5 h
8堆与 Top-K3 h
✅ 完成标志
  1. 能把「哈希表是 O(1)」这句话补完整，并说出三个限定词各自对应的真实故障
  2. 能解释标准的哪几条要求把 unordered_map 锁死成拉链法，以及 Swiss Table 放弃了什么
  3. 知道 Hash-DoS 的原理，能说出 C++ 里三种修法以及为什么限制参数个数也必须做
  4. 能完整证明自底向上建堆是 Θ(n)，并说清它推不出「堆排序也是 O(n)」
  5. 拿到「Top-K」「流式中位数」「定时器」三类需求，能各自选对结构并说出不选其他方案的理由
  6. 看到无界队列会主动警觉——知道它把背压问题藏到 OOM 才暴露
P5
树与区间结构（~7 h）
每个漂亮的复杂度背后都有一个明确的前提
#内容时间
9树与平衡树3.5 h
10并查集与区间结构3.5 h
✅ 完成标志
  1. 选树遍历序时不再靠记名字，而是问「信息是从上往下传还是从下往上收」
  2. 能推出红黑树的 2 log(n+1) 上界，并说清「删除最多 3 次旋转」为什么让标准库选了它
  3. 能算出为什么 B+ 树把 30 次磁盘 I/O 降到 3~4 次，以及范围扫描为何是它胜过 B 树的关键
  4. 知道 Redis 选跳表和 RocksDB 选跳表是两个不同的理由
  5. 能用势能法说清并查集 α(n) 的来源，并解释为什么可撤销就必须放弃路径压缩
  6. 拿到区间问题先问两句：「修改与查询是否交错」「这个运算可逆吗 / 可重叠合并吗」
P6
图论（~7 h）
难的不是算法，是「这是个图问题」和「图怎么存」
#内容时间
11图遍历与拓扑排序3.5 h
12最短路与最小生成树3.5 h
✅ 完成标志
  1. 能说清为什么有向图环检测需要三种颜色，以及只用 visited 会在哪个反例上误报
  2. 看到「某些移动免费、某些花 1」能立刻想到 0-1 BFS，而不是上 Dijkstra
  3. 拿到「依赖 / 先后」立刻想到拓扑排序，并知道按层剥离顺带给出关键路径长度
  4. 能指出 Dijkstra 正确性证明的哪一步用到了非负性，从而解释负权为何失效
  5. 知道「所有边权加一个大常数」为什么救不了负权图
  6. 能用割性质同时解释 Kruskal 和 Prim，并指出 Prim 与 Dijkstra 代码里那一处关键差别
  7. 拿到最短路问题的第一个动作是问「这图是 DAG 吗」

  7. 理解 border 之后不再需要背 KMP，并能用它顺手求出最小周期
