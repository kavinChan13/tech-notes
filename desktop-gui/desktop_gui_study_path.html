桌面 GUI 与 Qt 学习路径

P1 对象模型与线程：QObject 对象树、信号槽与 moc、QThread 与跨线程通信 → P2 通信与交付：网络与本机 IPC、构建部署与陷阱清单。适合有 C++ 基础、要做工业上位机或仪器软件的工程师。

~14 h前置：C++ 基础 · CMake
P1
对象模型与线程（~7 h）
#内容时间重点
1Qt 核心机制3.5 h对象树所有权、moc 如何实现信号槽、事件循环
2Qt 线程与并发3.5 hmoveToThread 而非继承 QThread、连接类型在 emit 时决定
✅ 阶段检查
  1. 能说清「谁负责 delete」：父子树、栈对象、智能指针三者为什么不能混用
  2. 能画出 emit 到槽执行之间的完整链路，并解释 Queued 连接的参数是怎么传过去的
  3. 能指出「QThread 子类的槽跑在哪个线程」这个经典误区错在哪
P2
通信与交付（~7 h）
#内容时间重点
3Qt 网络与本机 IPC3.5 h粘包半包处理、TLS 证书校验、设备重连状态机
4Qt 工程化与陷阱3.5 hAUTOMOC、Widgets/QML 选型、模型视图性能、部署清单
~14 h
✅ 完成标志
  1. 能独立写出一个带长度前缀的 TCP 收包循环，并说明如何防御超大长度字段
  2. 能设计一个带指数退避与心跳的设备重连状态机，说清每个状态的进入与退出条件
  3. 能解释 undefined reference to vtable 与「找不到平台插件」两类错误的根因
  4. 能就「这个项目用 Widgets 还是 QML」给出有理有据的选型结论
