通信系统与通信协议学习路径

这是一张 Communication Software Engineer Knowledge Map：从基础网络一路走到 5G RAN、核心网 EPC/5GC、前传、eCPRI、O-RAN、NETCONF/YANG，再落到 C/C++ 通信工程、高并发、ARM 平台与线上排错。读完你应能回答"一个现代 4G/5G 通信系统是怎么组成的，以及承载它的软件该怎么写"。

文章依赖关系（知识地图）

最重要的几组"层级 / 前传 / 核心网 / O-RAN / NETCONF / C++ 工程"关系

本主题反复强调下面这几组关系——建议随时回看：

TCP/UDP   → 传输层                 ▼

【C++ 工程线】
报文字节 → 零拷贝解析 (string_view/span)
        → 消息族 (variant) → 协议状态机 (FSM + 定时器)
        → 事件分发 (Reactor / Proactor) → 线程模型 (分片 / per-core)
        → 背压与过载保护 → 平台差异 (ARM 弱内存序) → 排错 (ASan/TSan/长稳)
牢记三条"反直觉"结论：① Open Fronthaul ≠ eCPRI（Open Fronthaul 是 O-RAN 定义的前传接口规范，eCPRI/以太网是它使用的承载技术）；② eCPRI 不是"更快的 TCP"（它是被以太网承载的前传协议，不是传输机制）；③ GTP-U ≠ eCPRI（GTP-U 在回传上搬运已解调的用户 IP 包，eCPRI 在前传上搬运 IQ/时频数据，两者根本不在同一段链路）。
