强化学习概述

五大核心要素

要素符号说明
Agent (智能体)—做决策的主体，学习最优策略
Environment (环境)—Agent 交互的外部世界
State (状态)s ∈ S环境在某时刻的描述
Action (动作)a ∈ AAgent 可执行的操作
Reward (奖励)r ∈ ℝ环境对动作的即时反馈信号

与其他学习范式的区别

特征监督学习无监督学习强化学习
反馈信号标签(label)无反馈奖励(延迟/稀疏)
数据i.i.d. 样本i.i.d. 样本序列决策，非 i.i.d.
目标最小化预测误差发现结构/模式最大化累积奖励
交互无无Agent 动作影响后续状态

核心挑战

  • 探索与利用 (Exploration vs Exploitation)：尝试新动作获取信息 vs 利用已知最优动作获取奖励
  • 延迟奖励 (Delayed Reward)：当前动作的好坏可能要很多步之后才能体现
  • 信用分配 (Credit Assignment)：如何将最终奖励归因到之前的每个决策
  • RL 与监督学习最本质的区别：没有正确标签，只有奖励信号；数据非独立同分布，动作影响后续数据分布
  • 探索-利用困境没有通用最优解，不同场景需要不同策略
  • 信用分配问题是 RL 困难的根源之一，TD 方法和 Eligibility Trace 是典型解法
02

MDP (马尔可夫决策过程)

MDP 由五元组定义： (S, A, P, R, γ)

形式化定义

MDP 由五元组定义：(S, A, P, R, γ)

  • S — 状态空间 (State Space)
  • A — 动作空间 (Action Space)
  • P — 状态转移概率 P(s'|s, a)，给定当前状态和动作，转移到下一状态的概率
  • R — 奖励函数 R(s, a, s')，执行动作后获得的即时奖励
  • γ — 折扣因子 γ ∈ [0, 1]

马尔可夫性质

P(s_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, ...) = P(s_{t+1} | s_t, a_t)

未来状态只依赖于当前状态和动作，与历史无关。这是 MDP 的核心假设。

折扣因子 γ 的意义

  • γ = 0：完全只关注即时奖励（短视）
  • γ = 1：同等重视所有未来奖励（可能导致无穷大回报）
  • 0 < γ < 1：平衡即时与长远奖励；γ 越大越远视
  • 数学意义：保证无穷级数收敛 → G_t = Σ γ^k · r_{t+k+1} 有限
G_t = r_{t+1} + γ·r_{t+2} + γ²·r_{t+3} + ... = Σ_{k=0}^{∞} γ^k · r_{t+k+1}
  • 马尔可夫性质是建模假设，现实中常通过 frame stacking、RNN 等手段逼近
  • γ 既有经济学解释（时间偏好）也有数学作用（保证收敛）
  • 区分 MDP（完全可观测）vs POMDP（部分可观测）
03

Bellman 方程

在状态 s 下，遵循策略 π 所能获得的期望累积回报

状态值函数 V(s)

V_π(s) = E_π[G_t | S_t = s] = E_π[r_{t+1} + γ·V_π(S_{t+1}) | S_t = s]

在状态 s 下，遵循策略 π 所能获得的期望累积回报。

动作值函数 Q(s, a)

Q_π(s, a) = E_π[G_t | S_t = s, A_t = a] = E_π[r_{t+1} + γ·Q_π(S_{t+1}, A_{t+1}) | S_t = s, A_t = a]

在状态 s 执行动作 a 后，遵循策略 π 的期望累积回报。

Bellman 期望方程推导

V 和 Q 的递推关系：

V_π(s) = Σ_a π(a|s) · Q_π(s, a) Q_π(s, a) = R(s,a) + γ · Σ_{s'} P(s'|s,a) · V_π(s')

合并得到：

V_π(s) = Σ_a π(a|s) · [R(s,a) + γ · Σ_{s'} P(s'|s,a) · V_π(s')]

Bellman 最优方程

V*(s) = max_a [R(s,a) + γ · Σ_{s'} P(s'|s,a) · V*(s')] Q*(s,a) = R(s,a) + γ · Σ_{s'} P(s'|s,a) · max_{a'} Q*(s',a')

V* 与 Q* 的关系

V*(s) = max_a Q*(s, a) Q*(s, a) = R(s,a) + γ · Σ_{s'} P(s'|s,a) · V*(s')
  • Bellman 方程体现了动态规划的递推思想：当前值 = 即时奖励 + 折扣后的未来值
  • 期望方程是给定策略的；最优方程用 max 替代了期望（对应最优策略）
  • Q* 直接给出最优动作选择：π*(s) = argmax_a Q*(s,a)
  • 非线性的 max 操作使最优方程没有解析解，需要迭代求解

策略与值函数

确定性策略 vs 随机策略

类型定义特点
确定性策略π(s) = a给定状态输出唯一动作；简单高效
随机策略π(a|s) = P(A=a|S=s)输出动作概率分布；天然具备探索性

三大方法分类

类别核心思想代表算法优缺点
Value-based学习值函数，隐式导出策略Q-Learning, DQN, Dueling DQN离散动作空间好用；连续动作困难
Policy-based直接参数化并优化策略REINFORCE, PPO (纯策略)支持连续动作；高方差
Actor-Critic同时学习策略(Actor)和值函数(Critic)A2C, A3C, PPO, SAC, TD3兼顾两者优势；减少方差
  • 最优确定性策略一定存在（MDP定理），但随机策略在 POMDP 和博弈中可能更优
  • Value-based 方法在离散动作空间有保证，连续空间需要 Policy-based
  • Actor-Critic 是当前主流：Actor 负责决策，Critic 负责评估，形成梯度低方差估计
  • PPO 兼具 Policy-based 和 Actor-Critic 特性，是工业界最常用的算法之一

动态规划 (DP)

DP 方法要求 完全知道环境模型 （即转移概率 P 和奖励函数 R），属于 Model-ba…

前提条件

DP 方法要求完全知道环境模型（即转移概率 P 和奖励函数 R），属于 Model-based 方法。

策略评估 (Policy Evaluation)

V_{k+1}(s) = Σ_a π(a|s) · [R(s,a) + γ · Σ_{s'} P(s'|s,a) · V_k(s')]

反复迭代直到 V 收敛 → 得到给定策略 π 的真实值函数 V_π。

策略改进 (Policy Improvement)

π'(s) = argmax_a Q_π(s, a) = argmax_a [R(s,a) + γ · Σ_{s'} P(s'|s,a) · V_π(s')]

对当前值函数贪心地选择动作 → 得到更好的策略 π' ≥ π。

策略迭代 vs 值迭代

方法流程特点
策略迭代评估 → 改进 → 评估 → 改进 → ...每轮完整评估到收敛；迭代次数少但每轮计算量大
值迭代直接迭代 Bellman 最优方程每轮只做一次更新就改进；等价于截断的策略迭代
值迭代：V_{k+1}(s) = max_a [R(s,a) + γ · Σ_{s'} P(s'|s,a) · V_k(s')]
  • DP 是理论基石但实际不常直接使用（因为很少完全已知环境）
  • 策略迭代的收敛性有严格数学证明（策略单调改进定理）
  • 值迭代本质是策略评估只做一步就跳到改进，效率更高
  • 两者时间复杂度均为 O(|S|²|A|) 每次迭代
06

蒙特卡洛方法 (MC)

其中 G_t 是从状态 s 开始到 Episode 结束的实际累积回报

核心特点

  • Model-free：不需要环境的转移概率，通过采样学习
  • 完整 Episode：必须等一个 Episode 结束才能更新
  • 无偏估计：直接用实际回报更新，不引入 Bootstrap 偏差

MC 策略评估

V(s) ← V(s) + α · [G_t - V(s)]

其中 G_t 是从状态 s 开始到 Episode 结束的实际累积回报。

First-visit vs Every-visit

方法规则特点
First-visit MC每个 Episode 中，状态 s 第一次被访问时记录 G_t无偏；理论保证更强
Every-visit MC每次访问状态 s 都记录 G_t渐近无偏；利用更多数据，实践中常更好
  • MC 方法方差大（一整条轨迹的随机性累积）但无偏
  • 只适用于 Episodic 任务（有终止状态），不适合 Continuing 任务
  • MC 是 TD 方法的特例（n=∞ 时 TD(n) = MC）
  • Off-policy MC 用重要性采样修正，但方差可能爆炸
07

时序差分 (TD Learning)

TD(0) 更新规则

V(S_t) ← V(S_t) + α · [r_{t+1} + γ·V(S_{t+1}) - V(S_t)] ↑ TD Target ↑ TD Error (δ_t)

TD vs MC 对比

维度TDMC
更新时机每步更新 (online)Episode 结束后
Bootstrapping是（用估计值更新估计值）否（用实际回报）
偏差 (Bias)有偏（因为 Bootstrap）无偏
方差 (Variance)低方差（只用一步随机性）高方差（整条轨迹随机性）
收敛性收敛到 V_π（线性函数逼近下有保证）收敛到 V_π（需完整 Episode）
适用范围Episodic + Continuing仅 Episodic

核心概念

  • TD Target：r_{t+1} + γ·V(S_{t+1})，是对真实回报 G_t 的一步估计
  • TD Error (δ)：TD Target - V(S_t)，衡量预测与（部分）现实的差距
  • Bootstrapping：用当前估计来更新估计，不等待真实结果

TD 家族扩展

  • SARSA：On-policy TD → Q(s,a) ← Q(s,a) + α·[r + γ·Q(s',a') - Q(s,a)]
  • Q-Learning：Off-policy TD → Q(s,a) ← Q(s,a) + α·[r + γ·max_a' Q(s',a') - Q(s,a)]
  • TD(λ)：通过 Eligibility Trace 统一 TD(0) 与 MC
  • TD 是 RL 中最核心的思想之一：从不完整经验中学习
  • 偏差-方差权衡：TD 牺牲无偏性换取低方差和 online 更新能力
  • Q-Learning 是 off-policy 的（行为策略≠目标策略），SARSA 是 on-policy 的
  • TD(λ) 中 λ=0 退化为 TD(0)，λ=1 退化为 MC

探索与利用

ε-greedy 策略

π(a|s) = { 1-ε+ε/|A| if a = argmax Q(s,a) { ε/|A| otherwise
  • 以概率 1-ε 选择当前最优动作（利用）
  • 以概率 ε 均匀随机选择动作（探索）
  • 通常 ε 随训练衰减：初期多探索，后期多利用

UCB (Upper Confidence Bound)

A_t = argmax_a [Q_t(a) + c · √(ln t / N_t(a))]
  • 第一项：利用（当前估计值）
  • 第二项：探索奖励（访问次数少的动作获得更大 bonus）
  • c 控制探索程度；理论上可达到对数级 regret

Boltzmann Exploration (Softmax)

π(a|s) = exp(Q(s,a)/τ) / Σ_{a'} exp(Q(s,a')/τ)
  • τ → 0：趋近贪心（确定性）
  • τ → ∞：趋近均匀随机
  • 温度参数 τ 控制探索-利用平衡

探索策略对比

策略优点缺点适用场景
ε-greedy简单；广泛使用探索无方向性；不考虑不确定性通用基线策略
UCB理论保证；有方向性探索需维护计数；难扩展到大状态空间Bandit问题；小状态空间
Boltzmann按价值差异分配探索概率对 Q 值尺度敏感；τ 需调参动作价值差异明显时
Curiosity-driven内在动机；适合稀疏奖励计算开销大；可能被噪声吸引大型探索问题
  • ε-greedy 是最常用的基线，但探索没有方向性——所有非最优动作被等概率选择
  • UCB 在 Multi-Armed Bandit 中有最优 regret 保证，但难以直接扩展到复杂 RL
  • 深度 RL 中常用技巧：Noisy Networks、ICM（好奇心驱动）、Count-based exploration
  • 探索是 RL 中尚未完全解决的根本性问题

📋 Q&A（Top 10）

核心区别有三点：
Q1：强化学习与监督学习最本质的区别是什么？

核心区别有三点：

  1. 反馈形式不同：监督学习有"正确答案"(label)，RL 只有标量奖励信号且可能延迟
  2. 数据分布非静态：RL 中 Agent 的动作会改变后续数据分布，不满足 i.i.d. 假设
  3. 序列决策：RL 需考虑长期累积回报，而非单步预测准确率

此外，RL 存在探索-利用困境——Agent 必须主动尝试才能获得新信息。

Q2：什么是马尔可夫性质？为什么它对 RL 很重要？

马尔可夫性质：P(s_{t+1}|s_t, a_t) = P(s_{t+1}|s_1,...,s_t, a_1,...,a_t)，即给定当前状态，未来与过去条件独立。

重要性：

  • 使得 Bellman 方程成立，从而可以用递推方式求解
  • 大大简化了问题的计算复杂度（无需记录完整历史）
  • 所有 DP、TD、MC 方法的理论基础都建立在此之上

实际应用中，当状态不满足马尔可夫性时，可用 frame stacking、LSTM/Transformer 等方法将观测转化为近似马尔可夫状态。

Q3：解释 Bellman 方程，并说明其期望形式与最优形式的区别。

Bellman 方程揭示了值函数的递推结构：当前状态的价值 = 即时奖励 + 折扣后继状态价值。

期望形式（评估给定策略 π）：

V_π(s) = Σ_a π(a|s)[R(s,a) + γΣ_{s'}P(s'|s,a)V_π(s')]

最优形式（寻找最优策略）：

V*(s) = max_a[R(s,a) + γΣ_{s'}P(s'|s,a)V*(s')]

区别：期望形式用 Σ_a π(a|s) 加权（线性方程组，可直接求解）；最优形式用 max（非线性，需迭代）。

Q4：Value-based、Policy-based、Actor-Critic 各自优缺点？

Value-based（如 DQN）：

  • 优：样本效率较高；收敛稳定（有目标网络等技巧时）
  • 缺：只能处理离散动作空间；难以表达随机策略

Policy-based（如 REINFORCE）：

  • 优：天然支持连续动作和随机策略；优化目标直接
  • 缺：高方差；样本效率低；容易收敛到局部最优

Actor-Critic（如 PPO, SAC）：

  • 优：Critic 降低方差；Actor 支持连续动作；平衡两者
  • 缺：更复杂；两个网络需要协调训练；调参更难
Q5：TD 学习和 MC 学习的本质区别？各自适合什么场景？

本质区别：TD 用 Bootstrapping（用估计更新估计），MC 用完整实际回报。

TD有偏低方差、每步可更新、适合 Continuing 任务
MC无偏高方差、需完整 Episode、适合 Episodic 任务

场景选择：

  • Episode 很长或无终止 → 用 TD
  • 环境有高随机性且需要准确估计 → MC 或多步 TD
  • 需要在线学习、实时更新 → TD
  • 实际中 TD(λ) 统一两者，λ 作为可调超参数
Q6：Q-Learning 和 SARSA 的区别？什么时候用哪个？

核心区别：Off-policy vs On-policy

  • Q-Learning：Q(s,a) ← Q(s,a) + α[r + γ·max_a' Q(s',a') - Q(s,a)]
    目标策略是贪心策略（max），行为策略可以是任意探索策略 → Off-policy
  • SARSA：Q(s,a) ← Q(s,a) + α[r + γ·Q(s',a') - Q(s,a)]
    用实际执行的下一动作 a' → On-policy

使用场景：

  • Q-Learning：更激进，学到的是最优策略，适合离线学习或可以安全探索的环境
  • SARSA：更保守（考虑了探索带来的风险），适合 cliff-walking 等危险环境
Q7：折扣因子 γ 的作用是什么？设置为不同值有何影响？

作用：

  1. 数学层面：保证无穷级数 G_t = Σγ^k·r_{t+k+1} 收敛
  2. 建模层面：体现对未来奖励的重视程度（时间偏好）
  3. 算法层面：影响值函数的传播速度和学习稳定性

不同取值：

  • γ=0：完全贪心，只看即时奖励，忽略长期后果
  • γ≈1（如0.99）：远视，适合需要长期规划的任务，但训练更慢
  • γ=1：无折扣，仅在 Episodic 有限长度任务中安全使用

实践中常用 γ=0.99 或 γ=0.995。

Q8：什么是 Bootstrapping？它带来了什么好处和问题？

Bootstrapping：用当前估计值来更新估计值（而非等待真实结果）。TD 方法的核心。

好处：

  • 不需要等待 Episode 结束，支持 online/incremental 更新
  • 低方差（只依赖一步转移的随机性）
  • 适用于 Continuing 任务
  • 通常收敛更快（特别是在马尔可夫环境中）

问题：

  • 引入偏差（初始估计不准时会传播错误）
  • 在函数逼近时可能不收敛（deadly triad 问题）
  • 对初始值敏感
Q9：策略迭代和值迭代的区别与联系？

策略迭代：

  1. 策略评估：完整计算 V_π 直到收敛
  2. 策略改进：对 V_π 贪心得到 π'
  3. 重复直到策略不变

值迭代：

  1. 直接迭代 Bellman 最优方程：V(s) ← max_a[R+γΣP·V(s')]
  2. 收敛后提取策略

联系：值迭代 = 策略评估只做1步就改进 = 截断的策略迭代。两者都保证收敛到最优策略。

实践选择：状态空间小时策略迭代通常更快收敛（迭代次数少）；状态空间大时值迭代每步更轻量。

Q10：ε-greedy 的局限性是什么？有哪些更好的探索方法？

ε-greedy 的局限：

  • 探索无方向性：所有非最优动作被等概率选择，不考虑不确定性
  • 探索量固定（或需要手动调度 ε 衰减）
  • 在高维动作空间中效率低
  • 不适合需要有结构化探索的难探索环境

更好的方法：

  • UCB/Thompson Sampling：根据不确定性引导探索
  • Noisy Networks：在网络参数中加入可学习噪声
  • ICM (Intrinsic Curiosity Module)：用预测误差作为内在奖励
