01

Q-Learning

Q-Learning 是一种 Off-policy 的时序差分（TD）控制算法

1.1 Off-policy TD 控制

Q-Learning 是一种 Off-policy 的时序差分（TD）控制算法。它直接学习最优动作价值函数 Q*(s,a)，无需知道环境的转移概率。

  • Off-policy：行为策略（用于探索）与目标策略（用于学习）分离
  • 行为策略通常用 ε-greedy，目标策略为贪心策略
  • 相比 On-policy（如 SARSA），Off-policy 更灵活但方差可能更大

1.2 Q 值更新公式

Q(s, a) ← Q(s, a) + α [ r + γ · max_a' Q(s', a') − Q(s, a) ]

其中：

  • α — 学习率
  • γ — 折扣因子
  • r + γ · max_a' Q(s', a') — TD 目标（使用 max 是关键区别）
  • r + γ · max_a' Q(s', a') − Q(s, a) — TD 误差

1.3 Q-Table

在表格形式中，Q(s,a) 用一个 |S|×|A| 的表格存储，适用于离散且有限的状态-动作空间。

# Q-Table 更新伪代码
Initialize Q(s, a) arbitrarily
for each episode:
    s = initial state
    while s is not terminal:
        a = ε-greedy(Q, s)
        take action a, observe r, s'
        Q(s,a) += α * (r + γ * max(Q(s',:)) - Q(s,a))
        s = s'

1.4 收敛性保证

在满足以下条件时，Q-Learning 能收敛到最优 Q*：

  • 所有状态-动作对被无限次访问
  • 学习率满足 Robbins-Monro 条件：Σα = ∞, Σα² < ∞
  • MDP 满足有限状态、有限动作

1.5 Q-Learning vs SARSA 对比

特性Q-Learning (Off-policy)SARSA (On-policy)
更新目标max_a' Q(s', a')Q(s', a') ← 实际选的 a'
学习对象最优策略当前策略
探索影响探索不影响学习目标探索直接影响学习
安全性可能学到"冒险"策略倾向"安全"策略
收敛速度通常更快可能更慢但更稳定

💡 知识要点

  • Q-Learning 用 max 使其成为 Off-policy；SARSA 用实际下一步动作使其为 On-policy
  • Off-policy 意味着可以从其他策略（甚至随机策略）的经验中学习
  • Q-Learning 在 cliff-walking 中会走悬崖边（激进），SARSA 会绕远路（保守）
  • Q-Table 的局限：状态空间大时表格爆炸，无法泛化到未见过的状态

DQN (Deep Q-Network)

用 深度神经网络 （参数为 θ）来近似 Q 函数：Q(s, a

2.1 核心思想

用深度神经网络（参数为 θ）来近似 Q 函数：Q(s, a; θ) ≈ Q*(s, a)，解决 Q-Table 无法处理高维/连续状态空间的问题。

2.2 网络架构

  • 输入：状态 s（如 Atari 中连续 4 帧灰度图 84×84×4）
  • 输出：所有动作的 Q 值向量 [Q(s,a₁), Q(s,a₂), ..., Q(s,aₙ)]
  • 一次前向传播得到所有动作的 Q 值，高效选择最优动作

2.3 Atari 游戏突破

DeepMind 2013：首次用 DQN 在 Atari 游戏上达到人类水平（NIPS Workshop）

DeepMind 2015：Nature 论文，49 款 Atari 游戏中 29 款超越人类专家

关键创新：经验回放 + 目标网络 使得深度网络+RL训练稳定

2.4 DQN 损失函数

L(θ) = E[(r + γ · max_a' Q(s', a'; θ⁻) − Q(s, a; θ))²]

其中 θ⁻ 为目标网络参数（周期性从 θ 复制）。

💡 知识要点

  • DQN = Q-Learning + Deep Neural Network + Experience Replay + Target Network
  • 网络输出是所有动作的 Q 值（非单个 Q 值），这样选 argmax 只需一次前向传播
  • 原始 DQN 使用 CNN 处理图像像素输入，证明端到端学习可行
  • DQN 的两大核心技巧解决了"非平稳目标"和"数据相关性"两大难题

经验回放 (Experience Replay)

# Replay Buffer 结构 class ReplayBuffer: def __i…

3.1 为什么需要经验回放

  • 打破数据相关性：连续采集的样本高度相关（时间相关性），违反了 SGD 的 i.i.d. 假设
  • 提高样本效率：每个 transition 可被多次使用，而非用完即丢
  • 平滑数据分布：从大量历史数据中均匀采样，避免策略突变导致的灾难性遗忘

3.2 Replay Buffer

# Replay Buffer 结构
class ReplayBuffer:
    def __init__(self, capacity):
        self.buffer = deque(maxlen=capacity)
    
    def push(self, state, action, reward, next_state, done):
        self.buffer.append((state, action, reward, next_state, done))
    
    def sample(self, batch_size):
        return random.sample(self.buffer, batch_size)

# 典型容量：10^5 ~ 10^6 transitions

3.3 优先经验回放 (PER)

不是均匀采样，而是按 TD 误差大小确定采样优先级：

  • TD 误差大 → 还没学好 → 应更频繁被采样
  • 优先级：p_i = |δ_i| + ε（加 ε 防止优先级为 0）
  • 采样概率：P(i) = p_i^α / Σ p_k^α
  • 需要 重要性采样权重 (IS) 来修正偏差：w_i = (N · P(i))^{-β}

💡 知识要点

  • 经验回放打破了时间相关性，使训练更稳定；Off-policy 特性使其可行（On-policy 不能用旧数据）
  • PER 用 SumTree 数据结构实现 O(log N) 采样
  • PER 引入偏差（非均匀采样），需要 IS 权重修正；β 从小逐渐退火到 1
  • Buffer 太小 → 过拟合近期经验；太大 → 包含过时策略的数据
04

目标网络 (Target Network)

如果用同一个网络计算 TD 目标和当前 Q 值：

4.1 为什么需要目标网络

如果用同一个网络计算 TD 目标和当前 Q 值：

  • 移动目标问题：更新 θ 时，TD 目标也在变 → 追逐一个不断移动的目标
  • 训练不稳定：可能导致 Q 值发散或剧烈震荡
  • 正反馈回路：Q 值增大 → 目标增大 → Q 值继续增大 → 爆炸

4.2 解决方案

使用一个参数延迟更新的目标网络 Q(s, a; θ⁻)：

TD Target = r + γ · max_a' Q(s', a'; θ⁻) ← 用 θ⁻ 而非 θ

4.3 硬更新 vs 软更新

方式公式特点
硬更新 (Hard)每 C 步：θ⁻ ← θ原始 DQN 使用，C 通常 10000 步
软更新 (Soft/Polyak)每步：θ⁻ ← τθ + (1-τ)θ⁻τ 很小（如 0.005），更平滑

💡 知识要点

  • 目标网络的核心是"暂时固定目标"，使回归问题有一个稳定的标签
  • 硬更新简单但更新瞬间有跳变；软更新平滑但引入了更多超参数
  • 没有目标网络时 DQN 完全无法训练，这是 DQN 成功的关键之一
  • Actor-Critic 中的 Critic 目标网络同理（如 DDPG、TD3、SAC）

Double DQN

max 操作系统性地导致 Q 值 过估计 (Overestimation) ：

5.1 DQN 的过估计问题

max 操作系统性地导致 Q 值过估计 (Overestimation)：

  • max_a Q(s', a) 既用 Q 选动作，又用同一个 Q 评估该动作的价值
  • 噪声/误差总是向上偏 → Q 值被高估 → 次优策略
  • 类比：同一份试卷既出题又评分 → 分数虚高

5.2 Double DQN 解决思路

核心：选择与评估分离

DQN: Y = r + γ · Q(s', argmax_a' Q(s', a'; θ); θ⁻) ← 同一个 θ 选和评估 Double DQN: Y = r + γ · Q(s', argmax_a' Q(s', a'; θ); θ⁻) ← θ 选动作，θ⁻ 评估
  • 在线网络 θ：负责选择最优动作 a* = argmax_a' Q(s', a'; θ)
  • 目标网络 θ⁻：负责评估该动作的价值 Q(s', a*; θ⁻)
  • 只需改一行代码，无额外计算成本

💡 知识要点

  • 过估计根源：max E[X] ≤ E[max X]（Jensen 不等式相关），噪声导致 max 有正偏差
  • Double DQN 不消除过估计，只是减轻——因为两个网络的误差不完全相同
  • 实现代价极低：改一行 argmax 的来源即可
  • 在线网络选错了也没关系，因为目标网络评估时会给低分

Dueling DQN

6.1 架构设计

将 Q 值分解为值流 (Value Stream) 和优势流 (Advantage Stream)：

Q(s, a; θ, α, β) = V(s; θ, β) + A(s, a; θ, α) − mean_a' A(s, a'; θ, α)
  • V(s)：状态值——"在这个状态有多好"
  • A(s, a)：优势——"这个动作比平均好多少"
  • 减去均值使 V 和 A 可辨识（uniquely identifiable）

6.2 为什么有效

  • 很多状态下动作差异不大：此时学好 V(s) 就够了，无需精确区分每个动作
  • 例如：Atari 中大部分帧不需要做任何操作，只需知道当前状态好不好
  • Value Stream 可以更频繁地更新（每次经验都更新 V），提高样本效率
  • 网络结构的先验知识 (inductive bias) 帮助更好地泛化

6.3 网络结构

Dueling DQN 网络结构 · 拆成 Value 流与 Advantage 流
Input (State)
分成两支各接一层 FC：
Value 流V(s) · 标量
Advantage 流A(s,a) · |A| 维
Q(s,a) = V(s) + A(s,a) − mean(A)

💡 知识要点

  • Dueling 改的是网络架构，不改损失函数和训练方式
  • 减去均值（或 max）是为了可辨识性：否则 V 和 A 有无穷多分解
  • 特别适合动作空间大但很多动作效果相似的场景
  • 可以和 Double DQN、PER 等正交地组合使用

Rainbow DQN

DeepMind 2017 年论文，将 DQN 的 6 种改进统一到一个 agent 中：

7.1 六种改进的集成

DeepMind 2017 年论文，将 DQN 的 6 种改进统一到一个 agent 中：

改进解决的问题核心思想
Double DQNQ 值过估计选择与评估分离
Dueling DQN动作无关的状态价值学习V + A 分解
PER均匀采样效率低按 TD 误差优先采样
Multi-step Learning单步 TD 偏差大n-step return 降低偏差
Distributional RL (C51)只学期望值丢失信息学习 Q 值的完整分布
Noisy Netε-greedy 探索效率低网络参数加噪声实现探索

7.2 各改进的贡献

  • 消融实验显示：PER 和 Multi-step 贡献最大
  • 去掉 Distributional 性能下降最多
  • 所有组件结合后性能远超任何单一改进

7.3 Multi-step Return

G_t^{(n)} = r_t + γr_{t+1} + γ²r_{t+2} + ... + γⁿ · max_a Q(s_{t+n}, a; θ⁻)

n-step 在偏差(bias)和方差(variance)之间取折中：n=1 是 TD，n=∞ 是 MC。

7.4 Distributional RL (C51)

不学 E[Q(s,a)]，而是学 Q 值的概率分布 Z(s,a)：

  • 将 [V_min, V_max] 离散化为 51 个 atom
  • 输出每个 atom 的概率 → 完整的 return 分布
  • 用 KL 散度（而非 MSE）作为损失函数

7.5 Noisy Net

在全连接层权重中添加可学习的噪声参数：

y = (μ_w + σ_w ⊙ ε_w)x + (μ_b + σ_b ⊙ ε_b)

探索程度由网络自动学习，无需手调 ε 衰减计划。

💡 知识要点

  • Rainbow 证明了这些改进是正交互补的，组合使用效果最好
  • 面试中问 Rainbow 通常考察你对每个组件的理解深度
  • Multi-step 为什么有效：减少偏差，加速信号传播（reward 信号更快回传）
  • Distributional RL 的直觉：知道分布比只知道均值好（风险敏感决策）
08

DQN 的局限

Policy Gradient 的优势：

8.1 只能处理离散动作空间

  • DQN 输出 = 每个动作的 Q 值 → 必须枚举所有动作
  • 连续动作空间（如机器人关节角度）→ 无法枚举，argmax 无法直接计算
  • 离散化连续空间？维度灾难：3个关节 × 100个离散值 = 100³ = 10⁶ 个动作

8.2 高维动作空间困难

  • 即使是离散动作，维度高时 Q 值输出层参数爆炸
  • 组合动作空间（如 RTS 游戏中多单位同时行动）更是不可行
  • 探索效率极低——大部分动作从未被充分探索

8.3 其他局限

  • 确定性策略：DQN 输出确定性的 argmax，无法自然地表示随机策略
  • 样本效率：虽有 Replay Buffer，但仍需大量交互
  • 过估计：虽有 Double DQN 缓解，但问题依然存在

8.4 为什么引出 Policy Gradient

Policy Gradient 的优势：

  • 直接参数化策略 π(a|s; θ)，天然支持连续动作空间
  • 可以输出动作的概率分布 → 自然支持随机策略
  • 可以处理高维/组合动作空间
  • 在某些问题中收敛性更好（策略空间比值函数空间更平滑）

演进路线：

Q-Learning → DQN → (局限) → Policy Gradient → Actor-Critic → DDPG/TD3/SAC

💡 知识要点

  • DQN 局限的本质：需要对动作取 max/argmax → 必须枚举所有动作
  • 连续控制任务（机器人、自动驾驶）必须用 Policy Gradient 类方法
  • Value-Based 和 Policy-Based 不是对立的 → Actor-Critic 结合两者优势
  • DQN 适合：Atari（离散、低维动作）；不适合：MuJoCo（连续、高维动作）

十道Q&A

本质区别 ：更新目标不同
Q1：Q-Learning 和 SARSA 的本质区别是什么？各适用什么场景？

本质区别：更新目标不同。Q-Learning 用 max_a' Q(s',a')（最优动作），SARSA 用 Q(s',a')（实际执行的动作）。

Q-Learning (Off-policy)：目标是找最优策略，探索不影响学习目标，适合仿真环境中大量试错。
SARSA (On-policy)：学习当前策略（含探索）的价值，更"安全保守"，适合真实环境中不能承受风险的场景（如机器人不能掉悬崖）。

经典例子：Cliff Walking 中 Q-Learning 走悬崖边最短路（偶尔掉下去），SARSA 绕远但安全。

Q2：DQN 相比传统 Q-Learning 的核心创新是什么？

DQN 有两大核心创新使深度网络+RL训练稳定：

1. 经验回放 (Experience Replay)：将 transition 存入 Buffer 后随机采样，打破样本时间相关性，满足 SGD 的 i.i.d. 假设，提高样本利用率。

2. 目标网络 (Target Network)：用一个参数延迟更新的网络计算 TD 目标，避免"追逐移动目标"导致的训练发散。

这两个技巧解决了深度网络做函数近似时的两大根本问题：数据非独立同分布、训练目标非平稳。

Q3：为什么 DQN 会过估计 Q 值？Double DQN 如何解决？

过估计原因：max 操作 + 函数近似噪声。Q(s',a') 对不同 a' 有正负误差，取 max 总是选到正误差最大的那个 → 系统性高估。数学上：E[max(X₁,...,Xₙ)] ≥ max(E[X₁],...,E[Xₙ])。

Double DQN 解决思路：选择和评估分离。用在线网络 θ 选动作 a* = argmax Q(s',a';θ)，用目标网络 θ⁻ 评估该动作价值 Q(s',a*;θ⁻)。两个网络的噪声独立，不太可能同时高估同一个动作。

实现上只改一行代码，计算成本不变。

Q4：经验回放为什么只能用于 Off-policy 算法？

根本原因：Replay Buffer 中存的是旧策略采集的数据。

Off-policy（如 Q-Learning/DQN）：学习目标（最优策略）与数据采集策略无关，旧数据仍然可以提供有效的学习信号。

On-policy（如 SARSA、REINFORCE、PPO）：学习的是当前策略的价值，旧策略产生的数据对当前策略来说是有偏的（分布不匹配）。虽然可以用重要性采样修正，但方差很大。

PPO 的做法是折中：用一小段旧数据（只旧几步），通过 clipping 限制偏差。

Q5：目标网络的更新频率如何选择？软更新和硬更新的 trade-off？

硬更新：每 C 步复制 θ→θ⁻。C 太小 → 接近无目标网络，不稳定；C 太大 → 目标太旧，学习慢。原始 DQN 用 C=10000。

软更新：每步 θ⁻←τθ+(1-τ)θ⁻，τ∈[0.001, 0.01]。更新平滑无跳变，但需要额外超参数 τ。

选择建议：
- 离散动作 DQN：硬更新即可（简单有效）
- 连续控制 Actor-Critic（DDPG/TD3/SAC）：通常用软更新（τ=0.005）
- 一般来说，τ 越小越稳定但学得越慢

Q6：Dueling DQN 中为什么要减去 Advantage 的均值？

可辨识性问题：Q = V + A 的分解不唯一。给 V 加常数 c，A 减常数 c，Q 不变。模型无法区分"状态好"还是"动作好"。

解决方案：强制约束 A 的均值为 0（或 max 为 0）：
Q(s,a) = V(s) + A(s,a) - mean_a' A(s,a')

这样 V(s) 就是 Q(s,·) 的均值，A(s,a) 就是偏离均值的程度。

实践中用 mean 比 max 更稳定（梯度更平滑）。

Q7：Rainbow DQN 各组件的消融实验结论是什么？

去掉后性能下降最多的（最重要）：
1. Distributional (C51) — 学习分布提供了更丰富的学习信号
2. Multi-step — n步 return 加速信号传播
3. PER — 聚焦困难样本

去掉后影响较小的：
4. Noisy Net（ε-greedy 也还行）
5. Dueling（架构改进，锦上添花）
6. Double（过估计问题在其他组件帮助下减轻了）

关键结论：这些改进互补而非冗余，组合效果远超任何单一改进。

Q8：PER（优先经验回放）的重要性采样权重是什么？为什么需要？

为什么需要 IS 权重：PER 改变了采样分布（非均匀），导致梯度估计有偏差。高优先级样本被过度采样 → 对应梯度被过度放大 → 策略被这些样本主导。

IS 权重修正：w_i = (1/(N·P(i)))^β，给高优先级样本降权，恢复无偏估计。

β 退火：β 从较小值（如 0.4）逐渐增到 1。训练初期允许偏差（有利于快速学习），后期偏差修正确保收敛。

实际影响：不加 IS 权重会导致训练后期不稳定或收敛到次优解。

Q9：DQN 为什么不能处理连续动作空间？有哪些解决方案？

根本原因：DQN 需要计算 max_a Q(s,a)，这要求枚举所有动作。连续空间无法枚举。

解决方案：
1. 离散化：简单但维度灾难（指数爆炸）
2. NAF (Normalized Advantage Function)：将 Q 限制为动作的二次函数，解析求 argmax
3. DDPG：用一个额外网络（Actor）直接输出 argmax_a Q(s,a)
4. Policy Gradient：绕过 Q 值，直接优化策略 → REINFORCE、PPO、SAC

实际最常用：Actor-Critic 方法（DDPG → TD3 → SAC）

Q10：从 DQN 到 Actor-Critic 的演进逻辑是什么？

演进逻辑：

Step 1: DQN 的成功 — 证明了深度 RL 可行，但局限于离散动作。

Step 2: 连续动作的需求 — 机器人、自动驾驶等需要连续控制。

Step 3: Policy Gradient — 直接优化策略，支持连续动作，但方差大、样本效率低。

Step 4: Actor-Critic 结合 — Actor（策略网络）处理动作输出 + Critic（Q网络）降低方差：
- DDPG：确定性策略 + Q-Critic（DQN 思想用于连续空间）
- TD3：解决 DDPG 的过估计和脆弱性
- SAC：最大熵框架，平衡探索与利用

本质上 Actor-Critic 是 Value-Based 和 Policy-Based 的统一。
