· MARL 概述

在 MARL 中，每个 agent 面对的环境不仅包含物理世界，还包含 其他 agent 的…

单智能体 vs 多智能体

维度单智能体 RL多智能体 RL
环境建模MDP（马尔可夫决策过程）Markov Game / Stochastic Game
策略数量1 个策略 πN 个策略 π₁…πₙ
环境稳定性环境平稳（transition 不变）非平稳：其他 agent 的策略也在变
收敛保证较成熟的理论保证理论保证较弱

环境非平稳性问题

在 MARL 中，每个 agent 面对的环境不仅包含物理世界，还包含其他 agent 的策略。当多个 agent 同时学习时，从单个 agent 的视角来看，环境的 transition function 会随着其他 agent 策略的更新而改变，这就是非平稳性（Non-stationarity）问题。

这意味着：单个 agent 的最优策略取决于其他 agent 的策略，而其他 agent 也在同时调整 → 形成了一个移动的目标（moving target）。

场景分类

场景类型目标关系典型例子
合作 Cooperative所有 agent 共享一个全局奖励多机器人搬运、Overcooked 合作烹饪
竞争 Competitive一个 agent 的收益是另一个的损失棋类对弈、零和博弈
混合 Mixed既有合作又有竞争足球、交通路口博弈、StarCraft 团战
  • 非平稳性是 MARL 区别于单智能体 RL 的最核心问题——需要能清晰阐述其成因和影响
  • 环境从 MDP 扩展到 Markov Game（也叫 Stochastic Game），需额外定义联合动作空间和各 agent 的奖励函数
  • 场景分类决定了算法设计思路：合作 → 共享奖励/值分解；竞争 → 自博弈/Minimax；混合 → 需要更复杂的均衡概念
02

· 博弈论基础

在一个 N 人博弈中，策略组合 (π₁*, π₂*, …, πₙ*) 构成纳什均衡，当且仅当…

纳什均衡（Nash Equilibrium）

在一个 N 人博弈中，策略组合 (π₁*, π₂*, …, πₙ*) 构成纳什均衡，当且仅当没有任何一个 agent 能通过单方面改变自己的策略来获得更高收益：

∀i, ∀πᵢ : Rᵢ(π₁*, …, πᵢ*, …, πₙ*) ≥ Rᵢ(π₁*, …, πᵢ, …, πₙ*)

零和博弈 vs 一般和博弈

类型特征均衡概念例子
零和博弈R₁ + R₂ = 0，完全对立Minimax 值唯一围棋、象棋、剪刀石头布
一般和博弈收益之和不固定可能有多个 Nash 均衡囚徒困境、交通博弈

Minimax 定理

在两人零和博弈中，最优策略就是最大化最坏情况下的收益：

V* = max_π₁ min_π₂ R₁(π₁, π₂) = min_π₂ max_π₁ R₁(π₁, π₂)

这是零和博弈的核心定理——max-min = min-max，保证了纳什均衡的唯一性（在混合策略意义下）。

Pareto 最优

一个策略组合是 Pareto 最优的，如果不存在另一个策略组合能在不降低任何 agent 收益的前提下，严格提升某个 agent 的收益。Pareto 最优不一定是纳什均衡（经典的例子：囚徒困境中双方合作是 Pareto 最优，但不是纳什均衡）。

  • 纳什均衡：没有人能通过单方面偏离获利——这是最核心的概念，务必能用自己的话清晰解释
  • 零和博弈中 Minimax 等价于 Nash 均衡；一般和博弈中可能存在多个 Nash 均衡
  • Pareto 最优 ≠ Nash 均衡——囚徒困境是经典反例，面试高频考点
  • MARL 中常用均衡收敛作为训练目标，而非简单的奖励最大化

· CTDE（集中训练·分散执行）

问题 1：独立学习（Independent Learning） ——每个 agent 各自学…

核心范式

Training Phase · 集中训练

Agent 1Agent 2Agent N

各 Agent 上报信息 → Central Critic / Mixer（可访问全局状态 s、联合动作 a），据此稳定训练。

Execution Phase · 分散执行

π₁(o₁)π₂(o₂)πₙ(oₙ)

训练完成后 仅用本地观测 oᵢ 决策，无需全局信息，满足实际部署约束。

为什么需要 CTDE？

问题 1：独立学习（Independent Learning）——每个 agent 各自学习，忽略其他 agent → 非平稳性严重，训练不稳定

问题 2：完全集中式——把所有 agent 看作一个"超级 agent"，联合动作空间 = |A|ᴺ → 维度爆炸

CTDE 的折中：训练时利用全局信息（稳定训练），执行时只用本地观测（满足实际部署需求）

CTDE 的两大技术路线

  • 集中式 Critic + 分散式 Actor：如 MAPPO、MADDPG — Critic 可以接收全局状态/联合观测，Actor 只用本地观测
  • 值分解（Value Decomposition）：如 QMIX、VDN — 将全局 Q 值分解为各 agent 的局部 Q 值的某种组合
  • CTDE 是当前 MARL 最主流的范式，面试必考
  • 核心要义：训练时可以"作弊"看全局信息，执行时只能用自己看到的
  • 两条技术路线：Actor-Critic（如 MAPPO）和 Value Decomposition（如 QMIX）
  • 要能解释为什么纯独立学习和纯集中式都不行，CTDE 如何取两者之长

· MAPPO（多智能体 PPO）

MAPPO 是单智能体 PPO 在多智能体场景下的自然推广，属于 CTDE 范式中 集中式…

从 PPO 到 MAPPO

MAPPO 是单智能体 PPO 在多智能体场景下的自然推广，属于 CTDE 范式中 集中式 Critic + 分散式 Actor 的路线。

Actor（分散式）

每个 agent i 有自己的策略 πᵢ(aᵢ | oᵢ)，仅基于本地观测 oᵢ 做决策。使用 PPO 的 clipped objective 更新：

L_actor = E[ min(rₜ · Âₜ, clip(rₜ, 1-ε, 1+ε) · Âₜ) ]

Critic（集中式）

Critic 估计价值函数，可以接收比 Actor 更多的信息：

  • 共享 Critic：V(s) — 接收全局状态，所有 agent 共享同一个 Critic
  • 独立 Critic：Vᵢ(oᵢ) — 每个 agent 有自己的 Critic，只用本地观测
  • 中心化 Critic：V(s, o₁, o₂, …, oₙ) — 使用全局状态 + 所有观测

共享 vs 独立 Critic 的选择

Critic 类型优点缺点适用场景
共享 Critic训练效率高、样本共享agent 差异大时表现差同质 agent、合作任务
独立 Critic灵活、可处理异质 agent训练效率低、非平稳异质 agent、竞争场景
中心化 Critic信息最完整、最稳定输入维度大、计算成本高agent 数量少时

MAPPO 在实际环境中的表现

StarCraft Multi-Agent Challenge (SMAC)：MAPPO 取得了与 QMIX 相当甚至更好的成绩，证明了简单的 policy gradient 方法在 MARL 中也能非常有效。

Overcooked：合作烹饪场景，MAPPO 配合参数共享能快速学会分工协作。

关键发现（来自 "The Surprising Effectiveness of PPO in Cooperative MARL"）：许多复杂的 MARL 算法并不一定比 well-tuned 的 MAPPO 更好。

  • MAPPO = PPO + CTDE，Actor 分散执行，Critic 可集中训练
  • 共享 Critic vs 独立 Critic 的选择是Q&A——关键看 agent 是否同质和任务类型
  • "The Surprising Effectiveness of PPO" 论文结论值得记住：简单方法 + 好的工程实践，往往胜过复杂算法
  • MAPPO 的参数共享（parameter sharing）能显著提升训练效率，但前提是 agent 角色相似

· QMIX / VDN — 值分解方法

值分解方法的目标是：将全局的团队 Q 值 Q_tot(s, a₁, …, aₙ) 分解为各…

核心思想

值分解方法的目标是：将全局的团队 Q 值 Q_tot(s, a₁, …, aₙ) 分解为各 agent 局部 Q 值 Qᵢ(oᵢ, aᵢ) 的某种组合，使得全局最优动作等价于各 agent 分别选择局部最优动作。

IGM 条件：argmax_a Q_tot(s, a) = (argmax_a₁ Q₁, …, argmax_aₙ Qₙ)

VDN（Value Decomposition Networks）

最简单的分解方式——直接加和：

Q_tot(s, a₁, …, aₙ) = Σᵢ Qᵢ(oᵢ, aᵢ)

优点：简单直观，自动满足 IGM 条件

缺点：表达能力弱，无法表示 agent 之间的复杂交互（如互补性）

QMIX

使用一个混合网络（Mixing Network）来组合各 agent 的 Q 值，约束为单调递增：

∂Q_tot / ∂Qᵢ ≥ 0, ∀i

这保证了 IGM 条件：如果 Q_tot 对每个 Qᵢ 单调递增，那么全局最优就是各自最优。

VDN · 简单加和

Q₁Q₂Q₃Σ → Q_tot

局部 Q 值直接相加得全局 Q_tot；不使用全局状态，表达力弱。

QMIX · 单调混合网络

Q₁Q₂Q₃Mixing Net → Q_tot

全局状态 s 经超网络生成混合权重（取绝对值 ≥ 0 → 保证单调性 / IGM）。

QMIX 的混合网络细节

  • 混合网络的权重由全局状态 s 通过超网络（Hypernetwork）生成
  • 超网络输出的权重经过绝对值操作确保非负 → 保证单调性
  • 偏置可以是任意值（不需要非负）

VDN vs QMIX 对比

方面VDNQMIX
分解方式简单加和单调性约束的非线性混合
表达能力弱中等（受限于单调性）
全局状态不使用用于生成混合网络权重
训练复杂度低中等（超网络参数）
IGM 保证✓ 天然满足✓ 由单调性保证
QMIX 的局限：单调性约束使得 QMIX 无法表示某些非单调的合作关系。后续工作如 QTRAN、QPLEX 试图放松这一约束，提升表达能力。
  • 值分解的核心是 IGM（Individual-Global-Max）条件——全局最优可以通过各 agent 独立 argmax 实现
  • VDN 加和分解最简单但表达力不足，QMIX 通过单调性约束的混合网络平衡了表达力与可分解性
  • QMIX 的超网络以全局状态为输入，生成混合网络权重（绝对值保证非负）——这是高频考点
  • QMIX 的局限在于单调性假设，后续 QTRAN/QPLEX 尝试突破

· 通信机制

在部分可观测环境中，单个 agent 只能看到局部信息

为什么需要通信？

在部分可观测环境中，单个 agent 只能看到局部信息。如果 agent 之间能学习通信协议来交换信息，就可以做出更好的协调决策。

CommNet

最经典的通信架构之一：

  • 每个 agent 生成一个通信向量 cᵢ
  • 所有其他 agent 的通信向量取均值后传入当前 agent
  • 通信是连续的（可微分），可以端到端训练
cᵢ = f(hᵢ)，hᵢ' = g(hᵢ, mean(c₋ᵢ))

限制：所有 agent 均等通信，没有选择性 → 当 agent 数量多时效率低

TarMAC（Targeted Multi-Agent Communication）

引入注意力机制实现有选择性的通信：

  • 每个 agent 生成 message（key-value）和 query
  • 用注意力权重决定关注哪些 agent 的消息
  • 不再是简单均值，而是加权聚合 → 可以学会"只听有用的"

学习通信协议

方法通信方式特点
CommNet均值聚合简单但无选择性
TarMAC注意力聚合有选择性的通信
IC3Net门控通信学习何时需要通信
DIAL离散消息训练时连续、执行时离散化

何时需要显式通信？

  • 环境部分可观测且 agent 观测互补时
  • 需要紧密协调的任务（如编队控制、接力传递）
  • agent 数量较少，通信开销可控时
  • 如果环境是全可观测的，或者任务可以通过隐式协调完成，显式通信可能不必要
  • 通信机制是 MARL 中解决部分可观测性的重要手段
  • CommNet（均值聚合）→ TarMAC（注意力机制）的演进体现了从"广播"到"定向通信"的进步
  • 通信协议可以端到端学习（因为消息是连续向量，梯度可以反向传播）
  • 需要能判断何时需要/不需要显式通信——全可观测 + 简单任务通常不需要

· 自博弈（Self-Play）

自博弈是一种在 竞争性环境 中训练 agent 的方法：让 agent 与自己的历史版本（或…

核心思想

自博弈是一种在竞争性环境中训练 agent 的方法：让 agent 与自己的历史版本（或当前版本）对弈，通过不断击败"过去的自己"来持续提升。

Self-Play 训练循环 · 不断击败"过去的自己"
当前策略 πₜ vs 历史策略 π₍ₜ₋ₖ₎
从策略池中抽取历史对手对弈
用对弈数据更新策略
πₜ₊₁ → 回到上一步
新策略既是选手也成为未来对手，循环自我提升

AlphaGo → AlphaZero

系统年份关键创新学习方式
AlphaGo2016SL 预训练 + RL 自博弈 + MCTS先从人类棋谱学习，再自博弈提升
AlphaGo Zero2017纯自博弈，无人类数据从随机初始化开始，完全自我学习
AlphaZero2018通用化（围棋/象棋/将棋）同一算法框架适用于多种棋类

OpenAI Five（Dota 2）

  • 5v5 Dota 2 对战，每个 hero 由独立的 agent 控制
  • 使用大规模自博弈 + PPO训练
  • 训练消耗约 10,000 年的等效游戏时间（通过分布式计算压缩到数月）
  • 关键技巧：手术刀训练（surgery）——训练过程中逐步放开游戏限制

自博弈的关键技术

  • 策略池（Policy Pool）：保存历史策略，从中采样对手 → 防止遗忘、保持多样性
  • Elo Rating：用 Elo 评分追踪策略强度，确保训练在进步
  • Fictitious Self-Play (FSP)：对手采样自历史策略的均匀分布 → 趋近纳什均衡
  • PFSP（Prioritized FSP）：优先与"恰好难以对付"的历史策略对弈 → 更高效地发现弱点
  • 自博弈的优势：不需要人类数据，能发现人类未知的策略；天花板取决于搜索空间的充分探索
  • AlphaGo → AlphaGo Zero 的关键区别：是否需要人类棋谱预训练（Zero 不需要）
  • 策略池防止"策略循环"（A 赢 B，B 赢 C，C 赢 A）——这是自博弈的核心工程挑战
  • OpenAI Five 展示了自博弈可以 scale 到复杂的多智能体实时对战场景

· MARL 的挑战

N 个 agent，每个有 |A| 个动作 → 联合动作空间 = |A|ᴺ ，指数级增长

挑战 1：维度爆炸

N 个 agent，每个有 |A| 个动作 → 联合动作空间 = |A|ᴺ，指数级增长。

例如：10 个 agent，每个 5 个动作 → 联合空间 = 5¹⁰ ≈ 1000 万

缓解方法：独立学习、值分解（QMIX/VDN）、Mean-Field 近似

挑战 2：信用分配问题（Credit Assignment）

团队获得了奖励，但哪个 agent 的贡献最大？这是合作场景中的核心难题。

  • 全局奖励：所有 agent 共享同一奖励 → 懒惰 agent 问题（free-rider）
  • 差分奖励（Counterfactual）：agent i 的贡献 = 有 i 时的团队奖励 - 没有 i 时的团队奖励
  • COMA：使用 counterfactual baseline 来精确分配信用
Aᵢ(s, a) = Q(s, a) - Σ_{a'ᵢ} π(a'ᵢ|oᵢ) · Q(s, (a₋ᵢ, a'ᵢ))

COMA 的优势函数：反事实基线移除了其他 agent 动作的影响。

挑战 3：非平稳环境

其他 agent 的策略在不断变化 → 从单个 agent 视角看，环境本身在变 → 传统 RL 的收敛保证不再适用。

缓解方法：CTDE（集中训练时考虑其他 agent 信息）、经验回放中加入 agent 指纹（Fingerprint）、Hyper Q-learning

挑战 4：可扩展性（Scalability）

当 agent 数量从几个增长到几百上千时：

  • 计算成本：参数量、通信量、采样效率都随 N 增长
  • 缓解方法：参数共享（同质 agent 共用网络）、Mean-Field 方法（用"平均 agent"代替逐个建模）、基于图的方法（只与邻居交互）
  • MARL 四大挑战务必能逐一清晰阐述：维度爆炸、信用分配、非平稳、可扩展性
  • 信用分配（Credit Assignment）是面试最高频考点——要能解释 counterfactual baseline 的思想
  • COMA 的核心：用反事实基线（如果 agent i 按策略均值行动，团队收益会怎样）来隔离 agent i 的贡献
  • 可扩展性的三大缓解方案：参数共享、Mean-Field、图网络——各自适用场景不同

自动驾驶多车协调

多辆自动驾驶车在交叉路口、高速合流等场景中需要协调决策：

  • 每辆车是一个 agent，观测周围车辆和道路信息
  • 合作目标：整体交通效率最大化、零碰撞
  • 挑战：agent 数量动态变化、安全约束硬性、实时性要求高

机器人协作

  • 多机器人搬运：多个机器人合作搬运超重物品，需要协调力的方向和大小
  • 仓库物流：AGV（自动导引车）路径规划与避碰
  • 编队控制：无人机群保持队形、协调避障

📋 Q&A（10 道）

核心区别在于 环境的非平稳性
Q1：多智能体强化学习与单智能体 RL 的核心区别是什么？

核心区别在于环境的非平稳性。在单智能体 RL 中，环境的 transition function 是固定的（MDP 假设）；而在 MARL 中，每个 agent 所面对的"环境"包含了其他 agent 的策略，当多个 agent 同时学习时，环境从单个 agent 视角来看是非平稳的。

其他区别还包括：(1) 从 MDP 扩展到 Markov Game；(2) 需要考虑 agent 间的合作/竞争关系；(3) 联合动作空间随 agent 数量指数增长；(4) 需要解决信用分配问题。

Q2：什么是 CTDE？为什么它是 MARL 中最主流的范式？

CTDE = Centralized Training, Decentralized Execution（集中训练，分散执行）。

训练阶段：可以使用全局信息（全局状态、其他 agent 的观测/动作等），这能缓解非平稳性问题，使训练更稳定。

执行阶段：每个 agent 仅基于自己的本地观测做决策，满足实际部署中的通信和延迟约束。

它之所以主流，是因为它平衡了两个极端：(1) 纯独立学习训练不稳定；(2) 纯集中式面临指数级的联合动作空间。CTDE 取两者之长——训练时"作弊"看全局信息保证稳定，执行时只用本地信息保证可部署。

Q3：请解释 QMIX 的工作原理和单调性约束

QMIX 是一种值分解方法，将全局 Q_tot 分解为各 agent 局部 Qᵢ 的非线性组合。关键约束是单调性：∂Q_tot / ∂Qᵢ ≥ 0，即 Q_tot 对每个局部 Qᵢ 单调递增。

工作机制：(1) 每个 agent 独立计算 Qᵢ(oᵢ, aᵢ)；(2) 一个混合网络（Mixing Network）将所有 Qᵢ 组合成 Q_tot；(3) 混合网络的权重由超网络（Hypernetwork）生成，输入是全局状态 s；(4) 超网络输出权重取绝对值，保证非负 → 保证单调性。

单调性保证了 IGM 条件：每个 agent 独立选择使 Qᵢ 最大的动作 aᵢ*，等价于全局最优的联合动作 → 因此执行时不需要集中式决策。

Q4：VDN 和 QMIX 有什么区别？各自的优缺点？

VDN：Q_tot = Σ Qᵢ，简单加和分解。优点是简单高效，天然满足 IGM；缺点是表达能力弱，无法表示 agent 之间的非线性交互。

QMIX：Q_tot = f(Q₁, …, Qₙ; s)，通过单调性约束的混合网络进行非线性组合。优点是表达能力更强，能利用全局状态信息；缺点是单调性假设限制了某些情况的表达（如互补关系）。

核心区别：VDN 假设 agent 贡献是独立可加的；QMIX 允许非线性组合但要求单调。实际中 QMIX 通常优于 VDN，但某些需要非单调关系的场景两者都可能失效 → 需要 QTRAN/QPLEX 等更强表达的方法。

Q5：什么是信用分配（Credit Assignment）问题？有哪些解决方案？

信用分配问题是指在合作场景中，团队获得一个全局奖励，但难以判断每个 agent 的个人贡献。如果所有 agent 获得相同奖励，可能出现"搭便车"（free-rider）现象。

解决方案：

  • 差分奖励：agent i 的贡献 = 有 i 的团队奖励 - 无 i 的团队奖励（反事实推理）
  • COMA：用反事实基线计算优势函数——将 agent i 的实际动作与其策略均值下的期望收益做差
  • Shapley Value：博弈论方法，精确但计算量指数级
  • 值分解（VDN/QMIX）：通过分解 Q 值隐式分配信用
  • Individual Reward Shaping：设计局部奖励函数来引导个体行为
Q6：MAPPO 中共享 Critic 和独立 Critic 如何选择？

选择取决于两个关键因素：agent 同质性和任务类型。

共享 Critic V(s)：所有 agent 共用一个 Critic。适用于同质 agent（角色相同）的合作任务。优点是样本效率高，缺点是无法区分不同 agent 的差异。

独立 Critic Vᵢ(oᵢ)：每个 agent 有自己的 Critic。适用于异质 agent 或竞争场景。灵活但效率较低。

中心化 Critic V(s, o₁…oₙ)：输入全局信息。信息最完整但维度大，适用于 agent 数量少的场景。

实践经验："The Surprising Effectiveness of PPO" 研究表明，在很多 benchmark 上共享 Critic + 参数共享的 MAPPO 表现出人意料的好，简单方法加上好的超参调优往往够用。

Q7：AlphaGo 和 AlphaZero 的自博弈机制有何不同？

AlphaGo (2016)：(1) 先用人类棋谱做监督学习（SL）预训练策略网络；(2) 再通过自博弈 + RL 微调策略；(3) 训练价值网络预测胜率；(4) 推理时用 MCTS 搜索。它依赖人类先验知识。

AlphaGo Zero (2017) / AlphaZero (2018)：(1) 从随机初始化开始，不使用任何人类棋谱；(2) 策略网络和价值网络合并为一个 ResNet；(3) 纯自博弈：用当前网络 + MCTS 采样，用搜索结果作为策略改进目标；(4) AlphaZero 进一步通用化到象棋和将棋。

关键区别：Zero/AlphaZero 证明了从零开始纯自我学习可以超越人类水平，不需要人类先验。它发现了许多人类棋手从未使用过的招法。

Q8：MARL 中的通信机制是如何学习的？

MARL 通信机制的关键在于让 agent 通过端到端训练学习通信协议，而非人工设计。

工作原理：(1) 每个 agent 生成一个连续向量作为消息；(2) 消息传递给其他 agent；(3) 接收方将消息整合到自己的决策中；(4) 因为消息是连续的，梯度可以通过消息传播，实现端到端优化。

演进路线：CommNet（均值聚合、无选择性）→ TarMAC（注意力聚合、有选择性）→ IC3Net（门控通信、学习何时通信）。

DIAL 方法则在训练时使用连续消息（可微分），执行时将消息离散化（更贴近真实通信约束）。通信并非总是必要的——全可观测环境或简单协调任务中，隐式协调可能就够了。

Q9：什么是纳什均衡？为什么 Pareto 最优不一定是纳什均衡？

纳什均衡：策略组合 (π₁*, …, πₙ*) 使得没有任何 agent 能通过单方面改变策略获得更高收益。它是一种"稳定态"——所有人都没有偏离的动机。

Pareto 最优：不存在另一个策略组合能在不损害任何人的前提下改善某人。它关注的是"社会效率"。

经典反例——囚徒困境：两个囚犯都选择"背叛"是纳什均衡（任何一方单独改为"合作"会被加刑），但双方都"合作"才是 Pareto 最优（总刑期最少）。问题在于"合作"不是纳什均衡——每个人都有偏离去"背叛"的动机。这揭示了个体理性 ≠ 集体理性的深刻矛盾。

Q10：如何解决 MARL 的可扩展性问题？

MARL 可扩展性问题的本质是：联合动作/状态空间随 agent 数量指数增长。主要缓解方法：

  • 参数共享（Parameter Sharing）：同质 agent 共用同一套网络参数，通过 agent ID 编码区分角色。将 N 个网络缩减为 1 个。
  • Mean-Field 方法：用所有邻居 agent 的"平均行为"来近似其影响，将 N-agent 交互简化为 1-vs-Mean 交互。计算复杂度从 O(Nᴷ) 降到 O(N)。
  • 图神经网络（GNN）方法：将 agent 间的交互建模为图结构，每个 agent 只与邻居通信。自然支持动态拓扑和不同数量的 agent。
  • 分层 MARL：高层规划器分配子目标，低层 agent 独立完成。将多 agent 协调分解为多个简单子任务。
  • 注意力机制：用注意力动态选择需要关注的 agent 子集，避免全连接通信的 O(N²) 开销。
