✅ 完成标志
  1. 能说清「实时 = 最坏情况有界，不等于快」，并解释为什么 WCET 只能给保守上界
  2. 能在一台机器上把最坏调度延迟系统性地压下来：隔离核、中断亲和、锁内存，并用 cyclictest 加负载实测验证
  3. 拿到一个新功能，能判断它该放 CP 还是 AP，并说清理由
  4. 能画出 CAN 的逐位仲裁过程，并解释低优先级报文的最坏响应时间由什么决定
  5. 能用 S/E/C 推出一个具体危害的 ASIL，并说清 ASIL 分解为什么必须先有独立性（FFI）
  6. 被问「为什么车端 C++ 禁动态内存和异常」时，能给出时序与可分析性的真实理由，而不是「标准规定」
