Transformer 架构

三个核心原因：①训练效率——Next Token Prediction 让 100% tok…
为什么 Decoder-Only 架构赢了 Encoder-Only 和 Encoder-Decoder？

三个核心原因：①训练效率——Next Token Prediction 让 100% token 参与损失计算，而 BERT 的 MLM 只有 15% token 参与，数据利用率低 6~7 倍；②简单性——单层堆叠比两层更容易扩展，训练基础设施、分布式策略、推理引擎都只需针对一种 block；③涌现能力——规模超过 100B 后自发出现 in-context learning 和 chain-of-thought 推理，这在其他架构中未被观察到。关键洞察：架构简单性是可扩展性的前提。

描述一个 token 从输入到输出的完整旅程。

完整旅程 11 步：①分词——文本通过 BPE/SentencePiece 转为 token IDs；②Embedding——整数查表得到 d_model 维向量，加上位置编码（RoPE/绝对位置）；③Attention——token 间通过 Q/K/V 交流信息（因果掩码只看过去）；④残差连接——input + Attention 输出；⑤FFN——每个 token 独立做非线性变换 + 知识检索；⑥残差连接——再次 bypass；⑦重复③-⑥共 N 次（32~126 层），维度始终 [batch, seq_len, d_model]；⑧Final LayerNorm——最后一次归一化；⑨LM Head——线性投影到 [vocab_size] 得到 logits；⑩Softmax——logits 转概率分布；⑪采样——根据策略（greedy/top-k/top-p/temperature）选下一个 token。

残差连接为什么对深度 Transformer 至关重要？

残差连接解决深层网络的 degradation 问题（56层比20层训练误差更高）。核心数学：反向传播时 ∂L/∂x = ∂L/∂y · (∂F/∂x + 1)，那个 +1 创建了"梯度高速公路"——即使 ∂F/∂x 很小（深层网络常见），梯度也不会消失。在 Transformer 中，每个子层（Attention 和 FFN）都包裹在残差连接中。没有残差连接，GPT-3 的 96 层和 Llama 3 的 126 层根本不可能训练。

FFN 在 Transformer 中的作用是什么？为什么说它是"知识存储"？

FFN 的作用：①引入非线性——Attention 是线性的（加权平均），FFN 通过激活函数（GeLU/SwiGLU）引入非线性变换能力；②知识存储——Geva 等人 (2021) 发现 FFN 本质是关联记忆：W₁ 的每行是 Key（匹配输入模式），W₂ 的每列是 Value（存储知识）。Transformer 的事实知识存在 FFN 权重中。FFN 占模型 ~80% 参数（Llama 3 8B 中约 6.4B/8B），印证了它是知识的主要载体。

Pre-Norm 和 Post-Norm 有什么区别？现代 LLM 用哪个？

Post-Norm: x = LN(x + Attn(x))，归一化在残差之后——梯度必须穿过 LayerNorm，深层训练不稳定。Pre-Norm: x = x + Attn(LN(x))，归一化在子层之前——残差连接保持"干净"，梯度可直接 bypass，训练 96+ 层稳定。现代标准是 Pre-Norm + RMSNorm（去掉减均值，快约 20%）。最新趋势：Post-Norm 正回归——OLMo 2 用 QK-Norm + Post-Norm 获得略好质量。

02

Self-Attention 机制

除以 √d_k 是为了控制注意力分数的方差
Self-Attention 中为什么要除以 √d_k？不缩放会怎样？

除以 √d_k 是为了控制注意力分数的方差。假设 Q 和 K 的每个分量都是均值 0、方差 1 的独立随机变量，那么 Q·K 的点积方差 = d_k。当 d_k 较大（如 64 或 128）时，点积值的分布范围很大，导致 Softmax 输入差异极大，输出接近 one-hot 分布。这种"饱和"状态下，Softmax 的梯度接近零，训练停滞（梯度消失）。除以 √d_k 将方差归一到 ~1，让 Softmax 工作在梯度健康的区域。

Self-Attention 和 Cross-Attention 有什么区别？

核心区别在于 Q、K、V 的来源。Self-Attention：Q、K、V 都来自同一个输入序列 X，每个 token 关注序列中的其他 token。Cross-Attention（交叉注意力）：Q 来自一个序列（如 Decoder 的当前状态），K 和 V 来自另一个序列（如 Encoder 的输出），用于两个不同序列之间的信息对齐。在 Decoder-Only 架构（GPT/Llama）中没有 Cross-Attention，只有带因果掩码的 Self-Attention。

为什么 Self-Attention 需要 Multi-Head？单头不够吗？

单头 Attention 只能学习一种"关注模式"。Multi-Head 将 d_model 拆分为 n_heads 个子空间（如 512 拆成 8×64），每个头独立计算注意力，学习不同的关注模式：有的头关注语法结构，有的关注语义关系，有的关注位置关系。参数量不变——d_model 拆成 n_heads 个子空间，总参数量与单头相同。

Self-Attention 的 O(n²) 复杂度是怎么来的？有哪些优化方法？

O(n²) 来自注意力分数矩阵——每个 token 的 Query 需要与所有 token 的 Key 做点积，产生 n×n 的分数矩阵。优化方法：①FlashAttention——IO 感知的分块计算减少 HBM 读写，实际加速 2-4 倍；②稀疏 Attention（Longformer/BigBird）——只计算局部窗口 + 少量全局 token，复杂度 O(n√n)；③线性 Attention（Performer）——用核函数近似 Softmax，复杂度 O(n)；④滑动窗口（Mistral）——每个 token 只看窗口内的 token，复杂度 O(nw)。

Self-Attention 是置换不变的，这意味着什么？如何解决？

置换不变性意味着：打乱输入序列的顺序，输出只是对应位置的打乱，不会改变任何值。这意味着模型无法区分 "猫追狗" 和 "狗追猫"。解决方案是引入位置编码：①绝对位置编码——每个位置一个可学习向量；②RoPE（旋转位置编码）——将位置信息通过旋转矩阵注入 Q 和 K 的点积中；③ALiBi——在注意力分数上加距离惩罚项。现代 LLM（Llama/Qwen/Mistral）普遍使用 RoPE。

03

KV Cache 与 MoE

KV Cache 是推理时缓存已计算 token 的 Key 和 Value 的技术
什么是 KV Cache？为什么推理时需要它？

KV Cache 是推理时缓存已计算 token 的 Key 和 Value 的技术。自回归生成中，每生成一个新 token 都需要对所有已生成 token 计算 Attention。如果没有缓存，生成第 n 个 token 需要重新计算前 n-1 个 token 的 K/V，复杂度 O(n²)。KV Cache 将前 n-1 个 token 的 K/V 缓存起来，生成第 n 个 token 时只需计算新 token 的 Q/K/V 并与缓存合并，复杂度降为 O(n)。代价是显存占用：batch × n_heads × seq_len × d_head × 2(K+V) × 层数，对长序列是显著瓶颈。

MoE (Mixture of Experts) 的核心思想是什么？

MoE 的核心是用多个"专家" FFN 替代单一 FFN，每次推理只激活少量专家。路由器（Router/Gating）决定每个 token 分配给哪些专家。关键优势：①参数量大但计算量小——如 Mixtral 8x7B 总参数 47B 但每次推理只用 13B（激活 2/8 专家）；②专家自然分工——不同专家倾向学习不同领域的知识。主要挑战：①负载均衡——避免某些专家过载；②显存占用——所有专家的参数都需要加载到显存；③训练稳定性——路由器的梯度估计（因为 argmax 不可导）。

Temperature 与解码策略

数学上 T=0 等价于 argmax，相同输入必然得到相同输出
Temperature=0 时输出为什么还不唯一？

数学上 T=0 等价于 argmax，相同输入必然得到相同输出。但工程实现中：①GPU 并行计算时线程执行顺序不确定；②浮点数加法不满足结合律——不同累加顺序导致不同舍入误差；③FP16/BF16 精度有限（~3-4 位有效数字），极接近的 logit 可能被舍入为相同值；④当 top-1 和 top-2 的 logit 差距小于精度时，GPU 误差可能导致排名反转；⑤贪心解码只选第一名，一旦选错后续路径完全分叉——"数值蝴蝶效应"。工业界方案：argmax 短路 + FP32 logits。

Top-K 和 Top-P (Nucleus Sampling) 有什么区别？

Top-K：固定保留概率最高的 K 个 token，缺点是 K 固定——分布集中时 K 太大（含低质量 token），分布平坦时 K 太小（丢失好候选）。Top-P：动态保留累积概率 ≥ P 的最小 token 集合，自适应——分布集中时候选少，分布平坦时候选多。实际使用通常组合：先 Top-K 截断（安全上限），再 Top-P 过滤（自适应），最后按概率采样。

如何在生产环境中保证 LLM 输出的确定性？

分层保障：①argmax 短路——T=0 时直接执行 argmax 跳过 softmax 和采样，完全确定性；②FP32 logits——LM Head 输出用 FP32 计算，精度从 ~3 位提升到 ~7 位有效数字，代价仅 ~2%；③锁死随机种子——锁定 Python/NumPy/PyTorch 的显式随机源；④GPU 确定性模式——强制固定并行计算顺序，但性能下降 10-30%。生产环境推荐组合：argmax 短路 + FP32 logits。

Scaling Laws

Kaplan Law (2020, OpenAI)：模型性能主要取决于参数量，参数越多越好…
什么是 Chinchilla Scaling Law？它和 Kaplan Law 有什么区别？

Kaplan Law (2020, OpenAI)：模型性能主要取决于参数量，参数越多越好，数据可以少一些。Chinchilla Law (2022, DeepMind)：模型参数量和数据量应该同步增长，最优配比约为 20 tokens/参数。例如 7B 参数的模型应该用 ~140B tokens 训练。Chinchilla 证明了之前很多大模型是"参数过多、数据不足"的。实践指导：如果训练预算固定，应该同时增加模型大小和数据量，而不是只增大模型。Inference Scaling 是最新趋势——通过增加推理时的计算量（如 o1 的思维链）来提升质量。

什么是 Emergent Abilities（涌现能力）？

Emergent Abilities 指模型在规模超过某个阈值后突然出现的能力，在小模型中观察不到。典型例子：①In-Context Learning——给几个例子就能学会新任务，不需要微调；②Chain-of-Thought——模型自发进行多步推理；③Few-shot 学习——小模型 few-shot 效果差，大模型 few-shot 效果接近 fine-tuning。争议：有研究认为涌现能力可能是评估指标选择导致的假象——使用连续指标（而非准确率阈值）时，能力提升是平滑的。但 in-context learning 的涌现性仍然被广泛认可。
