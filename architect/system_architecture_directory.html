高并发案例

IoT 接入网关（30 万长连接）

端到端 C++ 案例：从 SLA 反推单机 30 万连接的内存与握手预算、shared-nothing 线程模型与跨核下发、弱网半开连接与超时不等式、mTLS 握手风暴、QoS1 的 PUBACK 时机、OTA 控制面/数据面分离、以及 30 万连接怎么滚动升级。含 6 条 ADR。

标签：High Concurrency / C++阅读：100 分钟
万级并发图片处理流水线

端到端 C++ 案例：为什么「同时处理 10000 张」是未定义需求（360 GB vs 640 KB），三层并发度分开定容，4 MB 的 JPEG 为什么变 72 MB、配额单位为什么必须是字节，线程池分层与解码沙箱，队头阻塞与分级队列，GPU 批大小的吞吐/延迟兑换，以及反压失效的完整后果链。含 5 条 ADR。

标签：Throughput / C++阅读：65 分钟
容量估算与背压

两个案例的算术底座：Little's Law 的三种用法与三个盲区、利用率 70% 那条线与方差为什么比利用率更致命、USL 解释加核为什么会倒退、内存预算表的五步与两个必踩的坑、扇出与重试的尾延迟放大、背压的三种实现及其失效模式，外加一张 12 条的评审清单。

标签：Capacity / Methodology阅读：35 分钟

安全架构

架构师视角的安全：STRIDE 威胁建模怎么在评审里真的跑起来、认证与授权为什么必须分开（放错位置就是 IDOR）、JWT 当 session 用会怎样、多租户隔离必须在数据层兜底（RLS 的坑）、服务间身份与「秘密的零号问题」、密钥的三个生命周期问题与双密钥窗口、纵深防御每层各挡什么、供应链与 SBOM、以及假设已被攻破后的审计与告警。含 5 条 ADR 与反向判据。

标签：Security阅读：60 分钟

应用层架构

微服务架构

拆分边界（DDD 限界上下文）、服务通信、每服务一库、Saga、网关与服务网格。

标签：Microservices阅读：35 分钟
API 设计

API 的难点在于发出去就改不动了：一个字段类型改动，800 家客户要一到两年收敛。错误模型为什么也是契约（只有 code 不能改，按「调用方接下来该干什么」分三类并显式给 retryable）、幂等键的四个边界（占位必须在处理之前，否则并发下完全失效）、翻页期间数据变化导致的重复与遗漏、以及最难的下线老版本四步。含 3 条 ADR。

标签：API Design阅读：40 分钟
限流 · 熔断 · 降级 · 隔离

先把雪崩算出来（下游 RT 涨 100 倍吞吐掉 100 倍、线程池 2 秒打满），再逐个拆开那些「配错了等于没配」的细节：令牌桶的桶容量该由什么定、熔断为什么必须统计慢调用、线程池与信号量隔离的本质区别、超时三项取小与 deadline 传播、重试与熔断谁包着谁、CoDel 式自适应脱载。末尾给出全部参数的取值依据、3 条 ADR 与反向判据。

标签：Resilience阅读：55 分钟
架构的可验证性

怎么证明弹性设计真的生效：弹性代码平时一行都不跑，「配置了」和「生效了」之间常常脱节。稳态假设怎么定义、故障注入的四个层次（最值钱的是注入「慢」不是「挂」）、爆炸半径的四个维度与自动中止、契约测试解决什么与挡不住什么、金丝雀/影子流量/特性开关的适用边界与影子流量的三个陷阱、以及怎么把演练变成常态。含 4 条 ADR。

标签：Chaos / Verification阅读：40 分钟
