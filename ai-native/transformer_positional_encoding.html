为什么需要位置编码

Self-Attention 的计算本质是对输入 token 做 集合运算 ：对于查询向量…

1.1 Transformer 的排列不变性问题

Self-Attention 的计算本质是对输入 token 做集合运算：对于查询向量 q，它与所有 key 做点积再加权求和，这一过程与 token 的输入顺序无关。数学上：

Attention(Q, K, V) = softmax(QKᵀ / √d_k) V

如果将输入序列打乱顺序（对 Q、K、V 做相同排列），得到的输出只是同样被打乱，每个位置的注意力分数不变。这意味着：

  • "我 喜欢 你" 和 "你 喜欢 我" 在纯 Self-Attention 中无法区分
  • Transformer 本身是一个排列等变 (Permutation Equivariant) 函数
  • 没有位置信息注入，模型退化为"词袋模型 + 注意力"

1.2 与 RNN 的对比

特性RNN / LSTMTransformer (无 PE)
位置信息来源天然具备：按时间步逐个处理，隐状态累积序列顺序完全没有：并行处理所有 token，丢失位序
长距离依赖弱：梯度消失/爆炸强：任意位置直接交互
并行性差：必须串行好：可全并行
是否需要 PE不需要必须需要

1.3 位置编码的作用

没有位置编码的 Transformer 就像一个只能听到词汇集合却听不到语序的人——"狗咬人"和"人咬狗"在它耳中完全一样。

位置编码为每个 token 注入一个位置信号，使模型能够区分不同位置上的相同词。常见注入方式：

  • 加法注入：x' = TokenEmbed(x) + PosEmbed(pos)（主流方案）
  • 拼接注入：x' = [TokenEmbed(x); PosEmbed(pos)]（早期尝试，浪费维度）
  • 注意力偏置：直接修改 Attention Score（ALiBi 方案）
  • 旋转编码：在 Q/K 上做旋转变换（RoPE 方案）
知识要点
  • Transformer 的 Self-Attention 对输入顺序是排列等变的，不加 PE 无法区分词序
  • RNN 通过时间步递归天然编码位置，Transformer 必须显式注入位置信息
  • 位置编码不是"锦上添花"，而是 Transformer 工作的必要条件
02

正弦余弦位置编码 (Sinusoidal PE)

原始 Transformer（Vaswani et al

2.1 公式

原始 Transformer（Vaswani et al., 2017）提出的sinusoidal encoding方案，使用不同频率的正弦和余弦函数：

PE(pos, 2i) = sin(pos / 10000^(2i/d_model)) PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

其中：

  • pos — token 在序列中的位置（0, 1, 2, ...）
  • i — 维度索引（0, 1, ..., d_model/2 − 1）
  • d_model — 模型嵌入维度（如 512、768）
  • 偶数维用 sin，奇数维用 cos

2.2 频率的直觉理解

分母 10000^(2i/d_model) 随维度 i 增大而增大，对应的频率从高到低：

  • 低维度（i 小）：波长短、频率高 → 编码细粒度位置差异（相邻位置区分）
  • 高维度（i 大）：波长长、频率低 → 编码粗粒度位置信息（远距离位置关系）
  • 类比：二进制编码中，低位变化快（每个数都变），高位变化慢（每 2^k 个数才变一次）

Sinusoidal PE 波形示意（d_model=8, pos=0~7）—— 不同维度对用不同频率编码位置：

维度频率 ωsin 分量cos 分量作用
dim 0-1高频 1.000▁▂▃▅▇█▇▅█▇▅▃▂▁▂▃快速振荡 → 区分局部
dim 2-3中频 0.100▁▁▂▂▃▃▅▅███▇▇▅▅▃中速变化
dim 4-5低频 0.010▁▁▁▁▁▂▂▂████████▇缓慢变化
dim 6-7极低频 0.001▁▁▁▁▁▁▁▁█████████缓慢变化 → 编码全局结构

类似二进制计数：低位（低维）翻转快、高位（高维）翻转慢，多频率组合让每个位置获得唯一"签名"。

2.3 为什么选正弦/余弦——相对位置的线性变换

正弦编码最核心的数学性质：任意固定偏移 k 的位置编码可以通过当前位置编码的线性变换得到。

PE(pos + k) = T_k · PE(pos) 其中 T_k 是一个只依赖于 k 的线性变换矩阵（旋转矩阵）： 对每对维度 (2i, 2i+1)： ┌ PE(pos+k, 2i) ┐ ┌ cos(kω_i) sin(kω_i) ┐ ┌ PE(pos, 2i) ┐ │ │ = │ │ │ │ └ PE(pos+k, 2i+1) ┘ └ -sin(kω_i) cos(kω_i) ┘ └ PE(pos, 2i+1) ┘ ω_i = 1 / 10000^(2i/d_model)

这意味着模型可以通过学习注意力权重来捕获相对位置关系，而不仅仅是绝对位置。

Sinusoidal PE 的本质是一套"多频段时钟"——高频维度像秒针快速跳动区分相邻位置，低频维度像时针缓慢转动标记远距离关系。

2.4 可视化理解

想象一个热力图（pos × d_model）：

  • 每一行是一个位置的编码向量
  • 左侧列（低维）：条纹密集、快速振荡 → 高频分量
  • 右侧列（高维）：条纹稀疏、缓慢变化 → 低频分量
  • 不同位置的编码向量两两不同且点积随距离衰减

2.5 实现要点

  • Sinusoidal PE 是固定的，不参与训练（无可学习参数）
  • 理论上可泛化到任意长度（公式对任意 pos 有定义）
  • 与 token embedding 相加后输入 Encoder/Decoder
  • 原始论文实验表明 Sinusoidal 与 Learned PE 效果几乎相同
知识要点
  • 必须能写出完整公式，说清偶数维 sin、奇数维 cos
  • 核心优势：相对位置可通过线性变换表示 → 模型能学到相对位置关系
  • 频率设计：低维高频编码局部位置，高维低频编码全局位置
  • 不需要训练，理论上可推广到未见长度

可学习位置编码 (Learned PE)

直接将位置编码作为 可学习的嵌入矩阵 ，与词嵌入一样通过反向传播更新：

3.1 基本思想

直接将位置编码作为可学习的嵌入矩阵，与词嵌入一样通过反向传播更新：

PE = nn.Embedding(max_seq_len, d_model) x' = TokenEmbed(x) + PE(position_ids)

位置嵌入矩阵形状为 [max_seq_len, d_model]，每个位置对应一个可训练的 d_model 维向量。

3.2 代表模型

模型位置编码方式最大长度
BERTLearned PE512
GPT-2Learned PE1024
ViTLearned PE（2D 拉平为 1D）取决于 patch 数
原始 TransformerSinusoidal PE理论无限

3.3 与 Sinusoidal PE 对比

对比维度Sinusoidal PELearned PE
是否需要训练否（固定公式生成）是（反向传播更新）
参数量0max_len × d_model

实际效果与 Learned PE 相当与 Sinusoidal PE 相当
适用场景需要外推 / 参数效率优先固定长度任务（NLU、分类）
知识要点
  • Learned PE 最大的缺点：无法外推到训练时未见过的序列长度
  • BERT 最大支持 512 tokens 就是因为 Learned PE 限制了最大长度
  • 原始论文实验表明两者效果几乎相同，但后续 LLM 时代外推需求使得 Sinusoidal 及其改进方案更受青睐

相对位置编码 (Relative PE)

绝对位置编码为每个位置分配固定编码，但自然语言中 相对距离 往往比绝对位置更重要

4.1 核心思想

绝对位置编码为每个位置分配固定编码，但自然语言中相对距离往往比绝对位置更重要。例如"主语在谓语前面 2 个位置"比"主语在位置 3"更有意义。

相对位置编码直接在注意力计算中引入位置对之间的相对距离信息。

4.2 Shaw et al. (2018) — 相对位置表示

在注意力分数和值的加权中引入相对位置嵌入：

e_ij = (x_i W^Q)(x_j W^K + a_ij^K)ᵀ / √d_k z_i = Σ_j α_ij (x_j W^V + a_ij^V) a_ij^K, a_ij^V 是相对位置 (i−j) 对应的可学习嵌入 相对位置被截断到 [-k, k]（如 k=16）
  • 为 Key 和 Value 分别引入相对位置嵌入 aK 和 aV
  • 相对位置距离被 clip 到 [-k, k]，超出范围的共享边界嵌入
  • 总参数：2 × (2k+1) × d_k 个可学习参数

4.3 Transformer-XL (Dai et al., 2019)

Transformer-XL 重新分解了注意力分数，将绝对位置项替换为相对位置项：

原始：e_ij = (E_xi + U_i) W^Q W^K_ᵀ (E_xj + U_j)ᵀ 展开为四项： (a) E_xi W^Q W^K_E ᵀ E_xj ᵀ ← 内容-内容交互 (b) E_xi W^Q W^K_R ᵀ R_{i-j} ᵀ ← 内容-位置交互 (c) u W^K_E ᵀ E_xj ᵀ ← 全局内容偏置 (d) v W^K_R ᵀ R_{i-j} ᵀ ← 全局位置偏置 R_{i-j} = Sinusoidal(i−j)，u 和 v 是可学习全局向量
  • 用相对位置的 Sinusoidal 编码 Ri-j 替代绝对位置 U
  • 引入两个全局可学习偏置 u、v，取代原来每个位置的查询偏置
  • 支持段级递归 (Segment-level Recurrence)：建模超长文本

4.4 T5 Relative Bias (Raffel et al., 2020)

T5 采用最简洁的相对位置方案——直接在注意力分数上加一个标量偏置：

e_ij = x_i W^Q (x_j W^K)ᵀ / √d_k + b(i−j) b(·) 是对数分桶的相对位置偏置： 将相对距离映射到有限个桶（如 32 个），近距离用精细桶，远距离用粗桶 每个注意力头有独立的偏置参数
  • 偏置 b 是每个注意力头独立的标量参数
  • 使用对数分桶将无限的相对距离映射到有限个离散桶
  • 近距离分桶精细，远距离分桶粗糙 → 关注局部精确性
  • 参数量极少，效果优异
知识要点
  • 相对位置编码关注"两个 token 之间的距离"，而非"token 在序列中的绝对位置"
  • Shaw 方案为 K/V 都加相对位置嵌入；Transformer-XL 分解为四项并用 Sinusoidal 编码相对距离
  • T5 Bias 最简洁：每个头学一组标量偏置 + 对数分桶，参数极少
  • 相对 PE 天然更适合泛化到不同长度

RoPE (Rotary Position Embedding)

RoPE（Su et al

5.1 核心思想

RoPE（Su et al., 2021）的核心洞察：用旋转矩阵编码绝对位置，使得内积自然包含相对位置信息。

目标：设计函数 f(x, pos) 使得：

⟨f(q, m), f(k, n)⟩ = g(q, k, m − n) 即 q 和 k 在施加位置编码后的内积，只依赖于相对位置 m−n

5.2 数学推导

复数表示

将 d 维向量的每两个分量视为一个复数。对于第 i 对分量 (q2i, q2i+1)：

q̃_i = q_{2i} + j · q_{2i+1} （复数表示） 施加位置编码： f(q̃_i, m) = q̃_i · e^{j·m·θ_i} 其中 θ_i = 1 / 10000^(2i/d)

乘以 ejmθ 就是对复数做角度为 mθ 的旋转。

旋转矩阵形式

展开为实数矩阵运算：

┌ cos(mθ_i) −sin(mθ_i) ┐ ┌ q_{2i} ┐ f(q, m)_i = │ │ │ │ └ sin(mθ_i) cos(mθ_i) ┘ └ q_{2i+1} ┘ 对全部 d/2 对维度分别做旋转： f(q, m) = R(m) · q R(m) = diag(R_θ₁(m), R_θ₂(m), ..., R_{θ_{d/2}}(m))

验证内积的相对位置性质

⟨f(q, m), f(k, n)⟩ = qᵀ R(m)ᵀ R(n) k = qᵀ R(n−m) k 因为旋转矩阵满足 R(m)ᵀ = R(−m)，R(−m)R(n) = R(n−m) → 内积只依赖于相对位置 (n−m) ✓

5.3 RoPE 的优势

  • 绝对位置 → 相对位置：编码绝对位置但内积天然体现相对位置
  • 相对位置衰减：随着相对距离 |m−n| 增大，内积呈现自然衰减趋势（远距离 token 关注度降低），这符合语言学直觉
  • 外推性好：公式对任意位置有定义，配合 NTK 等方法可优雅扩展
  • 无额外参数：θ 的值由公式确定（与 Sinusoidal PE 类似），不增加模型参数
  • 计算高效：旋转操作等价于逐元素乘法，不引入矩阵乘法开销
  • 只作用于 Q/K：不修改 V，保留值向量的纯语义信息

5.4 为什么 RoPE 成为 LLM 标配

模型位置编码备注
LLaMA / LLaMA-2/3RoPEMeta 开源 LLM 系列

几乎所有主流开源 LLM 都采用 RoPE，原因：相对位置表达能力强 + 外推扩展方便 + 无需额外参数 + 实现简单高效。

知识要点
  • RoPE 的核心："旋转矩阵编码绝对位置，内积体现相对位置"——能用一句话概括
  • 数学推导：复数乘 ejmθ → 旋转矩阵 → R(m)ᵀR(n) = R(n−m)

  • 列举至少 3 个使用 RoPE 的 LLM（LLaMA、Qwen、DeepSeek）
  • RoPE 的衰减特性：远距离 token 的注意力分数自然衰减

ALiBi (Attention with Linear Biases)

ALiBi（Press et al

6.1 核心思想

ALiBi（Press et al., 2022）提出一个极简方案：不在嵌入层添加位置编码，而是直接在注意力分数上加一个与距离成正比的线性偏置。

6.2 公式

Attention_ij = softmax(q_i · k_j / √d_k − m · |i − j|) m 是每个注意力头的固定斜率（不可训练） head_1 用 m = 2^(−8/n), head_2 用 m = 2^(−16/n), ... n = 注意力头的总数

负号表示距离越远，注意力分数惩罚越大（偏置为负值）。不同头使用不同斜率，让模型同时关注局部和远距离：

  • 大斜率头：强烈惩罚远距离 → 关注局部上下文
  • 小斜率头：轻微惩罚远距离 → 关注全局上下文

6.3 特性

特性说明
无可训练位置参数斜率 m 由公式确定，不需要学习
不修改嵌入层不在 Q/K/V 之前注入位置信息
长度外推性强训练 1024 长度，推理可直接用于 2048+ 长度
实现极简只需在 attention score 上加一个预计算的偏置矩阵
计算开销几乎为零偏置矩阵可预计算并缓存

6.4 代表模型

  • BLOOM（BigScience）：176B 参数，使用 ALiBi
  • MPT（MosaicML）：使用 ALiBi 实现长上下文
  • 相比 RoPE，ALiBi 在 LLM 领域的采用率较低，但在特定场景（如超长文本处理）仍有价值
知识要点
  • ALiBi 不在嵌入层加位置编码，而是在注意力分数上减去线性偏置
  • 斜率 m 按几何级数分配，不需要训练
  • 天然外推性好：训练短序列可推理长序列
  • 与 RoPE 的区别：ALiBi 改 attention score，RoPE 改 Q/K 向量

长上下文扩展

RoPE 虽然公式对任意位置有定义，但模型在有限长度（如 4096）上训练后，直接推理到更长…

7.1 为什么 RoPE 的长度外推是热门研究方向

RoPE 虽然公式对任意位置有定义，但模型在有限长度（如 4096）上训练后，直接推理到更长序列（如 32K、128K）时性能会严重下降。原因：

  • 训练时未见过的高频旋转角度 → 注意力分布失真
  • 注意力分数的数值范围超出训练时的分布
  • 远距离 token 的位置信号与训练分布不匹配

LLM 长上下文能力是核心竞争力（RAG、长文档理解、代码分析），因此 RoPE 外推成为热门课题。

7.2 Position Interpolation (PI)

Chen et al., 2023 提出位置插值——最直接的方案：

原始：θ_i(pos) = pos / 10000^(2i/d) PI：θ_i(pos) = (pos × L_train / L_target) / 10000^(2i/d) 将位置缩放到训练长度范围内：pos' = pos × (L_train / L_target)
  • 将长序列的位置压缩到训练时的位置范围内
  • 需要少量微调（几百步）即可恢复性能
  • 缺点：压缩损失精度，近距离 token 的位置区分度下降

7.3 NTK-Aware Scaling

通过修改 RoPE 的基频 (base) 而非缩放位置来实现外推：

原始：θ_i = 1 / 10000^(2i/d) NTK-Aware：θ_i = 1 / (10000 × α)^(2i/d) α = (L_target / L_train)^(d/(d-2))
  • 直觉：调整旋转速度而非压缩位置
  • 高频分量（低维度）几乎不变 → 保留近距离位置精度
  • 低频分量（高维度）被缩放 → 扩展远距离表示范围
  • 甚至可以无需微调（Zero-shot）直接使用

7.4 Dynamic NTK

对 NTK-Aware Scaling 的改进：

  • 动态调整缩放因子：推理时根据实际序列长度动态计算 α
  • 短序列不缩放（保持原始精度），长序列自适应缩放
  • 无需预设目标长度 L_target

7.5 YaRN (Yet another RoPE extensioN)

Peng et al., 2023 综合了多种技术的 RoPE 扩展方案：

YaRN = NTK-Aware Interpolation + Attention Scaling + 分频段处理 低频维度：做 PI（插值） 高频维度：不修改（保留局部精度） 中间维度：在两者之间平滑过渡 额外加一个与序列长度相关的 Attention 温度缩放因子
  • 综合了 PI 和 NTK 各自的优点
  • 分频段处理：不同频率的维度使用不同策略
  • 只需少量微调（约 400 步）即可扩展到 128K+
  • 被 Qwen、Mistral 等模型采用

7.6 方法对比

方法核心策略是否需微调近距离精度远距离外推

Q1: 为什么 Transformer 需要位置编码？

因为 Self-Attention 的计算对输入顺序是排列等变 (Permutation Equivariant) 的——打乱输入 token 的顺序，每个位置的注意力分数不变（只是输出也被同样打乱）。这意味着纯 Self-Attention 无法区分"我喜欢你"和"你喜欢我"。而 RNN 通过时间步递归天然编码了位置顺序。Transformer 必须通过位置编码显式注入位置信息，否则会退化为"词袋模型 + 注意力权重"。

Q2: 写出 Sinusoidal 位置编码的公式，并解释为什么选用正弦/余弦？

公式：PE(pos, 2i) = sin(pos / 10000^(2i/d))，PE(pos, 2i+1) = cos(pos / 10000^(2i/d))。选用正弦/余弦的核心原因：相对位置可通过线性变换表示。具体来说，PE(pos+k) 可以通过一个只依赖于 k 的旋转矩阵 T_k 左乘 PE(pos) 得到，即 PE(pos+k) = T_k · PE(pos)。这意味着模型通过学习注意力权重，就能捕获任意相对距离的位置关系。此外，不同维度使用不同频率（低维高频、高维低频），类似二进制编码，能同时表达细粒度和粗粒度的位置信息。

Q3: Learned PE 和 Sinusoidal PE 各有什么优缺点？

Learned PE：优点是灵活，能适应特定数据分布，在固定长度任务（如 BERT 的 512 长度）上效果好；缺点是无法外推到训练未见过的序列长度，且增加 max_len × d_model 个参数。Sinusoidal PE：优点是无需训练参数，理论上可泛化到任意长度；缺点是固定模式，无法自适应数据。原始 Transformer 论文实验显示两者效果相当，但在 LLM 时代，外推需求使 Sinusoidal 及其改进（RoPE）更受欢迎。

Q4: 什么是相对位置编码？为什么它比绝对位置编码更好？

绝对位置编码给每个位置分配固定编码（如位置 0、1、2 各有对应向量），相对位置编码则关注 token 对之间的距离 (i−j)。相对 PE 更好的原因：①自然语言中"主谓间隔 2 个词"比"主语在位置 3"更具语义意义；②天然泛化到不同长度；③在翻译等任务中，同一句型出现在不同位置时，相对关系不变。代表方案包括 Shaw（为 K/V 加相对嵌入）、Transformer-XL（分解为四项）、T5 Bias（加标量偏置 + 对数分桶）。

Q5: 解释 RoPE 的核心原理，为什么它成为 LLM 标配？

RoPE 将每对维度 (2i, 2i+1) 视为一个复数/二维平面，对位置 m 处的 Q/K 向量做角度为 mθᵢ 的旋转（θᵢ = 1/10000^(2i/d)）。核心性质：旋转后的 Q 和 K 的内积 ⟨R(m)q, R(n)k⟩ = qᵀR(n−m)k，只依赖于相对位置 n−m。成为 LLM 标配的原因：①编码绝对位置但内积自然体现相对位置——两全其美；②无额外可训练参数；③远距离内积自然衰减，符合语言学直觉；④只作用于 Q/K，保留 V 的语义纯净性；⑤配合 PI/NTK/YaRN 可优雅扩展上下文长度。LLaMA、Qwen、DeepSeek、Mistral 等主流 LLM 均采用 RoPE。

Q6: RoPE 和 ALiBi 有什么区别？各自适合什么场景？

RoPE：在嵌入空间修改 Q/K 向量（旋转变换），位置信息编码进向量本身。ALiBi：不修改任何嵌入，直接在 attention score 上减去与距离成正比的线性偏置 m·|i−j|。差异：①RoPE 改向量，ALiBi 改分数；②RoPE 需要配合 PI/NTK 做长度扩展，ALiBi 天然外推性更好；③RoPE 被更多 LLM 采用（生态更丰富），ALiBi 用于 BLOOM/MPT。场景选择：需要强大社区支持和灵活扩展 → RoPE；追求极简实现和零成本外推 → ALiBi。

Q7: RoPE 的长度外推为什么会失败？PI 和 NTK-Aware Scaling 是如何解决的？

RoPE 外推失败的原因：模型在训练长度（如 4096）内见到的旋转角度范围有限，推理到更长序列时出现未见过的高频旋转角度，导致注意力分布严重失真（OOD 问题）。PI（Position Interpolation）：将超出范围的位置线性压缩到训练范围内，即 pos' = pos × (L_train/L_target)。优点是简单，缺点是压缩导致近距离位置分辨率下降。NTK-Aware Scaling：不压缩位置，而是修改基频 base = 10000 × α，使高频分量不变（保留近距离精度），低频分量扩展（覆盖远距离）。相比 PI，NTK 甚至可以零样本外推。

Q8: YaRN 是什么？它比 PI 和 NTK 好在哪里？

YaRN (Yet another RoPE extensioN) 综合了 PI 和 NTK 的优势，核心创新是分频段处理：①低频维度做 PI 插值；②高频维度不修改（保留局部精度）；③中间频段平滑过渡。此外还引入 Attention 温度缩放因子来补偿长序列的注意力稀释。优势：①保留近距离精度（高频不动）；②扩展远距离范围（低频插值）；③只需极少微调步数（约 400 步）即可扩展到 128K+。被 Qwen-2、Mistral 等模型采用。

Q9: T5 的相对位置偏置用了"对数分桶"，为什么？

T5 将无限的相对距离映射到有限个桶（如 32 个），使用对数分桶策略：近距离（如 |i−j| ≤ 8）每个距离一个桶，远距离按对数尺度合并。原因：①自然语言中近距离关系（相邻词、短语内部）需要精确区分，而远距离关系只需粗略感知；②对数分桶用有限参数覆盖大范围距离；③符合语言学直觉——"距离 100 和 101"的区别远小于"距离 1 和 2"的区别；④参数高效：32 个桶 × n_heads 个标量就能覆盖所有距离。

Q10: 如果你要从零设计一个支持 128K 上下文的 LLM，位置编码怎么选？

推荐方案：RoPE + YaRN。理由：①RoPE 是主流标配，社区支持好，工程实践成熟（LLaMA/Qwen/DeepSeek 验证）；②YaRN 分频段扩展近距离精度和远距离外推兼得；③先在 4K-8K 长度上预训练（数据获取容易、训练效率高），然后用少量长文本数据 + YaRN 扩展到 128K；④配合 FlashAttention-2 和 GQA 保证计算效率。备选方案：如果不想微调，可考虑 Dynamic NTK 做零样本外推；如果追求极简，ALiBi 也可以，但社区生态不如 RoPE。
