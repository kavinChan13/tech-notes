Vision Transformer (ViT)

从 Patch Embedding 到多模态视觉编码 —— 面试必备全解

Transformer 阅读 ~13 min 10 章
01

ViT 核心思想

ViT（Vision Transformer, Dosovitskiy et al

把图像当作一组 Token

ViT（Vision Transformer, Dosovitskiy et al., 2020）的核心想法极其简洁：

  1. 将输入图像（224×224）切分成不重叠的 Patch（默认 16×16），得到 N = 14×14 = 196 个 Patch；
  2. 将每个 Patch 展平为 768 维向量，通过一层线性投影映射到 D 维 Token Embedding；
  3. 在序列前端添加一个可学习的 [CLS] Token（与 BERT 一致）；
  4. 为所有 Token 加上可学习的位置编码（1D Position Embedding）；
  5. 将 (N+1) 个 Token 送入标准 Transformer Encoder；
  6. 取 [CLS] Token 的最终表示送入 MLP Head 完成分类。
z₀ = [ x_class ; x¹_p E ; x²_p E ; … ; xᴺ_p E ] + E_pos
其中 E ∈ ℝ^(P²·C × D)，E_pos ∈ ℝ^((N+1) × D)

为什么如此简单的想法就能 work？

  • 数据量够大时，Transformer 可以从数据中"学到" CNN 通过卷积核天然具备的局部性和平移等变性，无需硬编码归纳偏置。
  • 在 JFT-300M（3 亿张图片）上预训练后，ViT-L/16 在 ImageNet 上超越了同量级 CNN（如 BiT-L）。
  • Scaling Law：更大的模型 + 更多的数据 → 精度持续提升，且尚未饱和。
💡 知识要点
  • ViT 与 NLP Transformer 唯一的区别是输入端：NLP 用 tokenizer 把文本变成 token 序列，ViT 用 Patch Embedding 把图像变成 token 序列，之后完全一样。
  • "An Image is Worth 16x16 Words" — 标题即核心思想。
  • ViT 在小数据集（ImageNet-1K）上不如 CNN，因为缺少归纳偏置；但在大数据集上反超。
02

ViT 架构详解

将 H×W×C 的图像分为 N = HW/P² 个 Patch，每个 Patch 展平为 P…

2.1 Patch Embedding 层

将 H×W×C 的图像分为 N = HW/P² 个 Patch，每个 Patch 展平为 P²·C 的向量，然后进行线性投影：

x_patch ∈ ℝ^(P²·C) → z = x_patch · E，E ∈ ℝ^(P²·C × D)

实际实现中等价于 Conv2d(C, D, kernel_size=P, stride=P)。

2.2 Position Embedding（可学习）

  • 使用 1D 可学习位置编码，维度 (N+1) × D，直接加到 token 上。
  • 原论文实验表明：1D 与 2D 位置编码效果几乎无差异，因为模型可以自己从 1D 序列中学到 2D 空间关系。
  • 不使用正余弦固定编码（Sinusoidal），因为在视觉任务中可学习编码效果更好。

2.3 Transformer Encoder 层

每层由以下组件构成（Pre-Norm 形式）：

z'_l = MSA(LayerNorm(z_{l-1})) + z_{l-1}       # Multi-Head Self-Attention + 残差
z_l  = MLP(LayerNorm(z'_l))    + z'_l           # FFN + 残差
  • MSA：标准多头自注意力，复杂度 O(N²·D)
  • MLP：两层全连接，中间维度通常为 4D，激活函数 GELU
  • LayerNorm：放在注意力/MLP 之前（Pre-Norm），训练更稳定

2.4 MLP Head 分类头

  • 预训练时：[CLS] → LayerNorm → Linear(D, hidden) → GELU → Linear(hidden, classes)
  • 微调时：[CLS] → LayerNorm → Linear(D, classes)（单层即可）

💡 命名规则

ViT-B/16：B = Base 规模，16 = Patch 大小 16×16。Patch 越小 → Token 序列越长 → 计算量越大 → 精度越高。

💡 知识要点
  • Patch Embedding 等价于一个不重叠的大卷积核，但概念上更直观。
  • ViT 使用 Pre-Norm（LayerNorm 在前），而非 BERT 的 Post-Norm，训练更稳定。
  • 注意力计算复杂度 O(N²)，N=196（14×14），比 NLP 序列短很多，所以可以用全局注意力。

ViT 的数据需求

在仅使用 ImageNet-1K（130 万张）训练时，ViT-B/16 的 top-1 准…

3.1 小数据集上不如 CNN

在仅使用 ImageNet-1K（130 万张）训练时，ViT-B/16 的 top-1 准确率 低于 ResNet-152。原因：

  • CNN 天然具有局部性（locality）和平移等变性（translation equivariance）的归纳偏置；
  • ViT 几乎没有任何归纳偏置 — 每个 Patch 之间的关系完全靠自注意力从数据中学习。

3.2 JFT-300M 预训练后超越 CNN

预训练数据数据量ViT-L/16 Top-1BiT-L (ResNet152x4) Top-1
ImageNet-1K1.3M76.5%87.5%
ImageNet-21K14M85.1%87.5%
JFT-300M300M88.5%87.5%

结论：数据量从百万级 → 亿级，ViT 的优势才显现。

3.3 归纳偏置 (Inductive Bias) 讨论

归纳偏置CNNViT
局部性 (Locality)✅ 卷积核只看局部区域❌ 全局注意力，无局部先验
平移等变性 (Translation Equivariance)✅ 权重共享 + 滑动窗口❌ 仅靠位置编码隐式学习
尺度不变性⚠️ 通过池化部分实现❌ 无，需要多尺度策略
💡 知识要点
  • 归纳偏置是双刃剑：在小数据时帮助泛化，在大数据时反而限制模型的表达能力上界。
  • ViT 的设计哲学：用更多数据替代更强的归纳偏置。
  • 这与 NLP 的发展路径一致（LSTM → Transformer）。
04

DeiT — Data-efficient Image Transformers

ViT 需要 JFT-300M 级别数据才能训练好 → 能否只用 ImageNet-1K 就…

4.1 核心问题

ViT 需要 JFT-300M 级别数据才能训练好 → 能否只用 ImageNet-1K 就训练出有竞争力的 ViT？

DeiT（Touvron et al., 2021）的答案：可以，通过知识蒸馏 + 强数据增强。

4.2 知识蒸馏策略

DeiT 引入了一个专门的 Distillation Token：

  • 序列变为 [CLS] + N Patch Tokens + [DIST]，共 N+2 个 Token；
  • [CLS] Token → 与 Ground Truth Label 计算交叉熵损失；
  • [DIST] Token → 与 Teacher Model（RegNet）的输出对齐，计算蒸馏损失；
  • 总损失 = (1 - λ) · L_cls + λ · L_distill。
L = (1 - λ) · CE(softmax(z_cls), y) + λ · CE(softmax(z_dist), y_teacher)

4.3 硬蒸馏 vs 软蒸馏

方式Teacher 输出损失函数效果
软蒸馏 (Soft)softmax 概率分布KL 散度稍弱
硬蒸馏 (Hard)argmax 硬标签交叉熵更好 ✅

意外发现：硬蒸馏比软蒸馏更好（与传统认知相反），原因可能是硬标签的正则化效果。

4.4 数据增强与正则化

  • RandAugment：随机选择增强操作组合
  • Mixup：两张图线性混合
  • CutMix：用另一张图的区域替换
  • Random Erasing：随机擦除
  • Stochastic Depth：随机丢弃 Transformer 层
  • Repeated Augmentation：同一张图生成多个增强副本
💡 知识要点
  • DeiT 证明 ViT 不必依赖海量私有数据，公开数据 + 训练技巧即可达到 SOTA。
  • Distillation Token 是 DeiT 的独创设计，让蒸馏信号有专门的通道。
  • DeiT 的 Teacher 是 CNN（RegNet），说明 CNN 和 Transformer 各有所长。
05

Swin Transformer

ViT 的全局自注意力在高分辨率图像上计算量巨大（O(N²)），且单尺度特征不适合检测/分割…

5.1 设计动机

ViT 的全局自注意力在高分辨率图像上计算量巨大（O(N²)），且单尺度特征不适合检测/分割任务。Swin Transformer（Liu et al., 2021）引入层级结构 + 窗口注意力解决这两个问题。

5.2 层级结构 (Hierarchical)

类似 CNN 的多尺度特征金字塔：

阶段分辨率通道数Token 数
Stage 1H/4 × W/4C (96)56×56 = 3136
Stage 2H/8 × W/82C (192)28×28 = 784
Stage 3H/16 × W/164C (384)14×14 = 196
Stage 4H/32 × W/328C (768)7×7 = 49

5.3 窗口注意力 (Window Attention, W-MSA)

  • 将特征图划分为 M×M（默认 7×7）的不重叠窗口；
  • Self-Attention 仅在每个窗口内计算 → 复杂度从 O(N²) 降为 O(N · M²)；
  • 与全局注意力相比是线性的（相对于图像大小 N）。
全局注意力: O((H·W)²) = O(N²)
窗口注意力: O(N · M²)，M 固定为 7，所以对 N 是线性

5.4 移位窗口 (Shifted Window, SW-MSA)

窗口注意力的问题：窗口之间没有信息交互。Swin 在连续两层之间交替使用：

  • 第 l 层：常规窗口划分（W-MSA）
  • 第 l+1 层：窗口偏移 (M/2, M/2) 后再划分（SW-MSA）

通过 cyclic shift + mask 实现高效计算，不增加额外窗口数量。

5.5 Patch Merging 实现下采样

在每个 Stage 之间，将相邻 2×2 的 Token 在通道维度拼接（4C），再通过线性层降维到 2C。效果等价于 stride=2 的下采样，分辨率减半、通道翻倍。

5.6 与 ViT 的对比

特性ViTSwin Transformer
注意力范围全局（所有 Token）局部窗口 → 移位窗口
特征尺度单尺度多尺度（层级金字塔）
计算复杂度O(N²)O(N · M²)，线性
位置编码绝对位置编码相对位置偏置 (RPB)
适用任务分类分类 / 检测 / 分割 / 生成
作为 Backbone❌ 不直接适用✅ 可替代 ResNet
💡 知识要点
  • Swin 的核心创新：窗口注意力 + 移位窗口 → 在局部和全局之间取得平衡。
  • 层级结构使 Swin 能像 CNN Backbone 一样输出多尺度特征，天然适配 FPN / DETR。
  • Swin-T 与 ResNet-50 参数量相当（~29M），但在检测和分割上显著更强。
  • 相对位置偏置 (RPB) 比绝对位置编码更适合密集预测任务。

MAE — Masked Autoencoder

MAE（He et al

6.1 核心理念

MAE（He et al., 2022）是视觉领域的自监督预训练方法，灵感来自 NLP 的 BERT MLM，但针对图像特性做了关键改动。

6.2 方法流程

  1. 随机遮挡 75% 的 Patch（远高于 BERT 的 15%）；
  2. Encoder（标准 ViT）仅处理可见的 25% Patch → 计算量降为原来的 1/4；
  3. 在 Encoder 输出后，将 Mask Token 插入对应位置；
  4. Decoder（轻量 Transformer）重建被遮挡 Patch 的像素值；
  5. 损失函数：MSE（仅在被遮挡 Patch 上计算）。
L_MAE = 1/|M| · Σ_{i∈M} ‖ x_i - x̂_i ‖²

6.3 关键设计选择

设计选择原因
遮挡比例75%图像冗余度远高于文本，15% 太简单
Encoder 输入仅可见 Patch大幅加速训练（3~4×），Mask Token 不参与编码
Decoder轻量（8 层，512 维）重建任务不需要大模型，且解码器不用于下游
重建目标归一化像素值比原始像素或 tokenized patch 效果更好

6.4 与 BERT MLM 的对比

维度BERT MLMMAE
领域NLPCV
Mask 比例15%75%
Encoder 输入全部 Token（含 [MASK]）仅可见 Patch（高效）
重建目标离散词汇连续像素值
Decoder无独立 Decoder轻量 Decoder
信息冗余文本低冗余图像高冗余 → 需更高 mask 率
💡 知识要点
  • MAE 的高效性来自 Encoder 只处理可见 Patch，训练速度比 BEiT 等方法快 3~4 倍。
  • 75% 遮挡率是关键——太低任务太简单（插值即可），太高信息不足。
  • MAE 预训练 → 微调可超越从头训练，且在 ImageNet-1K 上即可完成（不需要额外数据）。
  • MAE 只用于预训练 Encoder，Decoder 在下游任务中被丢弃。

多模态视觉编码器

7.1 CLIP ViT

  • CLIP（Radford et al., 2021）= Contrastive Language-Image Pre-training
  • 使用 ViT 作为视觉编码器，Text Transformer 作为文本编码器
  • 通过对比学习（InfoNCE Loss）对齐 4 亿图文对的表示
  • 实现了零样本分类：无需微调，直接用文本描述类别即可分类
  • 学到的视觉表示具有极强的语义对齐能力
L_CLIP = -1/N · Σᵢ [ log( exp(sim(vᵢ,tᵢ)/τ) / Σⱼ exp(sim(vᵢ,tⱼ)/τ) ) ]

7.2 SigLIP

  • 将 CLIP 的 Softmax 对比损失替换为 Sigmoid 损失；
  • 不需要全局 Batch 归一化（去掉了 softmax 的分母），训练更稳定、可扩展性更好；
  • 支持更大 Batch Size，在 WebLI 数据集上训练；
  • 广泛用于 PaLI、Gemini 等谷歌多模态模型。

7.3 DINOv2

  • 自监督视觉预训练（无需文本/标签），结合自蒸馏 + masked image modeling；
  • 学到的特征在无需微调的情况下表现极佳（linear probing）；
  • 特征具有极强的空间感知能力，适合深度估计、分割、检索等密集任务；
  • 被认为是目前最强的纯视觉自监督特征。

7.4 作为 VLM 视觉编码器

模型视觉编码器特点
LLaVACLIP ViT-L/14Visual Instruction Tuning，开源标杆
LLaVA-1.5CLIP ViT-L/14 @ 336px高分辨率，MLP 投影
GPT-4V未公开（推测 CLIP 变体）商业闭源，能力最强
GeminiSigLIP / 内部 ViT原生多模态
InternVLInternViT-6B60 亿参数视觉编码器
💡 知识要点
  • CLIP ViT 是目前 VLM 最常用的视觉编码器，其核心价值是语义对齐的视觉表示。
  • SigLIP 是 CLIP 的工程改进，核心是用 Sigmoid 替代 Softmax，去掉全局归一化。
  • DINOv2 不用文本监督，但特征质量极高，尤其适合密集预测任务。
  • 视觉编码器通常冻结（或部分微调），通过 Projector 连接到 LLM。

CNN vs ViT

核心原理：归纳偏置 = 正则化

9.1 归纳偏置对比

维度CNNViT
局部性✅ 卷积核天然关注局部区域❌ 全局注意力，从数据学局部
平移等变性✅ 卷积 + 权重共享❌ 需要数据增强习得
层级结构✅ 逐层下采样❌ 单尺度（Swin 修复此问题）
全局建模❌ 感受野受限✅ 第一层即全局注意力

9.2 数据效率

  • 小数据（< 100K）：CNN 显著优于 ViT
  • 中等数据（~1M）：差距缩小，DeiT 策略可让 ViT 追上
  • 大数据（> 10M）：ViT 超越 CNN，且持续 scaling

核心原理：归纳偏置 = 正则化。数据越多，正则化的边际收益越低，而归纳偏置带来的表达力限制成为瓶颈。

9.3 计算复杂度

操作CNN (卷积)ViT (自注意力)
单层复杂度O(K² · C_in · C_out · H · W)O(N² · D + N · D²)
随分辨率增长线性增长二次增长（全局 ViT）/ 线性（Swin）
推理速度更快（硬件优化成熟）需要 FlashAttention 等优化

9.4 混合架构

现代趋势：融合 CNN 和 Transformer 的优点。

模型思路核心
ConvNeXt用 CNN 模仿 Transformer大核卷积 (7×7) + LayerNorm + GELU + Inverted Bottleneck
CoAtNetCNN + Transformer 拼接底层用深度可分离卷积（局部），高层用注意力（全局）
EfficientFormer面向移动端的混合架构轻量卷积 stem + 高效 Transformer blocks
MaxViT多轴注意力Block Attention + Grid Attention，线性复杂度的全局建模
💡 知识要点
  • CNN vs ViT 不是非此即彼 — 混合架构正在成为主流。
  • ConvNeXt 证明：只要设计得当，纯 CNN 也能达到 ViT 级别的精度。
  • CoAtNet 的启示：低层用卷积（局部）+ 高层用注意力（全局）是一种很好的组合。
  • 选择模型时需综合考虑：数据量、计算资源、部署环境、任务类型。

Q&A 10 问

ViT 将输入图像 (H×W×C) 切分为不重叠的 P×P Patch，得到 N = HW/…
Q1：ViT 是如何将图像转换为 Transformer 能处理的序列的？

ViT 将输入图像 (H×W×C) 切分为不重叠的 P×P Patch，得到 N = HW/P² 个 Patch。每个 Patch 被展平为 P²·C 维向量，通过线性投影映射到 D 维 Token Embedding。序列最前面拼接一个可学习的 [CLS] Token，所有 Token 加上可学习的 1D 位置编码，形成长度为 N+1 的序列送入 Transformer Encoder。

实现上，Patch Embedding 等价于一个 kernel_size=P, stride=P 的卷积操作。

Q2：ViT 在小数据集上效果不如 CNN 的根本原因是什么？

核心原因是归纳偏置 (Inductive Bias) 的缺失。CNN 通过卷积核天然具备局部性和平移等变性，这相当于内置了"图像的相邻像素更相关"的先验知识。ViT 几乎没有这些先验，全局注意力使得每个 Patch 都需要从数据中学习它与其他 Patch 的关系。

在数据量不足时，ViT 无法学到足够的模式，而 CNN 的归纳偏置起到了正则化的作用。但当数据量足够大时（如 JFT-300M），ViT 可以从数据中"学到"这些先验，且不受归纳偏置带来的表达力限制，因此反超 CNN。

Q3：DeiT 的 Distillation Token 是什么？为什么要用硬蒸馏？

Distillation Token 是 DeiT 在序列中额外插入的一个可学习 Token。它与 Teacher Model（RegNet）的输出对齐，而 [CLS] Token 与 Ground Truth 对齐。这样蒸馏信号和分类信号有各自独立的通道，避免两种损失相互干扰。

硬蒸馏（使用 Teacher 的 argmax 硬标签）比软蒸馏（使用 softmax 概率分布 + KL 散度）效果更好。虽然这与传统认知相反，但可能的解释是：硬标签引入了 Label Smoothing 的正则化效果，且减少了对 Teacher 过拟合模式的学习。

Q4：Swin Transformer 的窗口注意力如何降低计算复杂度？移位窗口解决了什么问题？

窗口注意力：将特征图划分为 M×M（默认 7×7）的不重叠窗口，Self-Attention 仅在每个窗口内计算。全局注意力复杂度为 O(N²)，而窗口注意力复杂度为 O(N·M²)，对图像大小 N 是线性的。

移位窗口 (Shifted Window) 解决了窗口之间无信息交互的问题。在连续两层中交替使用常规窗口和偏移窗口（偏移 M/2 像素），使得不同窗口的 Token 在下一层可以交互。通过 cyclic shift + attention mask 实现高效计算。

Q5：MAE 为什么要遮挡 75% 的 Patch？与 BERT 的 15% 有什么区别？

图像和文本的信息冗余度不同是根本原因。文本中每个词都承载独特的语义信息，遮挡 15% 已经构成有意义的预测任务。而图像具有极高的空间冗余——相邻 Patch 之间高度相关，遮挡 15% 时模型可以通过简单插值/外推完成"重建"，无需真正理解图像语义。

75% 的遮挡率迫使模型必须理解图像的全局结构和语义才能重建，形成了有效的自监督信号。

另一个关键区别：BERT 的 Encoder 处理所有 Token（包括 [MASK]），而 MAE 的 Encoder 只处理可见 Patch，Mask Token 仅在 Decoder 阶段引入。这使得 MAE 训练速度极快（约 3~4 倍）。

Q6：CLIP 是如何训练的？为什么 CLIP ViT 适合作为 VLM 的视觉编码器？

CLIP 训练：在 4 亿图文对上使用对比学习。将一个 Batch 中的 N 个图像和 N 个文本分别编码，计算 N×N 的相似度矩阵，正例为对角线（匹配的图文对），其余为负例。使用对称的 InfoNCE Loss 训练。

适合作为 VLM 视觉编码器的原因：

  • CLIP ViT 的视觉特征天然与文本语义对齐，LLM 更容易理解这些特征；
  • 对比学习使特征具有良好的零样本泛化能力，不局限于预定义类别；
  • CLIP 的训练数据覆盖了极其广泛的视觉概念，特征的语义覆盖面远超有监督训练。
Q7：Swin Transformer 为什么比 ViT 更适合目标检测和语义分割？

三个核心原因：

  1. 多尺度特征：Swin 通过 Patch Merging 产生 4 个不同分辨率的特征层（类似 ResNet 的 C2-C5），可以直接接入 FPN/DETR 等检测头。ViT 只输出单一分辨率的特征。
  2. 线性计算复杂度：检测和分割需要处理高分辨率特征图（如 800×1333），ViT 的 O(N²) 复杂度无法承受，而 Swin 的窗口注意力为 O(N·M²)。
  3. 局部归纳偏置：窗口注意力 + 移位窗口引入了一定的局部性先验，有利于密集预测任务中的精确定位。
Q8：ConvNeXt 的核心设计思路是什么？它证明了什么？

ConvNeXt 的思路是逐步将 ResNet "现代化"，对齐 Swin Transformer 的每个设计选择：

  • 宏观设计：Stage 比例改为 (3,3,9,3)，对齐 Swin
  • Stem：将 7×7 conv + pool 改为 4×4 conv stride 4（类似 Patch Embedding）
  • ResNeXt 化：使用 depthwise separable convolution
  • Inverted Bottleneck：窄→宽→窄（类似 MLP 的 4× 扩张）
  • 大卷积核：7×7 depthwise conv（模仿窗口注意力的感受野）
  • LayerNorm 替代 BatchNorm，GELU 替代 ReLU

ConvNeXt 证明了：ViT 的成功中有很大一部分来自训练策略和微观设计的进步，而非 Self-Attention 本身的不可替代性。纯 CNN 架构在对齐这些设计后，可以达到 Swin 级别的精度。

Q9：SigLIP 与 CLIP 的核心区别是什么？为什么要替换损失函数？

核心区别：CLIP 使用 Softmax 对比损失（InfoNCE），需要计算整个 Batch 的归一化分母；SigLIP 使用 Sigmoid 损失，将每个图文对独立判断为匹配/不匹配（二分类）。

替换的原因：

  • Softmax 需要在整个 Batch 上做全局归一化，分布式训练时需要跨设备通信，成为扩展瓶颈；
  • Sigmoid 损失每个图文对独立计算，天然适合大规模分布式训练；
  • Sigmoid 损失允许使用更大的 Batch Size（如 32K），进一步提升性能；
  • 在同等条件下，SigLIP 的性能与 CLIP 持平或略优，但训练效率更高。
Q10：给你一个新视觉任务，你会选 CNN 还是 ViT？

这是一个开放性问题，需要根据具体场景分析：

考量因素选 CNN选 ViT / Swin
数据量小数据（< 100K）大数据（> 1M）或有预训练
计算资源有限（移动端/边缘）充足（GPU 集群）
任务类型简单分类 / 实时推理检测/分割/多模态
是否需要全局建模否（纹理/局部特征为主）是（场景理解/长距离依赖）
工程成熟度高（TensorRT 优化成熟）快速追赶（FlashAttention 等）

最佳答案：先利用预训练模型（如 CLIP ViT / Swin / ConvNeXt），在目标数据集上 fine-tune；如果数据极少，考虑 CNN 或混合架构（CoAtNet）；如果部署环境受限，选择 EfficientNet / MobileNet 等轻量 CNN 或 EfficientFormer。
