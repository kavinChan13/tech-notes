自注意力机制的核心能力是让每个 token 都能"直接看到"整个序列里其他位置。

多头注意力：多角度看问题

Transformer 不只用一组注意力，而是同时用多组，这就是 多头注意力（Multi-Head Attention）。

为什么要多头？一个词和其他词的关系，往往不止一种维度。比如"苹果"和"树"的关系，可能既有"苹果是树上长的"这层语义，又有"苹果和树位置相邻"这层结构信息。单头注意力每次只能学一种关系模式，多头注意力相当于同时派出多个"分析员"，每个人从不同角度去看词与词的关系，最后把所有分析结果拼起来。

Multi-Head Attention = 多个注意力头并行计算 + 结果拼接 + 线性变换

其中 d_k = d_model / h，保证总计算量不随头数增加。

假设有 8 个注意力头，每个头负责不同的语义维度，最后把 8 个结果拼在一起，再做一次线性映射，输出和输入维度保持一致。

03

残差连接：把原来的自己加回来

自注意力算完之后，不是直接把结果往下传，而是要先做一个操作—— 把输出和输入相加

自注意力算完之后，不是直接把结果往下传，而是要先做一个操作——把输出和输入相加。

输出 = X + Sublayer(X)

这就是 残差连接（Residual Connection）。为什么要这样做？

好处解释
防止信息丢失哪怕注意力层没学到什么有用的东西，至少原始输入还保留着，不会越传越"面目全非"
解决深层训练难题网络层数很深时，梯度容易消失。残差连接提供了一条"快速通道"，让梯度可以直接流回较早的层，训练更稳定

残差连接的梯度高速公路原理：反向传播时，∂L/∂x = ∂L/∂y · (∂F/∂x + 1)。关键在于那个 +1——即使 ∂F/∂x 很小（深层网络中常见），梯度仍然有一条"直通路径"不经过任何权重矩阵的链式乘法。这意味着即使网络有 126 层，梯度也不会指数级衰减。

网络深度无残差连接有残差连接
20 层可训练，但收敛慢快速收敛
56 层训练失败（degradation 问题）稳定训练
96+ 层不可能标准配置

层归一化：把数值拉回合理范围

残差连接之后，紧接着是 层归一化（Layer Normalization，简称 LayerNorm）。

归一化的直觉：经过多次矩阵运算，数值可能跑得很大或很小，分布变得很不稳定。LayerNorm 的作用，是把每一层的输出重新拉回到均值为 0、方差为 1 附近的分布，让后续计算更稳定。

前馈神经网络子层：引入非线性理解

自注意力子层完成后，数据进入第二个子层：前馈神经网络（Feed-Forward Network，FFN）。

自注意力本质上是在做线性变换（对序列中各个位置进行加权组合）。但只有线性变换，模型的"理解能力"有上限——很多复杂的语义模式，线性变换捕捉不了。FFN 的存在，就是为了引入非线性，让模型能学到更深层次的语义信息。

FFN 结构：三步走

FFN 三步走 · 先升维引入非线性，再压缩回原维度

L × d_model = 512
L × 2048

L × 2048
引入非线性
输出 F
L × d_model = 512 · 降回原维度
FFN(X) = max(0, X · W₁ + b₁) · W₂ + b₂

这个"先升维再降维"的设计，让模型能够去捕捉非线性特征，然后再压缩回来继续传递。

本阶段小结

两个子层各司其职：

两个子层各司其职：

  • Self-Attention：让 token 之间互相"交流"，聚合全局信息
  • FFN：对每个 token 独立做深层非线性变换

两件外套保证稳定：

  • 残差连接：防止信息丢失 + 缓解梯度消失
  • 层归一化：稳定数值分布

常见误区：

  • 以为 Self-Attention 是非线性的（其实是线性的加权组合）
  • 忽略 FFN 的作用（非线性全靠它）
  • 混淆 Post-LN 和 Pre-LN 的顺序
  • 以为残差连接只是为了"保留信息"（更重要的是梯度通路）

Transformer Block 的可扩展性秘密：每个 Block 的输入输出维度完全相同 [batch, seq_len, d_model]，这意味着层与层之间无需任何适配——像 USB-C 接口一样即插即用。这个设计让 Transformer 可以无限制地堆叠：GPT-3 堆了 96 层，Llama 3 405B 堆了 126 层。

  • 保持输入输出维度一致（即插即用）
  • 使用 Pre-Norm（梯度直接 bypass）
  • 每个子层都包裹在残差连接中
  • 选择 RMSNorm（快 20%，现代标准）
  • 在层间改变张量维度
  • 去掉残差连接（深层训练必崩）
  • 用 Post-Norm 训练超过 24 层
  • 忽略 LayerNorm 的位置（Pre vs Post 差异巨大）

5 生产案例

生产验证： Llama 3 405B 采用 Pre-LN + RMSNorm + SwiGL…

生产验证：Llama 3 405B 采用 Pre-LN + RMSNorm + SwiGLU FFN 配置，堆叠 126 层 Transformer Block，训练稳定性良好（无梯度爆炸/消失）。对比实验：同参数规模下，Post-LN 在第 35 层时 loss 开始震荡（标准差从 0.02 飙升至 0.8），Pre-LN 全程标准差 <0.05。SwiGLU 相比 ReLU 在 MMLU 基准上提升 2.1 个百分点（78.3 → 80.4），代价是 FFN 参数量增加 50%（多一个门控矩阵）。残差连接的消融实验：去掉残差连接后，126 层模型在第 8 层就出现梯度消失（梯度范数 <10⁻⁷），训练完全失败。

Q&A

一层 Transformer Block 的结构是什么？
两个子层串联：(1) Self-Attention 子层——让 token 之间互相交流，聚合全局信息；(2) FFN 子层——对每个 token 独立做深层非线性变换。每个子层外面都包裹着残差连接和层归一化两件"外套"。关键特性：输入和输出维度完全一致（L × d_model），所以可以无限堆叠。
为什么要用多头注意力而不是单头？
一个词和其他词的关系往往不止一种维度。比如"苹果"和"树"可能既有语义关系（苹果长在树上），又有结构关系（位置相邻）。单头注意力每次只能学一种关系模式，多头注意力同时派出多个"分析员"从不同角度看词与词的关系，最后拼接结果做线性映射。总计算量不增加，因为每个头的维度 d_k = d_model / h。
残差连接为什么能缓解梯度消失？
反向传播时，梯度通过残差连接有一条直通路径（梯度恒为 1），不需要经过权重矩阵的链式乘法。即使网络很深，梯度也不会指数级衰减。另一个好处是信息保留——哪怕子层没学到有用的东西，原始输入还保留着，不会越传越"面目全非"。
Post-LN 和 Pre-LN 有什么区别？为什么现代模型用 Pre-LN？
Post-LN（原版）：子层 → 残差 → LN。Pre-LN（现代）：LN → 子层 → 残差。Pre-LN 的优势是训练更稳定——归一化在子层之前，确保子层输入的分布是稳定的，不会因为前一层的输出波动而震荡。Llama、PaLM 等现代大模型都用 Pre-LN。Post-LN 理论性能略好，但深层训练容易不稳定。
FFN 的作用是什么？为什么 Self-Attention 不够？
Self-Attention 本质上是在做线性变换（对序列中各个位置进行加权组合）。只有线性变换，模型的"理解能力"有上限——很多复杂的语义模式线性变换捕捉不了。FFN 通过"升维 → 激活函数（非线性）→ 降维"的三步走引入非线性。现代模型的 FFN 还有变体：GPT-2 用 GELU 激活，Llama/PaLM 用 SwiGLU 门控机制，效果更好。
Transformer 能堆到很深的原因是什么？
两个根本原因：(1) 维度一致性——每个 Block 的输入输出维度完全相同（L × d_model），所以可以无缝串联；(2) 残差连接——提供梯度直通通道，防止深层网络的梯度消失。GPT-3 堆了 96 层，GPT-4 推测 120+ 层。没有残差连接，堆到 10 层以上就基本训不动了。
